# 第 6 章　总体均数与总体率的估计

> 抽到一个样本，算出样本均数和样本率——这一章讲的是怎么给它们配一个有 95% 把握的范围。全部功夫都在一个量上：**标准误**。

## 这一章要解决什么

某地随机抽取 135 名正常成年男性测静息心率，得均数 78.82 次/分、标准差 9.58 次/分。那么能不能直接说「该地正常成年男性静息心率的平均水平就是 78.82 次/分」？

不能。换一批人再抽 135 例，算出来的均数不会正好还是 78.82。同样，某地抽 200 名居民查出 47 名高血压，患病率 23.5%，也不能直接说「该地居民高血压患病率就是 23.5%」。

原因就是上一章讲的**抽样误差**：只要个体之间有差异，样本统计量就不会正好等于总体参数。

最彻底的办法当然是普查——把总体里每个个体都测一遍，参数直接算出来，没有抽样误差。但实际工作中这往往做不到（人太多、经费有限），也没有必要（测一个地区所有人的心率没有意义）。所以研究者只能抽样，抽了样就必须面对抽样误差。于是这一章要回答两件事：

1. 抽样误差**有多大**？——用一个数把它量出来，这就是**标准误**。
2. 已知误差有多大之后，怎么给出总体参数的**合理范围**？——这就是**区间估计**。

样本均数（或样本率）是「点估计」，它简单但答不了「准不准」；区间估计才是本章的主角，也是后面假设检验的地基。

## 核心概念

### 抽样误差：样本统计量不等于总体参数

**抽样误差（sampling error）**：由于个体变异的存在，在抽样研究中产生的**样本统计量与总体参数之间**的差异，也包括**各样本统计量之间**的差异。

- **原因**：个体变异 + 抽样。两者缺一不可——总体里所有人一模一样就不存在抽样误差，不做抽样也就没有这个问题。
- **表现**：样本均数与总体均数的差别；样本均数与样本均数之间的差别。
- **不可避免**，但**有客观规律**，可以用统计方法估计其大小。

一个直观的演示：假设某地正常成年人红细胞数服从 $N(5.00,\ 0.43^2)$（单位 $10^{12}/\text{L}$），从该总体中每次抽 8 人测红细胞数，重复抽 100 份样本。结果是：

- 每份样本算出的均数**都不等于**总体均数 5.00；
- 100 个样本均数彼此也**不相等**；
- 但它们**围绕 5.00 分布，中间多、两边少，左右基本对称**，近似正态。

样本均数也是随机变量，有自己的概率分布，称为**均数的抽样分布**。要描述一组近似正态资料的变异程度，就用标准差——于是「100 个样本均数的标准差」这个量，自然成了抽样误差的度量。

**抽样误差小意味着什么**：样本统计量离总体参数近，用样本代表总体的可靠性大。可惜总体参数本来就是我们不知道的东西，所以抽样误差的大小没法直接算出来，只能通过研究样本均数的分布来把握它的规律。

### 标准误：样本均数的标准差（本章第一道坎）

> **样本统计量的标准差称为标准误（standard error）。样本均数的标准差称为均数的标准误**，记作 $S_{\bar{X}}$（有的软件输出里写成 SEM，standard error of the mean）。

定义听起来平淡，但它是本章最容易被混掉的概念。把它的来历拆成四步：

1. **样本均数是随机变量**。固定样本含量 $n$，从同一总体反复抽样，每份样本算出一个 $\bar{X}$。
2. **这些 $\bar{X}$ 构成一个分布**（均数的抽样分布），这个分布也有均数和标准差。
3. **这个分布的标准差**就是「样本均数的标准差」，即均数的标准误。理论上

   $$\sigma_{\bar{X}}=\frac{\sigma}{\sqrt{n}}$$

   它与原总体的标准差 $\sigma$ **成正比**，与样本含量 $n$ 的**平方根成反比**。
4. **$\sigma$ 通常未知**，用样本标准差 $S$ 代替，得到实际计算用的估计值

   $$S_{\bar{X}}=\frac{S}{\sqrt{n}}$$

   这也与前面对得上：若 100 个样本均数的标准差算出是 0.144，而理论值 $\sigma/\sqrt{n}=0.43/\sqrt{8}\approx 0.152$，两者十分接近。

**怎么理解这个式子**：

- 分子 $S$ 是**个体之间**的变异，分母 $\sqrt{n}$ 是「平均」效应——$n$ 个独立观测取平均，正的偏差和负的偏差互相抵消一部分，所以均数的变异比个体变异小，且 $n$ 越大越小。
- $S_{\bar{X}}$ 越大 → 样本均数越分散 → 抽样误差越大；$S_{\bar{X}}$ 越小 → 样本均数越集中 → 抽样误差越小。
- 只知道一个样本的 $\bar{X}$ 和 $S$，就能算出 $S_{\bar{X}}$，从而把「这次估计有多不准」量化出来。
- 对一个固定的总体，$\sigma$ 是常数，想减小抽样误差**只有增大样本含量 $n$ 这一条路**。注意是 $1/\sqrt{n}$ 的速率：样本量翻 4 倍，标准误才减半。

数值例：随机抽取某市 200 名 7 岁男童，身高均数 124.0 cm、标准差 4.6 cm，则均数的标准误为

$$S_{\bar{X}}=\frac{4.6}{\sqrt{200}}\approx 0.33\ \text{cm}$$

也就是说，用 124.0 cm 估计该市 7 岁男童身高的总体均数，抽样误差的量级大约是 0.33 cm。

#### 标准差与标准误的区别

这是本章第一个必考点，也是学生最常写错的地方。两者的公式只差一个 $\sqrt{n}$，含义却完全不同：

| 对比项 | 标准差 $S$ | 标准误 $S_{\bar{X}}$ |
| --- | --- | --- |
| 描述对象 | **个体观测值之间**的变异 | **样本均数之间**的变异 |
| 反映什么 | 个体差异的大小 | **抽样误差**的大小 |
| 公式 | $S=\sqrt{\dfrac{\sum (X-\bar{X})^2}{n-1}}$ | $S_{\bar{X}}=\dfrac{S}{\sqrt{n}}$ |
| 用途 | 描述频数分布状况；制定**医学参考值范围** | 描述样本均数的分布；用于**参数估计与假设检验** |
| 样本量变大时 | 基本不变（趋近 $\sigma$） | 越来越小 |

联系：样本含量一定时，标准误与标准差**成正比**——个体差异越大，抽样误差也越大。

一句话分辨：**标准差说的是「一个人和另一个人差多少」，标准误说的是「这次算出来的均数和真实均数差多少」。**

### 中心极限定理：为什么样本均数近似正态

上述推导依赖一个结论：

- 从均数为 $\mu$、标准差为 $\sigma$ 的**正态总体**中随机抽取例数为 $n$ 的样本，样本均数**服从正态分布**；
- 即使从**偏态总体**抽样，当 $n$ 足够大（如 $n>50$）时，样本均数也**近似**服从正态分布。

并且样本均数分布的均数与标准差是：

$$\bar{X}\sim N\!\left(\mu,\ \frac{\sigma^2}{n}\right),\qquad \mu_{\bar{X}}=\mu,\qquad \sigma_{\bar{X}}=\frac{\sigma}{\sqrt{n}}$$

注意两件事：**样本均数的均数仍等于总体均数 $\mu$**（所以用 $\bar{X}$ 估计 $\mu$ 是无偏的），**但它的标准差缩小到原来的 $1/\sqrt{n}$**。这条定理是后面所有区间估计的前提——不管总体长什么样，只要 $n$ 够大，样本均数就近似正态，就能用正态分布去划范围。

### t 分布：σ 未知时的补救

如果 $\sigma$ **已知**，把样本均数做标准化变换就得到标准正态分布：

$$u=\frac{\bar{X}-\mu}{\sigma_{\bar{X}}}=\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$$

可实际工作中 $\sigma$ 往往未知，只能用样本标准差 $S$ 估计它。这时变换的对象变了：

$$t=\frac{\bar{X}-\mu}{S_{\bar{X}}}=\frac{\bar{X}-\mu}{S/\sqrt{n}},\qquad \nu=n-1$$

统计量 $t$ **不再服从标准正态分布**，而是服从自由度为 $\nu=n-1$ 的 **t 分布**（又称 Student t 分布，1908 年由一位以「Student」为笔名发表论文的统计学家提出）。

为什么换成 $S$ 就不一样了？因为 $S$ 自己也是从这一次样本算出来的、带着抽样误差，$t$ 的分子分母都含随机成分，变异必然比 $u$ 大——多出来的那部分不确定性，就由 t 分布「更厚的尾巴」来承担，而尾巴有多厚由自由度决定。

**t 分布的特征**：

1. 单峰分布，在 $t=0$ 处最高，以 0 为中心左右对称；
2. 是一**簇**曲线，形状随自由度 $\nu$ 变化；
3. $\nu$ 越小，$t$ 值越分散，曲线越低平、**尾部越高**；$\nu$ 增大，曲线越尖峭、尾部越低；
4. $\nu\to\infty$ 时，t 分布逼近**标准正态分布**（t 分布的极限分布是标准正态分布）；
5. 曲线下面积（概率）总和为 1。

**t 界值表怎么读**：横标目是自由度 $\nu$，纵标目是概率 $P$（单侧 / 双侧），表内数字是与 $\nu$、$P$ 对应的 $t$ 临界值。由于左右对称，表里只列正值部分。

- 单侧概率的界值记作 $t_{\alpha,\nu}$，含义是 $P(t\le -t_{\alpha,\nu})=\alpha$ 或 $P(t\ge t_{\alpha,\nu})=\alpha$；
- 双侧概率的界值记作 $t_{\alpha/2,\nu}$，含义是 $P(|t|\ge t_{\alpha/2,\nu})=\alpha$，即左右两尾面积各 $\alpha/2$。

例如 $\nu=9$ 时，查表得单侧 $t_{0.05,9}=1.833$（曲线下 $t\ge1.833$ 的面积为 0.05），双侧 $t_{0.05/2,9}=2.262$（$t\le-2.262$ 与 $t\ge2.262$ 的面积之和为 0.05）。

从界值表能看出四条规律：

1. 自由度相同时，$t$ 界值越大，其对应的 $P$ 值越小；
2. $P$ 值相同时，自由度越大，$t$ 界值越小；
3. 同一个 $t$ 临界值处，**双侧概率是单侧概率的两倍**；
4. $\nu\to\infty$ 时，$t$ 界值就是 $u$ 界值（如双侧 $u_{0.05/2}=1.96$）。

规律 2 是全部区间估计的直觉来源：**自由度越大（样本越大），要的倍数越接近 1.96**。

### 总体均数的点估计

**点估计（point estimation）**：直接用样本统计量作为总体参数的估计值，例如用样本均数 $\bar{X}$ 估计总体均数 $\mu$。

上面的心率例子里，就是直接认为 78.82 次/分是该地正常成年男性静息心率的总体均数。

点估计的优点是简单；缺点是**没有考虑抽样误差**，既不知道估得准不准，也没法衡量误差有多大。同一个总体抽两次样，会得到两个不同的点估计值，谁也不知道离真值多远。

### 总体均数的区间估计

**区间估计（interval estimation）**：按事先给定的概率 $(1-\alpha)$，估计包含未知总体参数的一个可能范围。这个范围称为参数的**置信区间**或**可信区间**（confidence interval，CI），$1-\alpha$ 称为**置信度 / 可信度**（confidence level，常取 95%，也可取 90%、99%），区间通常用两个**可信限**（confidence limit）表示：较小的是**可信下限** $L$，较大的是**可信上限** $U$。

实现思路很朴素：既然 $\bar{X}$ 围绕 $\mu$ 波动，而波动的规律（分布）我们知道了，就可以反过来问——$\bar{X}$ 落在 $\mu$ 左右多大范围内是大概率事件？把这个不等式解出 $\mu$，就得到了 $\mu$ 的区间。

$$\bar{X}\sim N(\mu,\sigma_{\bar{X}}^2)\ \Longrightarrow\ P(-u_{\alpha/2}<\frac{\bar{X}-\mu}{\sigma_{\bar{X}}}<u_{\alpha/2})=1-\alpha\ \Longrightarrow\ P(\bar{X}-u_{\alpha/2}\sigma_{\bar{X}}<\mu<\bar{X}+u_{\alpha/2}\sigma_{\bar{X}})=1-\alpha$$

于是总体均数 $\mu$ 的 $1-\alpha$ 可信区间有三套公式，按 $\sigma$ 是否已知、$n$ 是大是小选择。

**① $\sigma$ 已知：用 u（标准正态）分布**

$$\left(\bar{X}-u_{\alpha/2}\sigma_{\bar{X}},\ \bar{X}+u_{\alpha/2}\sigma_{\bar{X}}\right)\qquad\text{即}\qquad \bar{X}\pm u_{\alpha/2}\sigma_{\bar{X}}$$

95% 时 $u_{0.05/2}=1.96$。

**② $\sigma$ 未知但 $n$ 足够大（如 $n>50$）：用 u 分布近似**

$n$ 大时 t 分布逼近 u 分布（$\nu$ 大，$t_{0.05/2,\nu}\approx1.96$），同时 $\sigma_{\bar{X}}$ 用 $S_{\bar{X}}$ 代替：

$$\bar{X}\pm u_{\alpha/2}S_{\bar{X}}\qquad\text{95\% 时即}\qquad \bar{X}\pm1.96\,S_{\bar{X}}$$

**③ $\sigma$ 未知且 $n$ 较小：用 t 分布**

这是**最常用、也最稳妥**的一套公式：

$$\boxed{\ \bar{X}\pm t_{\alpha/2,\nu}\,S_{\bar{X}}\ }\qquad \nu=n-1$$

**公式三个部分各是什么**：

- $\bar{X}$——点估计，区间的中心；
- $S_{\bar{X}}$——**标准误**，也就是 $S/\sqrt{n}$，它把「误差的尺度」定下来。这就是前面花大力气讲标准误的原因：**没有标准误就没有区间**。注意分子 $S$ 是这一个样本的样本标准差，不是总体标准差；
- $t_{\alpha/2,\nu}$——「要几倍标准误」，由可信度和自由度查 t 界值表得到。

**自由度为什么是 $n-1$**：$S_{\bar{X}}$ 里的 $S$ 是用这一次的样本估计出来的。$n$ 个观测值里，一旦样本均数 $\bar{X}$ 定了，就只有 $n-1$ 个偏差 $(X_i-\bar{X})$ 可以自由变动（它们之和必须为 0）。用掉一个自由度去估计均数，剩下的信息量就是 $n-1$，t 分布的自由度记的正是这份信息量。所以**样本量越大，$\nu$ 越大，$t$ 界值越接近 1.96，用 t 还是用 u 的差别越小**。

继续上面的心率例子：$n=135$，$\bar{X}=78.82$ 次/分，$S=9.58$ 次/分。

$$S_{\bar{X}}=\frac{9.58}{\sqrt{135}}\approx0.8245\ \text{次/分}$$

- 按公式②（$n=135$ 较大）：$78.82\pm1.96\times0.8245=78.82\pm1.62$，即该地正常成年男性静息心率总体均数的 95% 可信区间为 **（77.20，80.44）次/分**。
- 按公式③（$\nu=135-1=134$，查表 $t_{0.05/2,134}\approx1.98$）：$78.82\pm1.98\times0.8245=78.82\pm1.63$，即 **（77.19，80.45）次/分**。

两个结果几乎一样，说明 $n$ 大时两种方法没有实质差别。要注意的是：**当 $\sigma$ 未知时，无论 $n$ 是否足够大，都可以用公式③**（理论上更确切）；公式②只是 $n$ 大时为了手算方便的正态近似。有的教材把标准正态分位数写成 $u_{\alpha/2}$，有的写成 $z_{\alpha/2}$，指的都是 1.96 那个数。

**单侧可信区间**：如果只有一侧有意义——比如只关心「这批罐头的平均含量不高于多少」，下限没有实际意义——就用单侧区间：

$$\mu<\bar{X}+t_{\alpha,\nu}S_{\bar{X}}\qquad\text{或}\qquad \mu>\bar{X}-t_{\alpha,\nu}S_{\bar{X}}$$

注意单侧用的是 $t_{\alpha,\nu}$（不是 $t_{\alpha/2,\nu}$），同一个 $\alpha$ 下单侧界值更小，区间更窄。

数值例：随机抽取 10 听罐装牛肉，测得亚硝酸盐含量均数 17.6 mg/kg、标准差 1.64 mg/kg。关心的是「这批罐头的平均含量不高于多少」，所以只算单侧上限。$\nu=9$，$t_{0.05,9}=1.833$：

$$17.6+1.833\times\frac{1.64}{\sqrt{10}}=17.6+0.95=18.55$$

即 95% 单侧可信区间为**低于 18.55 mg/kg**。同一个资料若查双侧界值 $t_{0.05/2,9}=2.262$，上限会变成 18.77 mg/kg——单侧比双侧窄，正是因为把「两侧各 2.5%」的把握集中到了一侧。

### 可信区间的含义：话该怎么说

95% 可信区间的正确含义是：**从同一总体中重复抽取 100 份含量相同的独立样本，每份算一个可信区间，平均约有 95 个区间包含总体均数，约 5 个不包含。**本质上「随机」的是区间，不是参数。

实际研究只做一次抽样、只算一个区间，那么可以说：**这个区间包含总体均数，可信度为 95%。**

下面几种说法都是**错的**，考试里经常拿来设陷阱：

| 说法 | 错在哪 |
| --- | --- |
| 总体参数有 95% 的概率落在这个区间里 | 总体参数是常数，不是随机变量，谈不上「概率落在」；随机的是区间 |
| 有 95% 的总体参数在这个区间里 | 总体参数只有一个，没有「95% 的参数」这回事 |
| 该区间包含 95% 的总体参数 | 这是把可信区间和**医学参考值范围**搞混了 |
| 该区间包含总体参数，可信度为 95% | ✅ 这是正确的说法 |

**可信区间的两个要素**：

- **可信度（confidence）**：可靠性，即 $1-\alpha$，一般取 90%、95%、99%，可以人为控制，越大越有把握；
- **精确性（precision）**：区间的大小（长度），越小越好。

二者**必须兼顾**：想提高可信度（比如从 95% 提到 99%），分位数就要取大（1.96 → 2.58），区间必然变长、精度下降。所以不要盲目追求 99%，报告时要说明用的是多少可信度。

### 均数的可信区间与医学参考值范围

这两者公式长得像，含义完全不同，是本章第二个必考对比：

| 对比项 | 均数的可信区间 | 医学参考值范围 |
| --- | --- | --- |
| 意义 | 按预先给定的概率，确定**未知总体参数**的可能范围 | **「正常人」**的解剖、生理、生化等指标的波动范围 |
| 用哪个统计量 | **标准误** $S_{\bar{X}}=S/\sqrt{n}$ | **标准差** $S$ |
| 计算公式 | $\sigma$ 已知：$\bar{X}\pm u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$；$\sigma$ 未知：$\bar{X}\pm t_{\alpha/2,\nu}\dfrac{S}{\sqrt{n}}$ | 正态分布：$\bar{X}\pm u_{\alpha/2}S$；偏态分布：用百分位数法，如 $P_{2.5}\sim P_{97.5}$ |
| 用途 | **估计总体均数** | **判断某个观察对象的指标正常与否** |

一句话记：**可信区间回答「总体的平均水平大概是多少」（关于总体），参考值范围回答「这个人的指标算不算正常」（关于个体）。** 另外还有一个好用的分辨办法：**样本量增大时，参考值范围基本不变，可信区间却会明显变窄**——看题目里关注的是「个体波动」还是「估计精度」，就能判断问的是哪一个。

### 率的根基：贝努利试验与二项分布

总体率的估计不能照搬均数那一套，因为率来自另一种资料。它的基础是二项分布。

**贝努利试验（Bernoulli trial）**：$n$ 次独立重复试验，若每次试验结果出现且只出现对立事件 $A$ 与 $\bar{A}$ 之一，且每次出现 $A$ 的概率都是常数 $\pi$（$0<\pi<1$），则称为 $n$ 重贝努利试验。它要求三条：

1. 每次试验只有两种互斥结果（有效 / 无效、阳性 / 阴性、存活 / 死亡、合格 / 不合格）；
2. 各次试验结果互不影响（独立）；
3. 每次试验中事件 $A$ 发生的概率 $\pi$ 都相同。

令 $X$ 表示 $n$ 次试验中 $A$ 发生的次数，则 $X$ 可取 $0,1,2,\dots,n$，其概率函数为

$$P(X=k)=C_n^k\pi^k(1-\pi)^{n-k},\qquad k=0,1,2,\dots,n$$

称 $X$ 服从参数为 $n$ 和 $\pi$ 的**二项分布**，记作 $X\sim B(n,\pi)$。其中 $n$ 是离散参数（只能取正整数），$\pi$ 是事件 $A$ 发生的概率。它是典型的**离散型**概率分布。

以「3 只小白鼠接受毒物染毒、死亡率 80%」为例，死亡只数 $X$ 服从 $B(3,0.8)$，用上式算得

$$P(X=0)=0.008,\quad P(X=1)=0.096,\quad P(X=2)=0.384,\quad P(X=3)=0.512$$

四个概率之和为 1——它正好是二项展开式 $(0.8+0.2)^3$ 的各项。

**二项分布的性质**：

- 所有可能取值的概率之和等于 1：$\sum_{k=0}^{n}C_n^k\pi^k(1-\pi)^{n-k}=[\pi+(1-\pi)]^n=1$；
- **下侧累积概率**（至多 $m$ 例阳性）：$P(X\le m)=\sum_{k=0}^{m}C_n^k\pi^k(1-\pi)^{n-k}$；
- **上侧累积概率**（至少 $m$ 例阳性）：$P(X\ge m)=1-P(X\le m-1)$；
- 阳性发生数 $X$ 的总体均数、方差、标准差：$\mu=n\pi$，$\sigma^2=n\pi(1-\pi)$，$\sigma=\sqrt{n\pi(1-\pi)}$。

**二项分布的图形与正态近似**：$\pi=0.5$ 时分布对称；$\pi\ne0.5$ 时呈偏态（$\pi<0.5$ 正偏，$\pi>0.5$ 负偏），$n$ 越小、$\pi$ 离 0.5 越远就越偏；随着 $n$ 增大，二项分布逐渐逼近正态分布。一般地，当 $n\pi$ 与 $n(1-\pi)$ 都大于 5 时，就可以用正态近似原理处理二项分布问题。

**样本率的抽样分布**：由中心极限定理，$n$ 足够大时样本率 $p$ 近似服从正态分布，且

- $p$ 的总体均数等于总体率：$\mu_p=\pi$；
- $p$ 的标准差称为**率的标准误**：

$$\sigma_p=\sqrt{\frac{\pi(1-\pi)}{n}}\qquad\text{实际用}\qquad S_p=\sqrt{\frac{p(1-p)}{n}}$$

**率的抽样误差**就是「由抽样引起的样本率与总体率的差异」，用率的标准误度量——结构和均数的标准误完全平行：分子是变异（这次是 $\sqrt{p(1-p)}$），分母是 $\sqrt{n}$。

数值例：$n=200$、$p=0.235$，则 $S_p=\sqrt{0.235\times0.765/200}\approx0.030$，即该地居民高血压患病率的标准误估计值为 0.030。

### 总体率的区间估计

和均数一样，先用样本率 $p$ 作总体率 $\pi$ 的点估计，再做区间估计。两套方法：

**方法一：查表法**（适用于 $n$ 较小，或 $p$ 接近 0 或 1）

$n\le50$ 且 $p$ 接近 0 或 1 时，正态近似不成立，直接查「百分率的可信区间表」：按样本含量 $n$ 找行、按阳性例数 $X$ 找列，交叉处的数值就是总体率的 $1-\alpha$ 可信区间。

例：某医院用某抗生素治疗呼吸道感染，45 例患者中 2 例发生过敏反应，$n=45$ 行与 $X=2$ 列交叉处得 1～15，即过敏反应发生率的 95% 可信区间为 **（1%，15%）**。

> 使用附表时注意：表里通常只列出 $X\le n/2$ 的部分。当 $X>n/2$ 时，用 $n-X$ 去查表，再用 100% 减去查得区间的两个端点，得到所求可信区间。

**方法二：正态近似法**（适用于 $n$ 足够大、$p$ 与 $1-p$ 都不太小）

条件是 $np$ 与 $n(1-p)$ **均大于 5**，此时 $p$ 的抽样分布逼近正态分布，于是

$$\left(p-u_{\alpha/2}S_p,\quad p+u_{\alpha/2}S_p\right)$$

例：$n=200$，$p=0.235$，$np=47$、$n(1-p)=153$ 均大于 5，故

$$0.235\pm1.96\times0.030=(0.176,\ 0.294)$$

即该地居民高血压患病率的 95% 可信区间为 **（17.6%，29.4%）**。

**一个必须记住的收尾动作**：正态近似法算出来的下限可能小于 0%、上限可能大于 100%。这时应**相应地把下限写为 0%、上限写为 100%**，不能报告负的率。出现这种情况本身就是警报——说明样本量太小或 $p$ 太接近 0/1，正态近似条件不满足，应该改用查表法（或精确法）。

例如前面 45 例中 2 例的资料，若硬套正态近似法：$p=0.044$，$S_p=0.031$，区间算出来是（−1.6%，10.5%），下限为负，明显不合理；查表法给的（1%，15%）才是可用的答案。**小样本 + 接近 0 的率，一定要查表。**

### Poisson 分布：罕见事件计数的估计

当二项分布中的 $n$ 很大、$\pi$ 很小时，二项分布就变成了 **Poisson 分布**——它是二项分布的极限分布。若 $X\sim B(n,\pi)$ 中 $\pi$ 很小而 $n$ 很大，可认为 $X$ 近似服从参数 $\mu=n\pi$ 的 Poisson 分布。

**概率函数**：

$$P(X=k)=\frac{\mu^k}{k!}e^{-\mu},\qquad k=0,1,2,\dots$$

记作 $X\sim\Pi(\mu)$。$\mu>0$ 是唯一参数，表示单位时间（或单位面积、单位空间）内某随机事件的平均发生数，也就是总体均数；$e=2.7182\dots$ 是自然对数的底数。

**适用场景**：研究单位时间、单位人群、单位空间内**罕见事件**发生次数的分布，如单位体积水中的细菌数、单位体积空气中的粉尘数、单位时间内放射性物质放出的质点数、单位空间中某些昆虫数、一定人群中恶性肿瘤或罕见非传染性疾病的患病数或死亡数。

**三个条件**（满足则服从 Poisson 分布）：

- **平稳性**：$X$ 的取值与观察单位的位置无关，只与观察单位的大小有关；
- **独立性**：某个观察单位上 $X$ 的取值与其它观察单位上的取值独立；
- **普通性**：在充分小的观察单位上，$X$ 的取值最多为 1。

**性质**：

1. **总体均数与总体方差相等**，$\mu=\sigma^2$。利用这一点可以初步判断一个离散随机变量是否服从 Poisson 分布（例如某资料算得均数 0.500、方差 0.496，两者很接近，可以认为服从 Poisson 分布）。
2. **具有可加性**：若 $X_1,\dots,X_m$ 相互独立且分别服从 $\Pi(\mu_1),\dots,\Pi(\mu_m)$，则 $X_1+\dots+X_m$ 服从 $\Pi(\mu_1+\dots+\mu_m)$。应用中常借此把若干小观察单位合并成大观察单位，使 $\mu\ge20$，以便按正态近似处理。（注意：是**相加**才服从 Poisson 分布，相减不是。）
3. **图形**：$\mu$ 越小分布越不对称；$\mu$ 增大，分布趋于对称；$\mu=20$ 时已接近正态分布，$\mu\ge20$ 时可以用正态分布近似处理。

**平均计数的可信区间**：$n$ 个观察单位的总计数为 $X$，平均计数为 $X/n$。

- **$X>50$ 时用正态近似法**：

  $$\frac{1}{n}\left(X-u_{\alpha/2}\sqrt{X},\ X+u_{\alpha/2}\sqrt{X}\right)$$

  当 $n=1$（一个标准观察单位）时就是 $\left(X\pm1.96\sqrt{X}\right)$。例：某放射物质 30 分钟内测得脉冲数 $X=360$，则 30 分钟平均脉冲数的 95% 可信区间为 $360\pm1.96\times\sqrt{360}$，即（322.8，397.2）。

- **$X\le50$ 时用查表法**（根据 Poisson 分布直接计算）：

  例：$X=8$ 时查表得 95% 可信区间为（3.4，15.8）。如果改用正态近似法，会得到（2.5，13.5），明显偏窄——**计数小时必须用查表/精确法**，这一点和二项分布的小样本情形完全一样。

  若有多个观察单位：先把总计数 $X$ 查出来，得到区间后再**除以观察单位数**。例如 3 个单位时间共测得 $X=8+10+6=24$，先查 $X=24$ 得（15.4，35.7），再除以 3，得每个单位时间的 95% 可信区间（5.13，11.90）。

### 两总体均数之差的区间估计

实际工作里更常见的问题是「两组差多少」：试验组与对照组的血压平均降低多少？患病人群与正常人的某项指标平均相差多少？这时估计的对象是两总体均数之差 $\mu_1-\mu_2$，用的是两样本均数之差 $\bar{X}_1-\bar{X}_2$。

**① 两总体方差相等（$\sigma_1^2=\sigma_2^2$）**

$$\left(\bar{X}_1-\bar{X}_2\right)\pm t_{\alpha/2,\ (n_1+n_2-2)}\,S_{\bar{X}_1-\bar{X}_2}$$

其中两样本均数之差的标准误为

$$S_{\bar{X}_1-\bar{X}_2}=\sqrt{S_c^2\left(\frac{1}{n_1}+\frac{1}{n_2}\right)},\qquad S_c^2=\frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$$

$S_c^2$ 叫**合并方差**，是按自由度把两个样本的方差加权平均起来——因为假设两总体方差相等，就可以把两份信息合起来估计同一个 $\sigma^2$，比单独用一组更准。自由度 $\nu=n_1+n_2-2$（两组各用掉一个自由度估计各自的均数）。

**② 两总体方差不等（$\sigma_1^2\ne\sigma_2^2$）**

$$\left(\bar{X}_1-\bar{X}_2\right)\pm t_{\alpha/2,\ \nu'}\,S_{\bar{X}_1-\bar{X}_2},\qquad S_{\bar{X}_1-\bar{X}_2}=\sqrt{\frac{S_1^2}{n_1}+\frac{S_2^2}{n_2}}$$

此时不再合并方差，两组各自的方差各算一份；自由度 $\nu'$ 要用校正公式计算，结果一般不是整数（软件会自动算）。注意这里的标准误是**两组各自标准误的平方相加再开方**——这与单个均数的 $S/\sqrt{n}$ 是同一套逻辑，只是多了一组。

**③ 两样本含量都较大时**（$n_1,n_2$ 均大于 50），$t$ 分布近似正态分布，把 $t_{\alpha/2,\nu}$ 换成 $u_{\alpha/2}$ 即可。

**数值例**（用 R 自带的 `iris`，两种鸢尾花花萼长度）：setosa 与 versicolor 各 50 朵，$\bar{X}_1=5.006$、$S_1=0.352$，$\bar{X}_2=5.936$、$S_2=0.516$。按方差齐的公式：

$$S_c^2=\frac{49\times0.352^2+49\times0.516^2}{98}\approx0.195,\qquad S_{\bar{X}_1-\bar{X}_2}=\sqrt{0.195\times\left(\frac{1}{50}+\frac{1}{50}\right)}\approx0.0884$$

$\nu=98$，$t_{0.05/2,98}\approx1.984$，于是

$$(5.006-5.936)\pm1.984\times0.0884=-0.930\pm0.175\ \Longrightarrow\ (-1.105,\ -0.755)\ \text{cm}$$

**区间怎么读**：这段区间**不包含 0**，说明两种花的平均花萼长度之差不为 0，可以认为两者有差别；而且区间都在负数一侧，说明 setosa 的花萼长度更短（区间给出了差别的**方向**）。如果区间包含 0，就说明「差 0」是一个合理值，尚不能认为两组有差别。

### 两总体率之差的区间估计

同样，比较两组率（两种疗法的有效率、两个地区的患病率）时，估计的是 $\pi_1-\pi_2$，用 $p_1-p_2$ 推断。

**条件**：$n_1p_1$、$n_1(1-p_1)$、$n_2p_2$、$n_2(1-p_2)$ 都大于 5（两组各自的二项分布都接近正态）。

**正态近似法**：

$$\left(p_1-p_2\right)\pm u_{\alpha/2}\,S_{p_1-p_2},\qquad S_{p_1-p_2}=\sqrt{\frac{p_1(1-p_1)}{n_1}+\frac{p_2(1-p_2)}{n_2}}$$

结构上仍然是「估计值 ± 倍数的标准误」，而两样本率之差的标准误同样是**两组各自标准误平方相加再开方**。

**数值例**：甲组 200 例中 47 例阳性（$p_1=0.235$），乙组 180 例中 30 例阳性（$p_2=0.167$）。

$$S_{p_1-p_2}=\sqrt{\frac{0.235\times0.765}{200}+\frac{0.167\times0.833}{180}}\approx0.0409$$

$$(0.235-0.167)\pm1.96\times0.0409=0.068\pm0.080=(-0.012,\ 0.148)$$

即两总体率之差的 95% 可信区间为（−1.2%，14.8%）。**区间包含 0**，说明两组阳性率之差为 0 是个合理的可能，尚不能认为两组的总体率不同。

**样本量小、$p$ 接近 0 或 1 时**：近似正态法失效，可对样本率做「分子加 1、分母加 2」的校正（$\tilde p_1=(X_1+1)/(n_1+2)$，$\tilde p_2=(X_2+1)/(n_2+2)$，标准误也按校正后的率与校正后的分母计算），或者干脆用精确法。样本量很小时算出来的区间可能宽到（−50%，64%）这种程度——区间宽本身就是「信息不足」的表达，不要硬下结论。

### 区间估计与假设检验的关系

区间估计和假设检验是统计推断的两大方法，**回答的是同一个问题的两个侧面**，结论天然一致。

**一致性**：双侧检验时，若检验水准取 $\alpha$，则置信度为 $1-\alpha$ 的可信区间与检验结论一一对应：

- 可信区间**不包含** $H_0$ 所规定的参数值（单样本时是 $\mu_0$，两样本差值时是 0），等价于 $P<\alpha$，按 $\alpha$ 水准**拒绝** $H_0$；
- 可信区间**包含**该值，等价于 $P>\alpha$，**不拒绝** $H_0$。

原因不难理解：两者用的是同一个分布、同一个标准误。举个例子，某研究算得两组平均网购花费之差的 95% 可信区间为 $126\pm1.96\times95=(-60.2,\ 312.2)$（单位：元），要检验的 $H_0:\mu_1-\mu_2=0$ 正好落在这个区间里面，于是假设检验的结论必然是「不拒绝 $H_0$」——两个方法给出的是同一个答案。所以可以说：**可信区间能回答假设检验的问题。**

要注意对应关系：**双侧检验对应双侧可信区间，检验水准 $\alpha$ 对应可信度 $1-\alpha$**。用 95% 可信区间去判断 $\alpha=0.01$ 的检验，或者拿单侧检验的结论去对双侧区间，都会对不上。

**可信区间还能提供假设检验提供不了的信息**：P 值只回答「有没有统计学意义」，可信区间还告诉你**差别的大小和方向**，从而判断有没有**实际意义**。例如某降压药要求血压平均降低 10 mmHg 以上才算有临床价值，若差值的 95% 可信区间是（2，6）mmHg，虽然不含 0、统计学上有意义，但整个区间都够不上 10 mmHg，临床上意义不大；反过来区间很宽（如（−1，20））时，则提示样本量可能不足。所以**研究报告假设检验结论的同时，还应当报告相应的可信区间**——这也是现在期刊的通行要求。

## 在 R 里怎么做

### 1 一个均数：手算和 `t.test()` 对一遍

```r
# 用 R 自带的 iris：setosa 的花萼长度（cm），共 50 朵
x <- iris$Sepal.Length[iris$Species == "setosa"]
n <- length(x)

mean(x)             # 点估计：样本均数
sd(x)               # 标准差 S —— 个体之间的变异
sd(x) / sqrt(n)     # 标准误 S_X̄ —— 抽样误差的大小

# 手算 95% 可信区间：X̄ ± t(0.975, n-1) · S/√n
mean(x) + c(-1, 1) * qt(0.975, df = n - 1) * sd(x) / sqrt(n)

# 和 t.test() 给的可信区间对照，两者应当完全一致
t.test(x)$conf.int
```

输出怎么读：

- `mean(x)` ≈ `5.006`，`sd(x)` ≈ `0.352`，`sd(x)/sqrt(n)` ≈ `0.0498`——标准误比标准差小了 7 倍多，这就是「50 个观测取平均」换来的精度；
- `qt(0.975, df = 49)` = `2.0096`，就是公式里的 $t_{0.05/2,\nu}$。`qt(p, df)` 取的是**分位数**，$p=0.975$ 落在右尾，所以得到正值；
- 手算结果是 `(4.9058, 5.1062)`，`t.test(x)$conf.int` 打印的是同一对数字（它带属性，外面套一层 `as.numeric()` 就能看出完全相等）。

`qt(alpha/2, df)` 取到的是**负数**，所以也可以写成 `mean(x) + c(-1, 1) * (-qt(0.025, df)) * sd(x)/sqrt(n)`；两种写法等价，别把符号弄反。

### 2 标准误到底是什么：做一次抽样模拟

标准误的定义是「样本均数的标准差」，与其背定义，不如亲眼看一下。

```r
set.seed(20240601)

# 模拟：从 N(5.00, 0.43^2) 中每次抽 8 人，重复 1000 次，每次都算样本均数
means <- replicate(1000, mean(rnorm(8, mean = 5.00, sd = 0.43)))

sd(means)         # ≈ 0.15：1000 个样本均数的标准差（标准误的实测值）
0.43 / sqrt(8)    # ≈ 0.152：理论值 σ/√n

hist(means, main = "1000 个样本均数的分布", xlab = "样本均数")
```

输出怎么读：

- `sd(means)` 与 `0.43/sqrt(8)` 很接近——**「样本均数的标准差」就是标准误**，理论公式 $\sigma/\sqrt{n}$ 是对的；
- 直方图是钟形的，说明样本均数近似正态，这就是中心极限定理；
- 试着把 `8` 改成 `64`：样本量变成 8 倍，`sd(means)` 大约降到原来的 $1/\sqrt{8}\approx0.35$，也就是从 0.15 降到 0.05 左右。**标准误按样本量的平方根缩小**，想把误差压到一半，样本量要翻 4 倍——靠多抽人来提高精度，成本比想象中高。

### 3 一个率：正态近似法 vs 精确法

```r
# 某地 200 名居民中检出 47 例阳性
p <- 47 / 200
n <- 200

# 正态近似法（条件：np 与 n(1-p) 都大于 5）
sp <- sqrt(p * (1 - p) / n)
p + c(-1, 1) * qnorm(0.975) * sp

# 精确法（Clopper-Pearson），对应教材里查表法给的区间
binom.test(x = 47, n = 200)$conf.int

# 反过来看小样本：45 例中 2 例，正态近似法会失效
p2 <- 2 / 45
p2 + c(-1, 1) * qnorm(0.975) * sqrt(p2 * (1 - p2) / 45)  # 下限是负的
binom.test(x = 2, n = 45)$conf.int                       # 这才可用
```

输出怎么读：

- 正态近似法给出 ≈ `(0.176, 0.294)`，即（17.6%，29.4%），与手算一致；
- `binom.test(47, 200)$conf.int` 给出 ≈ `(0.178, 0.300)`，即（17.8%，30.0%）。$n=200$ 时两者只差一点点，说明大样本下正态近似足够用；
- 45 例中 2 例那次，正态近似法的下限算出来是**负数**（≈ −1.6%），这时按规矩要把下限写为 0，但更正确的做法是直接换方法：`binom.test(x = 2, n = 45)$conf.int` 给出 ≈ `(0.005, 0.152)`，即（0.5%，15.2%），与查表法得到的（1%，15%）量级一致（附表按整数百分比列印，把 0.54% 记作 1%）。

这里也能看出 `binom.test()` 和教材附表的关系：**附表就是精确法的表格版**，`binom.test()` 是它的计算版，而 `p + c(-1,1)*qnorm(0.975)*sp` 是它的近似版。条件满足时三者接近，条件不满足时只有精确法靠得住。

### 4 罕见事件的计数：Poisson

```r
# 精确法：总计数 X = 8
poisson.test(8)$conf.int

# 大计数可用正态近似：X ± 1.96√X
X <- 360
X + c(-1, 1) * 1.96 * sqrt(X)
poisson.test(360)$conf.int
```

输出怎么读：

- `poisson.test(8)$conf.int` ≈ `(3.45, 15.76)`，与查表得的（3.4，15.8）一致；
- $X=360$ 时正态近似给（322.8，397.2），精确法给 ≈（323.8，399.2），两者很接近——**总计数大时正态近似没问题，总计数小时一定用精确法**；
- 若原始数据是「每单位计数」的多次观测（$n$ 个观察单位），要先把总计数 $X$ 查区间再除以 $n$，或者直接用 `poisson.test(sum(v))` 之后再除以 $n$。

### 5 两总体均数之差

```r
x <- iris$Sepal.Length[iris$Species == "setosa"]
y <- iris$Sepal.Length[iris$Species == "versicolor"]

# R 默认 Welch 法（不要求方差齐），给出差值的 95% 可信区间
t.test(x, y)$conf.int

# 手算方差齐（合并方差）版本
n1 <- length(x); n2 <- length(y)
sc2 <- ((n1 - 1) * var(x) + (n2 - 1) * var(y)) / (n1 + n2 - 2)   # 合并方差
sed <- sqrt(sc2 * (1/n1 + 1/n2))                                  # 差的标准误
(mean(x) - mean(y)) + c(-1, 1) * qt(0.975, n1 + n2 - 2) * sed

# var.equal = TRUE 与手算一致；用它可以强制合并方差法
t.test(x, y, var.equal = TRUE)$conf.int
```

输出怎么读：

- 手算与 `var.equal = TRUE` 都给出 ≈ `(-1.105, -0.755)`，与前面核心概念里手算的结果一致：setosa 比 versicolor 平均短约 0.93 cm，这个差值不为 0；
- `t.test(x, y)` 默认用 Welch 校正，$\nu$ 不是整数（这里 ≈86.5），区间 ≈ `(-1.106, -0.754)`。本例如两组样本量相等，两种算法差不到 0.001；**样本量不等或方差不齐时差别会明显**，报告结果时要说清楚用的是哪一种；
- 顺序很重要：`t.test(x, y)` 的区间是 $\mu_{\text{setosa}}-\mu_{\text{versicolor}}$，反过来写 `t.test(y, x)` 区间就整体变号。看区间**含不含 0、正负方向**，别只看数字大小。

### 6 两总体率之差

```r
x1 <- 47; n1 <- 200
x2 <- 30; n2 <- 180

p1 <- x1 / n1
p2 <- x2 / n2
se <- sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)

# 两样本率之差的标准误：两组各自的标准误平方相加再开方
(p1 - p2) + c(-1, 1) * qnorm(0.975) * se
```

输出是 ≈ `(-0.012, 0.148)`，即（−1.2%，14.8%）。区间包含 0，说明还不能认为两组总体率不同——这个判断与用假设检验（卡方检验、两样本率比较的 u 检验）得到「P>0.05」是一致的。

> 注意两件事的差别：**做区间估计时用的是两组各自的样本率**（$p_1(1-p_1)/n_1+p_2(1-p_2)/n_2$）；而做假设检验（$H_0:\pi_1=\pi_2$）时，因为假定两总体率相等，会把两组数据合并成 $p_c=(X_1+X_2)/(n_1+n_2)$，标准误写 $\sqrt{p_c(1-p_c)(1/n_1+1/n_2)}$。两者目的不同，公式不同，别混用。

### 7 区间和检验结论对不对得上

```r
x <- iris$Sepal.Length[iris$Species == "setosa"]

# 检验 H0: mu = 5.0
t.test(x, mu = 5.0)$conf.int    # 区间 (4.906, 5.106) 包含 5.0
t.test(x, mu = 5.0)$p.value     # P ≈ 0.90 > 0.05：不拒绝 H0

# 检验 H0: mu = 5.8
t.test(x, mu = 5.8)$conf.int    # 还是 (4.906, 5.106)，不含 5.8
t.test(x, mu = 5.8)$p.value     # P 远小于 0.05：拒绝 H0
```

输出怎么读：**两次调用算出的可信区间完全相同**——因为可信区间是「数据算出来的」，与 $H_0$ 无关；变的只是拿哪个假设值去和它比。$H_0$ 的取值落在区间内 → P 大于 $\alpha$；落在区间外 → P 小于 $\alpha$。这就是「可信区间可以回答假设检验问题」的操作版。

### 8 缺失值：算标准误前先想清楚

```r
# airquality$Ozone 有缺失值（NA）
mean(airquality$Ozone)                       # NA —— 直接算会全军覆没
mean(airquality$Ozone, na.rm = TRUE)         # ≈ 42.13
x <- na.omit(airquality$Ozone)               # 更稳妥：先把缺失值去掉
mean(x) + c(-1, 1) * qt(0.975, length(x) - 1) * sd(x) / sqrt(length(x))
```

输出怎么读：$n=116$（原始 153 行里有 37 个缺失），$\bar{X}\approx42.13$，$S\approx32.99$，$S_{\bar{X}}\approx3.06$，95% 可信区间 ≈（36.1，48.2）。

两处细节：`na.rm = TRUE` 与 `na.omit()` 都把缺失值排除，但**删掉多少个观测会改变 $n$，也就改变了标准误和自由度**，报告里必须写清实际分析的例数；另外臭氧浓度分布明显右偏，样本量只有 116，用它做正态近似的区间估计时要留个心眼——先画图看分布，必要时做变量变换。

## 容易踩的坑

- **把标准差当标准误（或反过来）写进结论。** 「该地成年男性心率的平均水平为 78.82±9.58 次/分」用错了：9.58 是**个体之间**的变异，要说总体均数的估计精度，必须写 $S/\sqrt{n}=0.8245$。判断方法：和「总体均数」「估计」有关的用标准误，和「参考值范围」「个体是否正常」有关的用标准差。
- **以为「样本一大就必须丢掉 t 分布」，或者把公式的分母记错。** 恰恰相反：$\sigma$ 未知时**无论 $n$ 多大都可以用 t 分布法**（$\bar{X}\pm t_{\alpha/2,\nu}S_{\bar{X}}$），$n$ 大时它和 $u$ 分布法结果几乎相同，只是 t 更确切，「$n>50$ 就换成 1.96」只是手算的方便做法。另外 $\sigma_{\bar{X}}=\sigma/\sqrt{n}$，**不是** $\sigma/n$；单样本 t 的自由度是 $n-1$，两样本合并方差时是 $n_1+n_2-2$；估计 $\sigma$ 用的 $S$ 分母是 $n-1$。
- **把可信区间的含义说反。** 随机的是区间不是参数，所以不能说「总体均数有 95% 的概率落在（77.20，80.44）内」；正确说法是「该区间包含总体均数，可信度为 95%」。另外，**可信区间不是参考值范围**：前者关于总体均数、用标准误，后者关于个体、用标准差。
- **小样本、$p$ 接近 0 或 1 时硬套正态近似法。** 条件是 $np$ 与 $n(1-p)$ **都大于 5**；不满足就用查表法（或 `binom.test()`）。算出来下限为负、上限超过 100% 就是条件不满足的信号，此时把它截断成 0% 只是补救，换方法才是正解。
- **比较两组时的两个经典错误。** 一是**忘了看区间是否包含 0**：两总体均数之差、率之差的区间，含 0 = 尚不能认为有差别；还要看区间的方向和宽度，宽度很宽的「有差别」通常意味着样本量不足。二是**把估计和检验的标准误混用**：两样本率之差做**区间估计**用两组各自率的 $S_{p_1-p_2}$，做**假设检验**（$H_0:\pi_1=\pi_2$）用合并率 $p_c$ 算标准误，两者公式不一样。

## 小结

1. **样本统计量不能直接当总体参数。** 抽样误差由个体变异加抽样造成，不可避免但有规律；描述它的量是**标准误**。标准误不是标准差：标准差说个体之间的变异（用于参考值范围），标准误说样本均数的变异（用于参数估计与假设检验）。$S_{\bar{X}}=S/\sqrt{n}$ 与 $S$ 成正比、与 $\sqrt{n}$ 成反比，所以**减小抽样误差只能靠增大样本量**。
2. **t 分布是 $\sigma$ 未知时的补救，也是总体均数可信区间的依据。** $t=\dfrac{\bar{X}-\mu}{S/\sqrt{n}}$ 服从自由度 $\nu=n-1$ 的 t 分布：单峰、左右对称、$\nu$ 越小尾部越高，$\nu\to\infty$ 时趋于标准正态分布；查表要分清单侧 $t_{\alpha,\nu}$ 与双侧 $t_{\alpha/2,\nu}$。总体均数的 95% 可信区间为 $\bar{X}\pm t_{0.05/2,\nu}S_{\bar{X}}$，其中 $S_{\bar{X}}$ 是标准误、$\nu=n-1$；$\sigma$ 已知时用 $\bar{X}\pm1.96\sigma_{\bar{X}}$，$\sigma$ 未知但样本大时可用 $\bar{X}\pm1.96S_{\bar{X}}$ 近似。它的含义是「该区间包含总体均数，可信度 95%」，不是「参数有 95% 概率落在里面」，也不是参考值范围；可信度与精确性要兼顾。
3. **总体率的可信区间**分两法：$n$ 较小（如 $n\le50$）或 $p$ 接近 0/1 时用**查表法**（$n=45$、$X=2$ 得（1%，15%））；$np$ 与 $n(1-p)$ 均大于 5 时用**正态近似法** $p\pm u_{\alpha/2}S_p$，$S_p=\sqrt{p(1-p)/n}$，下限算成负数就截断为 0 并意识到这提示样本量不足。罕见事件计数服从 **Poisson 分布**（均数等于方差、具有可加性），总计数 $X>50$ 时用 $\frac{1}{n}(X\pm1.96\sqrt{X})$，$X\le50$ 时查表。
4. **两总体之差**用「差值 ± 倍数 × 差的标准误」：均数之差用合并方差 $S_c^2$ 与 $t_{\alpha/2,n_1+n_2-2}$（方差不齐时用各自方差与校正自由度）；率之差用 $\sqrt{p_1(1-p_1)/n_1+p_2(1-p_2)/n_2}$ 与 $u_{\alpha/2}$。**区间含 0 就不能认为两组有差别。**
5. **区间估计与假设检验相辅相成。** 双侧检验时，$1-\alpha$ 可信区间含不含 $H_0$ 的取值，与 $P$ 值和 $\alpha$ 的比较结论完全一致；可信区间还额外给出差别的**大小与方向**，能判断有没有实际意义，所以报告结论时应当一并给出。
