# 原题 / 答案 / 汇总 修改记录

这份文件记录了 2025 年对 `原题`、`答案`、`汇总` 三个目录所做的**全部文字性修改**。
改动范围仅限**错别字、笔误**，以及应作者要求**移除地图题**；题目内容、数据、
代码逻辑一律未动。

修改方式：`.docx` 走脚本做定点文本替换（只改 `word/document.xml` 里的文字，
样式/图片/公式对象原样保留），改完做过结构校验——除正文文字外，
其余条目与原文件**逐字节一致**。
