# 第 4 章　病例对照研究

> 队列研究是「先分因、再等果」，问题是**等不起**——罕见病要随访几十万人年。病例对照研究把方向倒过来：**先找病人，再回头问他过去暴露过什么**。代价是拿不到发病率，只能用 OR 估计关联。

## 这一章要解决什么

设想一个具体困难：某医院一年收治了 30 例某种罕见肿瘤。发病率大约是十万分之二。
要用队列研究验证某个可疑因素，得先找几十万暴露者和非暴露者，随访十年——**几乎不可能**。

于是换个思路：既然病人已经在手上，就**从病人出发往回看**。

- 病例组：这 30 个确诊的病人；
- 对照组：从同一来源找一批**没得这个病**、但其他条件可比的人；
- 然后分别追问两组**过去**有没有那个暴露，比一比两组的暴露比例。

如果病例组的暴露比例明显高于对照组，就提示这个暴露可能与疾病有关。
这就是病例对照研究，也叫**回顾性研究**（retrospective study）。

它换来的是**快、省、能研究罕见病**；付出的是**拿不到发病率**——所以只能算 **OR**，不能算 RR。

## 核心概念

### 定义

> **病例对照研究**（case-control study）是按研究对象**是否患有所研究的疾病**分为病例组和对照组，
> 分别**追溯**各组人群**既往**研究因素的暴露情况，并比较其差异，
> 从而推测暴露因素与疾病之间**有无关联及关联强度**的一种**观察性**研究。

三个关键词：**按结局分组**、**回顾性追溯暴露**、**观察性**（不施加干预）。

### 基本原理与方向

```
              ← 过去         现在
病例组    暴露 / 非暴露   ←  患所研究疾病与否
对照组    暴露 / 非暴露   ←  未患病
                    ↑
              比较两组的暴露率
```

**研究方向是「由果溯因」**：从现在的结局出发，回头看过去的暴露。
这和队列研究正好相反，也是它**不能确定因果关系**的根本原因——**时间顺序不如队列研究可靠**。

### 基本特点

| 特点 | 含义 |
| --- | --- |
| **观察性** | 不施加任何干预 |
| **按结局分组** | 研究对象分为病例组、对照组 |
| **回顾性** | 追溯既往暴露史 |
| **由「果」→「因」** | 方向与队列研究相反 |
| **无法确定因果关系** | 疾病和暴露在研究开始时**都已存在**，先后顺序靠回忆确定 |

### OR 为什么不能代替 RR

这是本章最核心的一点：

| | 队列研究 | 病例对照研究 |
| --- | --- | --- |
| 分组依据 | 暴露与否 | **患病与否** |
| 能算发病率吗 | **能**（有真实分母） | **不能**（病例和对照的人数由研究者定死） |
| 关联指标 | RR、AR、AR%、PAR、PAR% | **只能算 OR** |

病例组和对照组各取多少人，是**研究者自己定的**，不是人群中自然形成的比例。
分母既然是人造的，发病率就无从谈起，RR 自然也就算不出来。
能算的只有「**优势比**」——因为它是组**内部**的比值，不受两组人数比例影响。

## 用途

1. **疾病病因或危险因素的研究** —— 最主要用途，尤其适合**罕见病**、**原因未明疾病**；
2. **健康相关事件影响因素的研究**；
3. **疾病预后因素的研究**；
4. **影响临床疗效的因素研究**。

> 因为「一次研究可以同时分析多个因素与一种疾病的关系」，它非常适合**探索**——
> 把能想到的可疑因素都问一遍，先筛出有信号的，再用队列研究去验证。

## 研究类型

### 两大类

| 类型 | 别称 | 特点 |
| --- | --- | --- |
| **非匹配** | 成组病例对照研究 | 对照组不与病例个别配对，只要求成组可比 |
| **匹配** | 配比研究 | 按某些因素使对照组与病例组保持一致；又分**频数匹配**与**个体匹配** |

### 衍生的四种类型

| 类型 | 基本思路 |
| --- | --- |
| **巢式病例对照研究**（nested case-control） | 在一个已经建好的队列里，把随访中发病的人作病例，从同一队列未发病者中抽对照 |
| **病例-队列研究**（case-cohort） | 从队列里随机抽一个子队列作对照，与所有病例比较 |
| **病例-病例研究**（case-case） | 只比较病例之间的亚型，找不同亚型的危险因素 |
| **病例交叉研究**（case crossover） | 同一个体「发病前的一段」与「更早的一段」自身比较，适合**短暂暴露**的急性事件 |

> 巢式和病例-队列研究是「队列里套病例对照」——**既省了检测成本，又保留了队列的分母信息**，
> 所以它们其实能算出接近 RR 的量（这已在标准课程之外，了解即可）。

## 匹配：最容易做错的一步

**匹配**（matching，又称配比）是以对研究结果有干扰作用的因素或特征作为**匹配因素**，
使对照组和病例组在匹配因素上**保持一致**，以排除匹配因素的干扰。

### 匹配的目的

1. **提高研究（统计）效率** —— 同等样本量下检验效能更高；
2. **控制混杂因素** —— 把已知的混杂因素人为拉平。

### 分类

| 方式 | 做法 |
| --- | --- |
| **频数匹配**（成组匹配） | 只要求两组在匹配因素上的**分布**一致（如年龄构成相同），不逐个配对 |
| **个体匹配** | 给每个病例配 1 个或多个条件相同的对照（1:1、1:R） |

### 四条注意事项（都是考点）

::: warning 匹配的四条铁律
1. **慎重选择匹配因素** —— 匹配的因素越多，能研究的因素越少，找对照也越难。
2. **可疑病因绝对不能作为匹配因素** —— 一旦匹配，这个因素的效应就被你**人为抹平**了，
   再也研究不出来。这是最致命的错误。
3. **匹配比例最多不超过 1:4** —— 对照超过 4 个以后，统计效率提升很有限，但工作量和成本陡增。
4. **避免「匹配过头」（overmatching）** —— 把与疾病无关、或处于因果链中间环节的因素也拿来匹配，
   会白白损失信息、降低效率。
:::

> 一句话记法：**匹配是用来「消掉」干扰因素的，不是用来「消掉」你要研究的因素的。**

## 设计与实施

### ① 确定研究目的与类型

目的要明确，再据此选类型：

| 目的 | 建议类型 |
| --- | --- |
| 广泛地探索疾病的危险因素 | 非匹配或频数匹配 |
| 检验病因假设 | 个体匹配 |
| 开展罕见病的小样本研究 | 个体匹配 |
| 病例在年龄、性别构成上特殊，随机抽样难与病例组均衡 | 1:R 个体匹配 |

### ② 确定研究因素

包括**明确的病因因素**、**可疑的病因因素**、**可能的混杂因素**。
每项都要有**明确而具体的判定标准**，尽量采用国际或国内统一的标准。

### ③ 确定研究对象

#### 病例的选择

**两条原则**：

- **代表性** —— 病例要能代表目标人群中该病的全体患者；
- **诊断明确** —— 患病部位、病理学类型、诊断标准要明确限制；对外部特征（年龄、性别、种族、职业）也要明确限制。

**三种病例种类**（优先顺序很重要）：

| 种类 | 评价 |
| --- | --- |
| **新发病例** | **首选** —— 信息丰富又准确，回忆偏倚小 |
| **现患病例** | 受疾病迁延及**存活因素**影响（病程长的人更容易被选进来） |
| **死亡病例** | 信息准确性较差（只能由家属代答） |

**两种来源**：

| 来源 | 名称 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **医院** | 以医院为基础的病例对照研究 | 简便、易行、信息量高 | 只反映该机构病人特点，**易发生选择偏倚（入院率偏倚）** |
| **社区** | 以社区为基础的病例对照研究 | 代表性好 | 获取资料难 |

#### 对照的选择

**五条原则**：

1. 诊断标准与病例相同，**明确排除该病**；
2. 有**代表性**；
3. 与病例有**可比性**；
4. **对照组不应与所研究疾病的病因相同**（否则会把效应掩盖掉）；
5. 可同时选择两个以上的对照。

**三种常见来源**：

- **医院中患有其他疾病的病人** —— 方便、应答好，但要注意「其他疾病」不能与所研究的暴露有关；
- **来自社区人群** —— 总体人群或抽样人群中具有代表性的非病例，代表性最好；
- **邻居、亲属配偶、同事同学** —— 在**社会经济地位、居住环境**上天然可比，但要注意
  亲属可能有共同遗传背景、配偶可能有共同生活习惯（**过度匹配**风险）。

### ④ 确定样本量

四个影响因素：

| 因素 | 说明 |
| --- | --- |
| **对照组暴露率 $p_0$** | 暴露越少见，需要的样本越大 |
| **预期 OR** | 关联越弱，需要的样本越大 |
| **检验水平 $\alpha$** | 一般取 0.05；$\alpha$ 越小，样本越大 |
| **检验效能 $1-\beta$** | $\beta$ 为第二类错误的概率，一般取 $\beta = 0.10$（即效能 90%） |

估计方法分**成组比较**与**个体匹配**两种：成组比较的公式与队列研究相同
（只是 $p_1$、$p_0$ 的含义变成**病例组与对照组的暴露率**）；
个体匹配则要先估计**不一致的对子数**，再推算总对子数。

### ⑤ 资料收集

**方式**：询问、体检、生物标志物检测、职业或其他记录等。

**三条注意事项**（都是为了减少信息偏倚）：

1. 病例与对照使用**相同的调查问卷**；
2. 调查人员要**统一培训**；
3. 调查过程中对待病例与对照的**态度应一致**。

## 资料整理与分析

### 第一步：均衡性检验

比较某些**非研究因素**（年龄、性别等）在病例组和对照组是否齐同或相似，
目的是检验两组的**可比性**。

如果确实不可比，在推断性分析时就要考虑它对结果的影响并予以**控制**（分层、多因素分析）。

### 第二步：成组资料的四格表

| | 病例组 | 对照组 | 合计 |
| --- | --- | --- | --- |
| **暴露** | $a$ | $b$ | $a+b$ |
| **非暴露** | $c$ | $d$ | $c+d$ |
| 合计 | $a+c$ | $b+d$ | $n$ |

先做 **$\chi^2$ 检验**：若两组暴露率差异有统计学意义，说明暴露与疾病**有关联**。

### 第三步：OR 及其意义

$$\text{OR} = \frac{\text{病例组的暴露优势}}{\text{对照组的暴露优势}} = \frac{a/c}{b/d} = \frac{ad}{bc}$$

**OR 的解读与 RR 平行**：

| OR | 含义 |
| --- | --- |
| $\text{OR} > 1$ | **正关联**：暴露越多，发病危险性越大，暴露是**危险因素** |
| $\text{OR} < 1$ | **负关联**：暴露越多，发病危险性越小，暴露是**保护因素** |
| $\text{OR} = 1$ | **无关联** |

取值在 $0 \sim \infty$ 之间。**含义与 RR 相同**：都指暴露组的疾病危险性为非暴露组的多少倍。

### 第四步：OR 的 95% 可信区间

样本 OR 只是总体 OR 的点估计，受抽样误差影响，要给出可信区间（常用 **Miettinen 法**或 **Woolf 法**）：

- **区间不包含 1** → 关联有统计学意义；
- **区间包含 1** → 即使样本 OR 不等于 1，也**不能说明**暴露与疾病有关联。

> 这是报告 OR 时必须配的一句话。只报一个「OR = 2.5」而不给区间，等于没报告。

### 第五步：1:1 个体匹配资料

个体匹配的资料**不能按成组资料处理**，要单独列配对四格表（按「病例暴露 / 对照暴露」配对统计），
用配对 $\chi^2$（McNemar）检验，OR 的算法也变成「**不一致对子**的比值」：

$$\text{OR} = \frac{b}{c} \quad (\text{$b$、$c$ 为两种不一致的对子数})$$

这和第 14 讲「同分布检验与列联表检验」里的配对资料是同一套逻辑。

## 优点与局限

### 优点

1. **适用于罕见病、原因未明疾病的病因研究** —— 这是它最大的价值；
2. **需要样本量较少，节省人力、物力、时间，易于组织实施**；
3. **一次研究可以同时分析多个因素与某种疾病的关系** —— 适合探索；
4. **可以应用于疾病的病因、诊断、治疗、预防、预后等方面**。

### 局限

1. **不适于人群中暴露率很低因素的研究**（暴露太少见，病例组里也凑不出几个）；
2. **产生偏倚的机会多** —— 回忆偏倚、选择偏倚、入院率偏倚……（见第 5 章）；
3. **难以确定疾病与暴露的时间先后顺序，不能确定因果关系**；
4. **不能计算发病率、死亡率**，只能用 OR 估计关联强度。

## 队列研究 vs 病例对照研究（全维度对照）

| 方法特点 | 前瞻性队列研究 | 病例对照研究 |
| --- | --- | --- |
| **样本组成** | 无该病的个体 | 病例与对照 |
| **分组标准** | 暴露与否 | **患所研究疾病与否** |
| **时间顺序** | 前瞻性（由因及果） | 回顾性（由果溯因） |
| **因果关系** | **可以确定** | **不能确定** |
| **比较内容** | 发病与死亡情况 | **暴露情况** |
| **计算指标** | 发病率或死亡率 | **暴露率** |
| **联系强度** | RR、AR、PAR、AR%、PAR% | **OR** |
| **适用疾病** | 常见病 | **罕见病** |
| **样本量** | 大 | 小 |
| **耗时/花费** | 长、贵 | 短、省 |
| **偏倚机会** | 较少（主要是失访偏倚） | 较多 |

> 一句话总结：**队列研究「贵而硬」，病例对照研究「快而软」**。
> 实际研究中常见做法是：先用病例对照**筛线索**，再用队列研究**下结论**。

## 常见误区

::: warning 六个高频错误
- **从病例对照研究里算 RR。** 病例组和对照组的例数由研究者定死，真实发病率无从得知，**只能报 OR**。
- **把 OR 当 RR 读。** 结局不罕见时 OR 会**夸大**效应（见 [第 3 章](./03-cohort) 与
  [卫生统计学 第 12 章](/Health-statistics/12-bivariate-association)）。
- **把可疑病因拿去匹配。** 这是**不可逆**的错误——匹配之后这个因素就再也研究不了了。
- **病例组全用现患病例。** 病程长、存活久的人更容易被选进来，
  如果暴露恰好与生存有关，结果就被系统性地带偏（**现患—新发病例偏倚**）。
- **用医院对照却不考虑入院率。** 医院里不同疾病的入院率不同，
  两组在「住院机会」上本来就不可比（**入院率偏倚**）。
- **配对资料当成组资料算。** 1:1 匹配的资料有配对信息，用普通 $\chi^2$ 检验等于把它整个丢掉。
:::

## 小结

1. **病例对照研究按结局分组、回顾性追溯暴露**，方向是由果溯因，属观察性研究。
2. 因为**分母是人造的**，所以**只能算 OR，不能算 RR**，也**不能确定因果**。
3. 最大价值是**研究罕见病**，快、省、可同时分析多个因素。
4. **匹配**是为了控制混杂、提高效率，但**可疑病因绝不能匹配**，比例不超过 1:4，防止匹配过头。
5. OR $>1$ 正关联、$<1$ 负关联、$=1$ 无关联；**必须给出 95% 可信区间**。
6. 与队列研究的关系：队列由因及果、能算 RR、贵而硬；病例对照由果溯因、只能算 OR、快而软。
