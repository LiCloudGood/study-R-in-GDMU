# 第 6 章　病因与因果推断

> 上一章解决了「怎么把偏倚排掉」。排掉之后，剩下的那个关联就能叫「因果」了吗？**还不能。** 这一章给出两套判断工具：**Mill 准则**（怎么从现象里推原因）和 **Hill 准则**（怎么判断一个关联够不够格算因果）。

## 这一章要解决什么

两个真实的研究结论放在你面前：

1. 「吸烟者肺癌发病率是不吸烟者的 10 倍」；
2. 「冰淇淋销量高的月份，溺水死亡也多」。

两个都是**统计上显著的正相关**，但一个能说因果，一个不能。
差在哪里？——**时间顺序**（吃冰淇淋在溺水之前吗？不，两者都被「气温」带着走）、
**生物学合理性**（吸烟有致癌机制，冰淇淋没有）、**剂量-反应**（烟越多风险越高，冰淇淋吃多了也不会更容易溺水）……

所以「相关 ≠ 因果」不是一句正确的废话，它背后有一套**可以逐条检查的标准**。
这一章要讲的，就是这套标准怎么来、怎么用、边界在哪。

## 一、病因的定义

> 流行病学的病因一般称为**危险因素**（risk factor），
> 含义就是使疾病发生概率即风险（risk）升高的因素。

但「相关」还不够，定义里还带了两个限定条件：

1. **必须确定该危险因素发生于疾病之前** —— 时间顺序不能反；
2. **「升高的概率」未受到其他因素的干扰** —— 也就是已经把混杂、偏倚排掉了。

> 这两条限定，正好对上了上一章和这一章的关系：
> **第 5 章负责「排除干扰」，第 6 章负责「判断因果」。**

## 二、病因模型

病因模型是「用来组织我们对病因的想象」的框架。课程讲了三个阶段/三类模型：

### 01 生态学模型

把**机体与环境作为一个整体**来考虑，是流行病学最经典的病因观。

#### 流行病学三角

```
            宿主（Host）
              /\
             /  \
            /    \
     动因（Agent）—— 环境（Environment）
```

- **宿主**：人（或动物），含遗传、免疫、营养、行为等；
- **动因**：致病因子（生物、化学、物理）；
- **环境**：使动因得以作用于宿主的外部条件。

三者必须**同时存在并相互作用**才会发病。任何一角改变，都可能打破平衡。

#### 轮状模型

```
        ┌───────────────┐
        │   生物环境     │
        │   ┌───────┐   │
        │   │ 宿主  │   │
        │   │ ┌───┐ │   │
        │   │ │遗传│ │   │   ← 内核
        │   │ └───┘ │   │
        │   └───────┘   │
        │  社会环境 理化环境│
        └───────────────┘
```

轮状模型把**宿主放在中心**，外面套着**遗传内核**与**环境**（生物环境、社会环境、理化环境）。
它比三角模型更强调「宿主自身的遗传素质」和「多层次的环境」。

> **两者的区别一句话**：三角模型把宿主、动因、环境**并列**；
> 轮状模型把宿主放**中心**，环境**环绕**四周，并区分了遗传内核。

### 02 病因因素模型（近因 / 远因）

把病因按**离疾病的远近**分层：

```
经济社会因素 ┐
生物学因素   │
环境因素     ├→ 医学生物学因素（机制）→ 疾病
心理、行为因素│
卫生保健因素 ┘
```

- **远因**：社会经济、文化、政策等**上游**因素；
- **近因**：直接作用于机体的**下游**因素（如血压、血糖、血脂）。

这个模型的价值在于：**干预远因影响面大但见效慢，干预近因见效快但治标**。

### 03 病因网络模型（病因链 / 病因网）

#### 病因链

原因一个接一个，串成一条链：

```
 globalization ┐
 城市化        ├→ 合理膳食 / 少体力活动 / 吸烟
 人口老龄化    ┘        ↓
                    高血压 / 高血糖 / 超重肥胖
                          ↓
                  冠心病 / 糖尿病 / 肺癌
```

（上图就是「远因 → 中间病因 → 近因 → 疾病」的链条）

#### 病因网

现实中原因往往不是一条链，而是**互相交织的网**：吸烟、饮酒、饮食、体力活动、
体重指数、血压、血脂之间互相影响，共同指向冠心病、脑卒中、动脉粥样硬化。

> **病因网的意义**：它解释了为什么「单因素分析」常常不够——
> 一个因素的作用可能要通过网中的多条路径传导，也可能被其他路径抵消。

## 三、病因类型

按「在因果中扮演什么角色」分：

| 类型 | 含义 |
| --- | --- |
| **必要病因** | 疾病**必然**有它；没有它一定不发病（如结核杆菌之于结核病） |
| **充分病因** | 有它就**足以**发病（往往是多个因素组合成的一个完整集合） |
| **危险因素** | 增加发病概率，但既不必要也不充分（如吸烟之于肺癌） |
| **直接病因 / 间接病因** | 按离疾病的远近分 |

> 关键认识：**大多数慢性病没有单一的「必要且充分」病因**。
> 所以现代流行病学更多用「危险因素」这个概念，
> 用**概率**而不是「有/无」来表述因果。

## 四、病因研究的基本方法

三类研究对应三步走，每一步的任务不同：

| 研究类型 | 具体方法 | 任务 |
| --- | --- | --- |
| **描述性研究** | 现况调查、病例报告、生态学研究 | **建立**病因假说 |
| **分析性研究** | 病例对照研究、队列研究 | **检验**病因假说 |
| **实验性研究** | 临床试验、现场试验、社区试验 | **验证**病因假说 |

> 注意用词：**建立 → 检验 → 验证**，力度逐级增强。
> 描述性研究只能「提出」，分析性研究能「检验」，只有实验研究能「验证」。

## 五、因果推断的逻辑方法：Mill 准则

Mill（穆勒）准则是一套**从现象归纳原因**的逻辑方法，分两条路径：
**假设演绎法**与 **Mill 准则**（求同法、求异法、共变法、类推法、排除法）。

### 五法及流行病学例子

| 方法 | 逻辑 | 课上的例子 |
| --- | --- | --- |
| **求同法** | 不同场合都发病，**共同点**就是可疑原因 | 肝癌病例(A)均有乙肝感染(x) |
| **求异法** | 有该因素者发病、无该因素者不发病 | 非肝癌个体（非 A）均无乙肝感染（无 x） |
| **共变法** | 因素**量变**引起疾病**率变** | 随着吸烟(x)量的增加，发生肺癌(A)的危险性也增加 |
| **类推法** | 甲病已知由某因素引起，乙病表现与甲病相似，推测同一因素 | 动物的白肌病由缺硒(x)所致，克山病(A)的病理变化与白肌病一致 |
| **排除法** | 已排除已知原因后，**剩余的**部分归因于新因素 | 肝癌(A)除病毒和黄曲霉毒素能解释的部分外，剩余部分可归因于其他因素，如饮水中的蓝绿藻毒素 |

### Mill 准则与流行病学研究设计的对应

这张对应表很值得记——**逻辑方法其实就藏在研究设计里**：

| Mill 准则 | 对应的流行病学研究设计 |
| --- | --- |
| **求同法** | **病例系列**：找出病人**共有的**因素 |
| **求异法** | **病例对照**：病人有、非病人缺的因素 |
| **类推法** | **描述性研究、实验研究** |
| **共变法** | **剂量-效应关系**的分析 |
| **剩余法** | **个案发生原因的推测**、主要病因的推测 |

### Mill 准则的四点不足

::: warning 为什么不能只靠 Mill
1. **没有考虑收集的原始研究是否全面和完整** —— 前提错了，推理再漂亮也没用；
2. **对原始研究证据的真实性（方法学）没有考评** —— 不管证据质量，一视同仁；
3. **未区分「研究内」以及「研究间」提供的信息** —— 把不同来源的证据混在一起；
4. **对「一致性」没有量化的界定，很难判断** —— 「一致」到什么程度算一致？说不清。
:::

> 正因为这四条不足，才需要下一节的 Hill 准则来做**更细的判断**。

## 六、因果关系的推断

### （一）统计学关联

> 暴露因素与疾病之间存在统计学关联，**只是排除了偶然，不一定存在因果关系。**

这一步能排除的只有**随机误差**（机遇）。P 值小，说明「不太可能是碰巧」，
但**完全没有涉及**偏倚、混杂、时间顺序。

### （二）从中介关联到真实关联：一层层排除

判断因果是一条**逐级筛除**的路：

```
      观察到的关联
           │
   排除机遇关联（随机误差）
           ↓
      有统计学关联
           │
   排除虚假关联（选择偏倚、测量偏倚）
           ↓
       继发关联
           │
   排除间接关联（混杂偏倚）
           ↓
      真实关联（因果推断）
```

| 要排除的 | 靠什么 |
| --- | --- |
| **机遇关联** | 统计检验（P 值、可信区间） |
| **虚假关联** | 良好的设计（抽样、测量、盲法）—— 见第 5 章 |
| **间接关联** | 分层、标准化、多因素分析 —— 见第 5 章 |

> 走完这条路剩下的「真实关联」，才有资格进 Hill 准则去评判。

### （三）因果关联的推断标准：Hill 准则

| # | 标准 | 含义 | 地位 |
| --- | --- | --- | --- |
| 1 | **关联的时间顺序**（temporality） | 因必须先于果发生 | **必要条件** |
| 2 | **关联的强度**（strength） | 用来评价病因与疾病之间是否存在关联及关联强度的指标（RR、OR 等） | **必要条件** |
| 3 | **剂量-反应关系**（dose-response） | 疾病发生频度随可疑病因的强度或数量变化而变化 | **必要条件** |
| 4 | **可重复性**（repeatability） | 不同时间、地点、人群，不同研究者用类似方法获得相同结果的可能性 | 非常重要 |
| 5 | **实验证据**（experimental evidence） | 关于该关联的实验性研究证据 | 非常重要 |
| 6 | **生物学合理性**（plausibility） | 病因假设与现有一般生物医学事实、知识和理论相符合的程度 | 参考 |
| 7 | **生物学一致性**（coherence） | 同上，强调与整体知识体系的符合程度 | 参考 |
| 8 | **特异性**（specificity） | 病因与疾病之间关系的**排他性或特异程度** | 参考 |
| 9 | **相似性**（analogy） | 已存在确定的类似的病因—疾病关系，加强新关系的可能性 | 参考 |
| 10 | **预测力**（predictive performance，1991 年增加） | 用该理论提出对未来或过去的预测，再收集数据评估预测的正确性 | 参考 |

### （四）综合判断

> - **关联的时间顺序是必需满足的**；
> - **关联的强度、可重复性、剂量-反应关系及实验证据**有非常重要的意义；
> - 其他标准可作为参考。
> - 因果关系的判断中，**并不一定要求 10 条标准全部满足**。
>   **满足的条件越多，则因果关联成立的可能性越大。**

::: tip 三条「必要条件」最该记住
**时间顺序、关联强度、剂量-反应关系**——这三条在课上被明确标为「判断的必要条件」。

- **时间顺序**是底线：因果关系不能倒过来（这也是为什么队列研究比病例对照研究更有力）；
- **关联强度**（RR / OR 离 1 多远）说明效应大小；
- **剂量-反应关系**是最有说服力的一条：**暴露越多、结局越重**，很难用混杂解释。

而「特异性」这条在现代流行病学里已经被弱化——慢性病几乎都是多因多果，
要求「一个因素只导致一种病」过于苛刻（吸烟同时导致肺癌、冠心病、慢支）。
:::

## 常见误区

::: warning 六个高频错误
- **把「有统计学关联」当成「有因果」。** P < 0.05 只排除了偶然，没排除偏倚、混杂、时序倒置。
- **忽略时间顺序。** 横断面研究里暴露和结局同时测量，永远无法满足 Hill 的第 1 条。
- **把 Hill 准则当成打分表。** 它不是「满足 N 条就得 N 分」，而是**整体判断的参考框架**；
  课上明确说「不要求 10 条全部满足」。
- **死抠「特异性」。** 慢性病多为多因多果，特异性已不是必要条件。
- **只做 Mill 推理不做偏倚排除。** Mill 准则的四点不足正是它不能单独使用的原因。
- **把「危险因素」当成「必然致病」。** 危险因素只改变**概率**，不决定**个体结局**。
:::

## 小结

1. **病因 = 危险因素**：使发病概率升高，且必须**先于疾病**、**未受其他因素干扰**。
2. **三类病因模型**：生态学模型（流行病学三角、轮状模型）、病因因素模型（近因/远因）、
   病因网络模型（病因链/病因网）。
3. **四类病因概念**：必要病因、充分病因、危险因素、直接/间接病因。
4. **三类研究对应三步**：描述性**建立**假说 → 分析性**检验**假说 → 实验性**验证**假说。
5. **Mill 五法**：求同法、求异法、共变法、类推法、排除法；对应病例系列、病例对照、
   剂量-效应分析、描述/实验研究、个案推测。它**有四条不足**，不能单独用。
6. **Hill 准则十条**，其中**时间顺序、关联强度、剂量-反应**是**必要条件**；
   其余（可重复性、实验证据、生物学合理性/一致性、特异性、相似性、预测力）作参考。
   **满足越多，因果可能性越大**，但**不要求全满足**。
