# 诊断试验评价

> 前面各章处理的都是「组间比较」：两组均数差多少、两个率差多少。这一节换一个问题：**一个检查指标（或一台仪器、一套评分标准）到底有没有本事把病人和非病人分开？** 临床上这叫诊断试验评价。它要回答的是灵敏度、特异度、阈值定在哪儿、以及「这个指标换一个科室还准不准」。这些内容和《医学大数据分析与决策》第 6 周的分类评价是同一件事，只是那边从模型的混淆矩阵讲，这里从临床指标讲。

## 这个专题要解决什么

临床上每天在做判断：这个指标高到什么程度才叫「异常」？一个筛查试验说「阳性」，病人真的得病的可能性有多大？

**这两个问题必须分开看**，它们分别对应两类指标：

- **从「有没有病」出发看检查结果** → 灵敏度、特异度、似然比；
- **从「检查结果」出发猜有没有病** → 阳性预测值、阴性预测值。

前者描述**试验本身的性能**，跟人群无关；后者描述**在这群人里用它的结果**，跟患病率绑死。混为一谈是这一节最容易犯的错，下面会重点说。

::: tip 这一节不在课本的 19 章里
《卫生统计学》的 17 章没有把诊断试验评价单独列章，但临床上它用得非常频繁，本站把它补成专题。
方法本身是标准内容（ROC 分析、Delong 检验都是几十年的成熟方法），重点放在
**怎么算、怎么读、哪里容易读错**。
:::

## 核心概念

### 四格表：灵敏度和特异度

把「金标准」的诊断结果和待评价试验的结果交叉列表，就得到诊断试验的四格表：

| | 金标准：有病 | 金标准：无病 | 合计 |
| --- | --- | --- | --- |
| **试验阳性** | 真阳性 $TP$ | 假阳性 $FP$ | $TP+FP$ |
| **试验阴性** | 假阴性 $FN$ | 真阴性 $TN$ | $FN+TN$ |
| 合计 | $TP+FN$ | $FP+TN$ | $N$ |

- **灵敏度**（sensitivity，真阳性率）：

$$Se=\frac{TP}{TP+FN}$$

  分母是**所有真正有病的人**。灵敏度 0.80 的意思是：100 个病人里，这个试验能查出 80 个。
  $1-Se$ 叫**假阴性率**，也就是漏诊率。

- **特异度**（specificity，真阴性率）：

$$Sp=\frac{TN}{TN+FP}$$

  分母是**所有真正没病的人**。特异度 0.90 的意思是：100 个没病的人里，90 个会被判为阴性。
  $1-Sp$ 叫**假阳性率**，也就是误诊率。

这两个数的分母**都是按真实病情分的**，所以它们**不随患病率变化** —— 这是它们最大的优点，也是它们最大的局限。

::: tip 灵敏度、特异度的方向别搞反
一个数描述的是**有病的那一列**（$Se$），另一个描述的是**没病的那一列**（$Sp$）。
记忆的办法：**灵敏度看病人漏没漏，特异度看健康人冤没冤**。
两者往往此消彼长：阈值调低 → 阳性的人变多 → 灵敏度上去了、特异度下来了。
:::

### 约登指数：一个数概括「分得开不开」

阈值一动，$Se$ 和 $Sp$ 就一升一降，光看两个数不好比较。**约登指数**（Youden index）把它们合成一个：

$$J = Se + Sp - 1 = Se - (1-Sp)$$

它等于**真阳性率减假阳性率**，取值在 $-1$ 到 $1$ 之间（实际用在 0 到 1）。$J=0$ 意味着这个试验跟瞎猜没区别；$J$ 越大，越能把两组人分开。

:::: info 约登指数和 ROC 上的一点是对应的
ROC 曲线的横轴是 $1-Sp$、纵轴是 $Se$，所以 $J = Se-(1-Sp)$ 就是**图上那个点离对角线有多高**。
「取约登指数最大」等价于「在 ROC 曲线上找离对角线最远的那个点」。
::::

### 似然比：比灵敏度、特异度更好用的两个数

两个**跨人群可比**的指标：

$$LR^+ = \frac{Se}{1-Sp}, \qquad LR^- = \frac{1-Se}{Sp}$$

- $LR^+$：阳性结果在病人中出现的可能性，是它在非病人中出现可能性的多少倍。**越大越好**（通常 $>10$ 才算强证据）。
- $LR^-$：阴性结果在病人中出现的可能性，是它在非病人中出现可能性的多少倍。**越小越好**（通常 $<0.1$ 才算强证据）。

它们的好处是**可以直接用来更新判断**（把检查前的概率换算成检查后的概率），而且和患病率无关。$LR^+$ 和 $LR^-$ 一个由灵敏度主导、一个由特异度主导，所以**同一个试验被两个数分别评价**时，能看出它更适合用来「排除」还是「确认」。

### 预测值：为什么同样的试验换个科室就不准了

临床上医生真正想问的其实是另一个问题：**这个人结果是阳性，他真有病的概率是多少？**

- **阳性预测值** $PPV = \dfrac{TP}{TP+FP}$
- **阴性预测值** $NPV = \dfrac{TN}{TN+FN}$

注意分母变了：$PPV$ 的分母是**所有试验阳性的人**（$TP+FP$），不是所有病人。

**关键在这里**：$Se$ 和 $Sp$ 只跟试验有关，$PPV$ 和 $NPV$ 却**跟着患病率走**。用贝叶斯公式可以直接看出来：

$$PPV = \frac{Se\cdot p}{Se\cdot p + (1-Sp)(1-p)}$$

其中 $p$ 是患病率。下面用真实数据算一遍这个效应，差别大到会改变临床决策。

### ROC 曲线是怎么画出来的

上面所有的 $Se$、$Sp$ 都是**在某一个阈值下**算的。阈值是人为选的，所以与其挑一个阈值报两个数，不如**把所有可能的阈值都算一遍**，把结果画成一条线：

- 横轴：$1-Sp$（假阳性率）
- 纵轴：$Se$（真阳性率）
- 阈值从最严（谁都判阴性）扫到最松（谁都判阳性），每个阈值对应图上一个点，连起来就是 **ROC 曲线**。

曲线左下角 $(0,0)$ 对应「全部判阴性」，右上角 $(1,1)$ 对应「全部判阳性」。
**好的试验，曲线会向左上角鼓**（$Se$ 高、$1-Sp$ 低）；如果曲线贴着对角线走，说明这个指标跟抛硬币差不多。

### AUC 怎么读

**AUC**（曲线下面积）是 ROC 曲线与横轴围出的面积。它的准确含义是一个概率：

> 随机抽一个有病的人和一个没病的人，**有病那个人的指标值更高的概率**。

这句话很重要，因为它说明 AUC 是**秩**意义上的指标：只要病人组的指标普遍比非病人组高就行，指标本身的量纲、单位、是否偏态都不影响。AUC 也正好等于 Mann-Whitney U 统计量归一化后的值（在二分类 logistic 回归里就是 $c$ 统计量）。

- $AUC = 0.5$：完全没有判别能力（沿对角线）；
- $AUC = 1$：完美分开。

::: warning 关于「AUC 多少算好」的经验分档
文献里流传一套分档（常被引到 Hosmer 与 Lemeshow 的《Applied Logistic Regression》）：
0.5~0.7 判别能力差、0.7~0.8 一般、0.8~0.9 好、0.9 以上很好。

**这是经验说法，不是标准，也不该当成结论**。同一个 AUC 在不同场景里的价值差得很远：
用来筛查一个后果严重、后续确诊手段便宜的疾病，0.7 可能就够用；
用来替一个创伤很大的确诊检查下结论，0.9 也未必敢用。
报 AUC 的时候，与其写一句「AUC = 0.73，判别能力一般」，不如把**灵敏度、特异度、以及临床上能接受的最低水平**一起写出来。
:::

**AUC 也不是万能的**。它把曲线下所有阈值一起平均了，所以两个指标可能 AUC 相同、但曲线形状完全不同（一个中间段好、一个两端好），在各自实际使用的那个阈值区间里表现差很多。**AUC 相同不等于临床价值相同**。

### 阈值怎么定

常见三条路子，没有哪条一定对：

| 方法 | 做法 | 什么时候用 |
| --- | --- | --- |
| 约登指数最大 | 取 $Se+Sp-1$ 最大的那个阈值 | 默认选择，$Se$ 和 $Sp$ 同等看待 |
| 最靠近左上角 | 取到点 $(0,1)$ 距离最小的阈值 | 和约登指数接近，结果常常一样 |
| 按临床要求固定 | 规定 $Se$ 必须 $\geq$ 某个值（或 $Sp$ 必须 $\geq$ 某个值），再取满足条件里最好的 | **最有临床意义**：漏诊代价大的病，就先把灵敏度钉死 |

第三条最值得强调：**阈值应当由「漏诊和误诊哪个后果更重」决定，而不是由算法决定**。
筛查艾滋病、宫外孕这类漏诊后果严重的病，宁愿误诊多一些也要把灵敏度提上去；
而一个阳性结果会导致创伤性进一步检查的试验，就得先保特异度。

### 两条 ROC 曲线怎么比

两个指标（或两个模型）的 AUC 谁高谁低，**不能直接比大小** —— 差距可能只是抽样误差。标准做法是 **DeLong 检验**（DeLong 等，1988），它考虑了同一条曲线上各点之间的相关性，而且在两个指标测的是**同一批人**时能正确处理配对结构。

## 在 R 里怎么做

用 `pROC` 包里自带的 `aSAH` 数据：113 例动脉瘤性蛛网膜下腔出血患者，结局分 Good / Poor（Poor 41 例，占 36.28%），
指标是 `s100b` 和 `ndka` 两个生物标志物。

```r
library(pROC)
data(aSAH, package = "pROC")

# 结局分布：Poor 是我们关心的「有病」那一组
table(aSAH$outcome)
#  Good Poor
#    72   41

# 画 ROC 曲线，顺便算 AUC 与它的 95% 可信区间
r <- roc(aSAH$outcome, aSAH$s100b, levels = c("Good", "Poor"))
auc(r)        # 0.7314
ci.auc(r)     # 0.6301 ~ 0.8326

plot(r, print.auc = TRUE, print.thres = "best",
     xlab = "1 - 特异度（假阳性率）", ylab = "灵敏度（真阳性率）")
```

**AUC = 0.7314，95% 可信区间 0.6301 ~ 0.8326。**

按约登指数选阈值：

```r
coords(r, "best", best.method = "youden",
       ret = c("threshold", "sensitivity", "specificity"))
#   threshold sensitivity specificity
# 1     0.205   0.6341463   0.8055556
```

阈值 0.205 处：**灵敏度 0.634，特异度 0.806，约登指数 0.440**。
由此得 **$LR^+ = 3.26$，$LR^- = 0.454$** —— 两个数都只算「中等」，说明这个指标单独用不足以确诊或排除。

拿这个阈值做四格表，再算预测值：

```r
thr <- 0.205
tab <- table(pred = ifelse(aSAH$s100b >= thr, "阳性", "阴性"),
             truth = aSAH$outcome)
tab
#       truth
# pred   Good Poor
#   阳性    14   26
#   阴性    58   15
```

$TP=26$、$FP=14$、$FN=15$、$TN=58$，于是

- $PPV = 26/(26+14) = 0.650$
- $NPV = 58/(58+15) = 0.795$

**注意这两个数只在患病率 36.28% 的这组人里成立**。同一套 $Se$、$Sp$，换个人群就变样：

| 患病率 | 阳性预测值 PPV | 阴性预测值 NPV |
| --- | --- | --- |
| 5% | **0.147** | 0.977 |
| 10% | 0.266 | 0.952 |
| 36.28%（本研究人群） | 0.650 | 0.795 |
| 50% | 0.765 | 0.688 |

**这张表值得盯一会儿**：同一个试验，转到患病率 5% 的人群里（比如社区筛查），
阳性结果里只有 14.7% 是真病人 —— **阳性基本等于白阳性**。这就是为什么**低患病率人群不适合用低特异度的试验做筛查**，也是为什么「体检发现某项阳性」常常需要复查而不是直接下结论。

阈值不同，$Se$ 和 $Sp$ 的取舍也不同：

| 阈值 | 灵敏度 | 特异度 | 约登指数 |
| --- | --- | --- | --- |
| 0.05 | 0.976 | 0.069 | 0.045 |
| 0.10 | 0.829 | 0.389 | 0.218 |
| 0.15 | 0.659 | 0.639 | 0.297 |
| **0.20** | **0.634** | **0.806** | **0.440** |
| 0.30 | 0.512 | 0.833 | 0.346 |

阈值从 0.20 降到 0.05，灵敏度从 0.63 涨到 0.98，但特异度从 0.81 掉到 0.07 —— **几乎所有人都被判阳性**，这个「高灵敏度」已经没有意义了。所以「把阈值调低以提高灵敏度」是有代价的，不能只看一边。

最后比较两个指标的 AUC：

```r
r2 <- roc(aSAH$outcome, aSAH$ndka, levels = c("Good", "Poor"))
auc(r2)                        # Area under the curve: 0.612
roc.test(r, r2, method = "delong")
# Z = 1.3908, p-value = 0.1643
```

`s100b` 的 AUC（0.7314）看着比 `ndka`（0.612）高不少，但**DeLong 检验 p = 0.164，差别没有统计学意义**。
113 例的样本量下，这个差距还说明不了问题 —— 这正是「不能直接比 AUC 大小」的原因。
（`roc.test` 同时给出 AUC 之差的 95% 可信区间 −0.049 ~ 0.288，同样跨过 0。）

## 容易踩的坑

::: warning 六个常见错误
**① 用预测值去比较两个试验的好坏。**
$PPV$、$NPV$ 随患病率变，在两个患病率不同的人群里做出来的 $PPV$ 根本不能比。
比较试验性能要用 $Se$、$Sp$、似然比或 AUC。

**② 把「灵敏度高」当成「阳性就是有病」。**
灵敏度高只说明**病人漏得少**；阳性预测值高不高，取决于患病率。
低患病率人群里，灵敏度再高，阳性预测值也可能很低（上面那张表就是证明）。

**③ 只报 AUC，不报阈值下的 $Se$、$Sp$。**
AUC 是**阈值平均**的结果，临床上必须落到一个具体阈值才能用。
报 AUC 而不给阈值，等于没说这个试验该怎么用。

**④ 在有金标准偏倚或选择偏倚的人群里做评价。**
诊断试验的 $Se$、$Sp$ 只有在「用金标准确认过每个人的真实状态」时才成立。
如果只对试验阳性的人做金标准检查（verify bias），算出来的灵敏度和特异度都是有偏的。

**⑤ 拿同一个数据集既选阈值又报性能。**
在同一批数据上选出约登指数最大的阈值，再用这个阈值报灵敏度和特异度，**是乐观偏倚**。
正规做法是拿一部分数据（或另一个中心的数据）选阈值，在另一部分上验证。

**⑥ 用「试验阳性率」反推患病率。**
患病率的估计要靠流行病学调查，不能由某台仪器的阳性率除出来 —— 那个数还夹着 $Se$、$Sp$。
:::

## 小结

| 想回答的问题 | 用什么指标 | 关键提醒 |
| --- | --- | --- |
| 这个试验能查出多少病人？ | 灵敏度 $Se$ | 分母是**所有病人**，不随患病率变 |
| 这个试验会冤枉多少健康人？ | 特异度 $Sp$ | 分母是**所有健康人**，不随患病率变 |
| 一个数比较两个试验？ | 约登指数、似然比、AUC | 约登指数对应 ROC 上离对角线最远的点 |
| 结果阳性，真有病的可能性？ | 阳性预测值 $PPV$ | **随患病率剧变**，不能跨人群比较 |
| 结果阴性，真没病的可能性？ | 阴性预测值 $NPV$ | 同上；患病率低时 $NPV$ 天然很高 |
| 阈值定在哪儿？ | 约登指数最大 / 按临床要求钉死 $Se$ 或 $Sp$ | **漏诊和误诊哪个后果更重，决定的不是算法是临床** |
| 两个指标的 AUC 谁更高？ | DeLong 检验 | AUC 差得多也可能是抽样误差；AUC 相同也可能临床价值不同 |
