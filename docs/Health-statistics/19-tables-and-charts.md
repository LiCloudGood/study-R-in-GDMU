# 第 19 章　常用统计图表

> 数据已经算出来了，怎么摆进一张表、一张图 —— 既让人一眼看懂，又不让图形替你把结论说大。

## 这一章要解决什么

前面的章节解决的是「算得对不对」：均数、标准差、率、$P$ 值。这一章解决的是「说得清不清楚」。

同一批结果，摆成一张结构混乱的网格表、画成一张纵轴被截断的直条图，读者会得出完全不同的印象 —— 哪怕数字一个都没算错。所以本章有两件事：

1. **统计表**：把资料和指标按行列排好，做到「由左向右读一行，就能读懂一句完整的话」。核心要求就三条：重点突出、层次清楚、简单明了。
2. **统计图**：用点、线、面把数据的**分布、构成、趋势、关系**画出来。图比表直观得多，但正因为直观，**它也更容易误导** —— 一张裁剪过纵轴的直条图，比十个错误的小数点更能改变别人的结论。

这一章的内容看着最"文科"，实际上是**选图和排版的技术规范**：什么资料配什么图、坐标轴能不能不从零开始、构成比该用圆图还是百分条图。这些规则背后都有理由，本章把理由一并讲清楚。

## 核心概念

### 统计表的五个部件

把统计资料及其指标以表格形式列出，就是**统计表**（statistical table）。科研论文里用的是**狭义统计表**（分析用表）；调查表、整理表属于广义统计表，不在本章范围。

一张规范的分析用表由五个部件构成，每个部件的位置和要求都很具体：

| 部件 | 位置 | 要求 |
| --- | --- | --- |
| 标题 | 表的上方**正中** | 概括表的主要内容，必要时注明时间、地点；有多张表时加序号，序号与标题同行、放在标题前面；全表单位一致时，把单位写在标题末尾的括号里 |
| 横标目 | 表的**左侧** | 被研究事物的主要特征（即分组标志）；排列要有规律 —— 时间按先后、数值由小到大、或按重要性/习惯顺序 |
| 纵标目 | 标目分隔线**上方** | 被研究事物的各项统计指标；有单位时写在括号里 |
| 线条 | 顶线、底线、标目分隔线 | 竖线、斜线一律去掉；有合计栏时加一条合计线；需要分层表示时用短横线分隔 |
| 数字 | 数据区 | 用阿拉伯数字；**同一指标的小数位数一致、小数点对齐**；表内不留空格，暂缺写「…」，无数字写「—」，真的是 0 就写 0 |
| 备注 | 表的**下方** | 数据区不插任何文字；需要说明时在对应数字右上角标 `*`，在表的下方以注释说明 |

一句自检口诀：**横标目（是什么）+ 纵标目（哪个指标）= 一句完整的话**。比如「高血压的患病率是 25.2%」「男性 40~55 岁的平均收缩压是 128 mmHg」—— 读得通，表就对了；读出来像半句话，说明标目放错了位置。

### 三线表：只留三条横线

论文里要求的是**三线表**：只有顶线、标目分隔线、底线三条横线，**没有竖线、没有斜线、没有单元格网格**。理由很实在：竖线会把读者的视线切成一个个小格子，让人一格一格地读数字；去掉竖线之后，视线自然沿着横行移动，一行读下来就是一句完整的话。

下面这张表就是按三线表的要求写的（VitePress 的表格默认只画三条横线，正好是三线表的样子）：

| 疾病 | 患病率（%） |
| :--- | ---: |
| 高血压 | 25.2 |
| 高血脂 | 28.6 |
| 糖尿病 | 9.7 |

编写时有两条实用技巧：

- 数字列在分隔行里用 `---:` 右对齐（如上面的 `| :--- | ---: |`），小数点自然对齐，同位数好比较；
- **不要把 `x̄ ± S` 塞进标题或纵标目**。标题说明的是「这张表在讲什么事」，`x̄ ± S` 是「数字的含义」，应当写在纵标目里；表里同时有绝对数和相对数时，更要把 `n`、`%` 各占一列，并在纵标目里写清楚。

### 简单表与复合表

按分组标志的个数分两类：

- **简单表**：只有一个分组标志，用于几个相互独立事物（或同一事物不同水平组）之间的比较。
- **复合表**：有两个及以上分组标志，例如同时按「学习阶段」和「家长吸烟情况」分组，这样才能分析两者的联系。

复合表信息量大，但也最容易违反「重点突出」。判断标准是：**一张表一般只表达一个中心内容**。如果一张表里既比手术时间、又比出血量、又比术后疼痛分级，还混着绝对数和相对数，就应该拆成两张（术中情况一张、术后情况一张）。

### 统计图：结构、原则和「自明性」

统计图用点、线、面表达数值大小、分布情况、变化趋势和相互关系。它最大的特点是**自明性**：不读正文，只看图就该明白在说什么。这一点也是要求：**标题、标目、单位、图例缺一个，「自明」就做不到**。

一张图的五个部件：

| 部件 | 要求 |
| --- | --- |
| 标题 | 放在图体的**下方正中**（和表相反，表题在上、图题在下）；有编号时编号在标题前面 |
| 图域 | 作图空间，一般取第一象限，以两轴交点为起点；长宽比约 **5∶7** 比较美观 |
| 标目 | 横标目在横轴**下方**，纵标目在纵轴**左侧**；**有单位的一定要标单位** |
| 刻度 | 数值由小到大排列（纵轴自下而上、横轴从左至右），一般标在横轴下侧和纵轴外侧 |
| 图例 | 同一张图里比较两种及以上事物时，用不同线形/图标/颜色区分，并附图例（放图域右上角空隙或图体下方中间） |

制图三原则：

1. **选图适当** —— 按资料性质和分析目的选图型，这是本章最核心的考点；
2. **简单明了** —— 一幅图通常只表达一个中心内容或主题；
3. **准确美观** —— 线粗细适中、定点准确、比例恰当，不同事物用不同线形或颜色区分。

> 图与表的取舍：图适合"看形状、看趋势、看关系"，表适合"看准确数值"。图**没有**精确标出每个元素代表多少，只能提供概略情况，所以关键数值仍应以统计表给出，两者常常配套使用。

### 直条图（条形图）：比独立指标的大小

**直条图**（bar chart，简称条图；横放时习惯叫条形图）适用于**相互独立的资料**，用等宽直条的长短表示各统计量的大小，描述各独立指标的数量及对比关系。它有单式和复式两种：一个统计指标 + 一个分组因素是单式；一个统计指标 + 两个及以上分组因素是复式。

绘图要点：

1. 通常横轴安排相互独立的事物（分组因素），纵轴是统计指标；直条一般竖放，也可横放；
2. **纵轴尺度必须从「0」开始**，等距离划分，中间一般不折断 —— 否则会改变各组之间的对比关系（见「常见的图表误导」）。个别数据偏离主体太远、非折不可时，可在坐标轴上插入 `//` 符号表示折断再续；
3. 各直条宽度相等，间隔一般与直条等宽或为其一半（**条图有缝，直方图无缝**，这是两种图最容易混的地方）；
4. 各直条可按指标数值大小排列，有自然顺序的（如病程分期）按自然顺序排；
5. 复式直条图里同一组的各直条要用不同颜色或纹理区分并附图例；有隶属关系的两个事物，可以用直条全长表示全部、下段表示其中一部分（分段条图/堆积面积图）。

判断能不能用直条图，只要问一句：**这几个分组之间是"并列"的，还是"连续"的？** 病种、地区、血型是并列的 → 直条图；身高组段、年龄组是连续的 → 直方图或线图。

### 圆图与百分条图：看构成比

两者都用于**构成比资料**，用面积大小描述事物内部各部分占的比例。

**圆图**（pie chart）以圆的总面积代表全部（100%），以圆内各扇形面积代表各组成部分。画法要点：

- 圆周 360° 分成 100 等份，每 1% 对应 3.6°，所以各部分的圆心角

$$\text{圆心角} = \text{构成比}(\%) \times 3.6^\circ$$

- 通常以时钟 12 点位置为起点，顺时针量出各圆心角，把圆分成若干扇形，并标出百分比；
- 不同扇面用不同颜色或纹理区分，并附图例。

**百分条图**（percent bar chart）以直条全长的面积为 100%，以各段面积大小代表各部分：

- 先画一条全长 100%、以 0 为基线的比例尺，再画一条与比例尺等长的直条（宽窄不限，以美观为准）；
- 按各部分百分比把直条分成若干段（从大到小或按自然顺序），各段用不同颜色/纹理区分、标出百分比并附图例。

**选哪个**：只有一个构成比要展示时两者都行；**要比较两组及以上的构成比，用百分条图**（多条直条可以上下对齐、逐段比较），圆图并排摆在一起几乎没法比。

### 线图：看趋势

**线图**（line chart）适用于**连续型资料**，用线段的升降描述某事物随时间或条件改变而变动的趋势。横轴多为时间、年龄等连续变量，纵轴表示率、均数或频数。分两种：

- **普通线图**：纵横轴都是算术尺度，反映事物的**绝对**变化量，常用来描述变化趋势；
- **半对数线图**（semi-logarithmic line chart）：横轴算术尺度、纵轴对数尺度，反映事物的**相对**变化量，用来描述**变化速度**，尤其适用于所比较的事物绝对量相差悬殊的情况。

绘图要点：

1. 各测定值标记点之间用直线连接，**不可修匀成光滑曲线**（光滑曲线会暗示你没有观测到的中间值）；
2. 普通线图纵轴一般从「0」开始；半对数线图纵轴的起点按资料情况可取 0.1、1、10 等；横轴可以不以 0 为起点；
3. 按组段绘图时，每组以组段下限为起点，**坐标点取组段中点**；
4. 同一图域内不宜画太多曲线，两条及以上时用实线/虚线/虚点线或颜色区分并附图例。

**为什么"变化速度"必须用半对数线图？** 变化速度是相对改变量。设两个时间点的指标为 $y_1$、$y_2$，则在两种尺度上，"斜率"分别对应：

$$\text{算术尺度斜率} \propto y_2 - y_1 \quad(\text{绝对差}),\qquad \text{对数尺度斜率} \propto \lg y_2 - \lg y_1 = \lg\frac{y_2}{y_1}\quad(\text{相对比})$$

看三组数：$1000\to100$（绝对差 900，相对比 10）、$100\to10$（绝对差 90，相对比 10）、$10\to1$（绝对差 9，相对比 10）。三组的**下降速度完全一样**，但绝对差相差 100 倍。画在普通线图上，三条线的斜率天差地别，看起来"起点高的那组降得快"；画在半对数线图上，因为对数差都等于 1，三条线**斜率一致**，速度相同一目了然。

这就是为什么发病率、死亡率这类绝对量相差悬殊的指标比较变化速度时，必须用半对数线图 —— 普通线图会让人产生"高基线的那组波动大、降得快，低基线的那组几乎没变化"的错觉。这也是实习里常见的一道辨析题：**普通线图看"变化了多少"，半对数线图看"变化了百分之多少"**。

### 直方图：看分布

**直方图**（histogram）用于描述**连续型资料的分布**，揭示频数分布的特征（集中趋势与离散趋势）和类型（对称分布或偏态分布），以相连直条面积的大小表示各组频数的多少。

绘图要点：

1. 横轴表示研究对象，纵轴表示频数，**纵轴尺度从「0」开始**；
2. **各直条之间不留空隙**（可以在条与条之间画直线隔开，但绝不能有空档）；
3. 条的宽度等于组距，高度等于该组频数；
4. 如果整理资料时用了**非等距分组**，画图前必须换算成相同组距，即调整各矩形的高：

$$h_i = \frac{f_i}{d_i}\quad(\text{矩形高} = \text{该组频数} \div \text{该组组距})$$

第 4 条是常被忽略的细节：等距分组时"高=频数"和"高=频数/组距"只差一个常数，看着无所谓；但一旦组距不等（比如末段是"80 岁以上"，跨度远大于其他组），直接用频数当高度就会**把宽组画得过分显眼**，分布形状被扭曲。

### 箱式图：比较多组分布

**箱式图**（box plot）用 5 个统计量反映数据的分布特征和类型，常用于两组或多组连续型资料分布情况的比较：

- 矩形上端 = 上四分位数 $P_{75}$，矩形下端 = 下四分位数 $P_{25}$，矩形中间的横线 = 中位数 $M$；
- 上下两条"柄"（须）= 除异常值以外的最大值和最小值；
- 数据中存在异常值时用「○」标出，极端值用「*」标出。

怎么读图：

- **矩形越长，变异程度越大**；
- 横线在矩形**正中** → 分布对称；偏向一侧 → 偏态（偏向数值高的一侧说明左偏，反之右偏）；
- 箱外的圆圈/星号就是**离群点**，它们可能是数据错误，也可能是真实存在的重要个案，两种情况都要追查。

R 的 `boxplot()` 判断异常值用的是四分位数间距规则：

$$IQR = P_{75}-P_{25},\qquad \text{超出 } [\,P_{25}-1.5\,IQR,\ P_{75}+1.5\,IQR\,] \text{ 的点标为异常值}$$

箱式图最大的价值是**它同时给出位置、离散和异常值**。等你看到一张"两组均数差不多"的直条图时，箱式图可能告诉你一组是对称的、另一组是双峰的 —— 均数相同，意义完全不同。

### 散点图：看两个变量的关系

**散点图**（scatter chart）以点的密集程度和趋势描述两个变量间的数量关系。

绘图要点：

1. 横轴代表自变量 $x$，纵轴代表应变量 $y$；**纵轴可以不从「0」开始**（这一点和直条图不同，因为散点图关心的是两变量的关系，不是各自的大小）；
2. 每一对变量值描一个点，**点与点之间不用直线连接**（连起来会凭空造出一批你没有观测到的中间值）。

散点图是直线相关与回归分析的**前置检查**：先看图，才知道该不该做相关回归。如果点呈弯曲的带状，或者有明显的分组结构、有远离主体的离群点，那么直接算 Pearson 相关系数 $r$ 是没有意义的 —— 这一点在第 13 章直线回归里会反复用到。

### 误差条图：均数 + 不确定性

**误差条图**（error bar chart）在直条（或点）上叠加一条短线表示变异程度，是医学论文里最常见的"带信息的直条图"。误差棒画什么，必须在图注里写明，因为三种写法的含义完全不同：

$$\bar{x}\pm s \quad(\text{标准差，描述个体变异}),\qquad \bar{x}\pm s_{\bar x}=\bar{x}\pm\frac{s}{\sqrt{n}}\quad(\text{标准误，描述均数的抽样误差}),\qquad \bar{x}\pm 1.96\,s_{\bar x}\quad(\text{近似 95\% 置信区间})$$

同一个数据集，$\bar x \pm s$ 的误差棒比 $\bar x \pm s_{\bar x}$ 长约 $\sqrt{n}$ 倍 —— 画标准差看起来"组间差别很小"，画标准误看起来"两组明显不同"，**读者只看图根本分辨不出你画的是哪一种**。所以：图注必须写明是 SD、SE 还是 95% CI，比较组间差别时用置信区间或标准误更合适。

还有一条：**误差棒只能表示"均数 ± 变异"，它不能替代假设检验**。两个组的误差棒不重叠不等于差别有统计学意义，重叠了也不等于没有差别 —— 结论仍然要靠检验。

### 热图：一张图看一个矩阵

**热图**（heatmap）用颜色的深浅表示格子里的数值大小，适合"行、列都是分组、格子里是数值或率"的矩阵式数据，比如相关系数矩阵、基因表达矩阵、各年龄段 × 各病种的发病率表。它的优势是**一屏之内找高低值区域**：哪里是一片深色、哪里是突变，比读表格快得多。

三条使用纪律：

1. **热图不适合精确读数**。颜色只能分出"高、中、低"，要具体数字还得回到表；
2. **不同量纲的列必须先标准化**（否则量级大的列会独占整个色阶），并且图例要写明横纵轴是什么、颜色代表什么；
3. 经典热图会**顺带画出行/列的聚类树状图**（层次聚类的结果），这时候图的含义已经不只是"看数值"，而是"看聚类结构"。

### 统计地图：看地域分布

**统计地图**（statistical map）描述某现象在地域上的分布：以行政区划为单位，用不同深浅的阴影或颜色表示某疾病的患病率、流行程度等。数据本身带地理属性（省、市、县）时它是首选；反过来，**不要用饼图或直条图来表达地理分布**，那等于把地图信息扔掉了。

### 什么数据配什么图

这是本章最该背下来的一张表。选图时按顺序问三个问题：**数据是什么类型** → **分析目的是什么** → **有没有更不容易误导的画法**。

| 数据类型 | 分析目的 | 推荐图形 | 不推荐什么 |
| --- | --- | --- | --- |
| 分类资料：几个相互独立的分组（病种、地区、血型） | 比大小、排名 | 直条图（单式） | 线图（分组之间没有连续顺序）；饼图（要比较大小） |
| 分类资料：一个指标 + 两个分组因素（城乡 × 病种） | 组间比较 | 复式直条图 | 把两组各画一个饼图并排比大小 |
| 分类资料：一个整体的内部构成（血型构成、死因构成） | 各部分占多大比例 | 圆图（分块 ≤ 5~6 个）；多个构成比比较用百分条图 | 圆图分块过多；用多个圆图比较构成 |
| 连续资料：单变量（身高、血压、体温） | 看分布形状、集中与离散、偏态/双峰 | 直方图 | 直条图（连续变量的条间不能留空隙） |
| 连续资料：按组比较分布（男/女、三种处理） | 比较位置与离散、找异常值 | 箱式图 | 只画均数 ± SD 的直条图（掩盖双峰、偏态和异常值） |
| 两个变量的关系（BMI 与收缩压） | 看相关、非线性、离群点 | 散点图 | 线图（点之间没有连续意义） |
| 连续资料随时间变化（年份、月龄） | 看趋势与波动 | 普通线图 | 直条图（把连续时间当成分类型）；把折线修匀成光滑曲线 |
| 多组指标随时间变化、绝对量相差悬殊 | 比较变化速度（相对改变量） | 半对数线图 | 普通线图（斜率被绝对差主导，速度比较会得出错误结论） |
| 组间均数 + 变异信息 | 比较均数并展示不确定性 | 误差条图（并写明误差棒是 SD / SE / 95% CI） | 只画均数不画变异的直条图 |
| 矩阵式数据（行、列都是分组，格子里是数值或率） | 快速找高低值区域 | 热图 | 用热图做精确读数；不标准化就去比不同量纲的列 |
| 现象带地域属性（省、市、县） | 看地理分布 | 统计地图 | 用饼图或直条图代替地图 |
| 聚类、分类的结果 | 看簇结构、样本归属 | 树状图（谱系图）、轮廓图、簇散点图 | 只看一个数字（如平均轮廓系数）就下结论 |

记忆版：**独立的分组 → 直条图；内部的构成 → 圆图/百分条图；随时间的趋势 → 线图；速度 → 半对数线图；分布 → 直方图；多组分布比较 → 箱式图；两变量关系 → 散点图。**

### 常见的图表误导

图比表直观，但直观的代价是**读者的判断被你的作图选择左右**。下面三种做法，数据一个都没改，结论却能被彻底翻转。

**一、截断纵轴（直条图纵轴不从 0 开始）**

某医院四个科室的抢救成功率是 80.25%、77.26%、94.12%、78.33%。

- 纵轴从 0 开始：四条直条几乎一样高，读者看到的是"四个科室差不多"；
- 纵轴从 70 开始：80.25 这条直条长度是 $80.25-70=10.25$，77.26 那条是 $77.26-70=7.26$，前者看起来比后者**高出约 40%**，读者会以为差距巨大。

同一批数字，只因为起点从 0 改成 70，"差不多"就变成了"差很多"。所以规则是硬的：**直条图的纵轴必须从 0 开始，等距划分，中间不折断**。确实有个别数值远离主体、非折不可时，才在轴上画 `//` 折断符号明示。要注意散点图和箱式图的纵轴可以不以 0 为起点 —— 因为它们不是用"长度"表示大小的，这条禁令只针对直条图。

**二、饼图分块过多**

把 12 个死因构成画成饼图，其中三块的构成比是 8.1%、8.0%、8.0%。换算成圆心角：$8.1\% \times 3.6^\circ = 29.16^\circ$，$8.0\% \times 3.6^\circ = 28.8^\circ$ —— 相差 0.36°，**肉眼看不出哪块更大**，而这三块在排序上分属第三、第四、第五位。

人眼比较角度和面积的精度远不如比较长度。所以：分块超过 5~6 个就别用圆图；要比较两个及以上构成比，改用百分条图；**如果目的其实是"比大小"而不是"看构成"，直接上按数值排序的直条图**。

**三、双纵轴**

把"空调销量"和"月平均气温"画在同一张图上，左轴是销量、右轴是气温，两条曲线看起来高度吻合，仿佛证明了"气温决定销量"。但两个纵轴的刻度是你自己定的：左轴取 0~1000 万台、右轴取 0~40 ℃，两条线就会显得同步；把右轴改成 20~45 ℃，立刻"不吻合"了。

问题不在于数据，而在于**图里藏了一个可以任意调整的自由参数**，而这个参数不写在图上。这就是 R 里用 `par(new = TRUE)` 把两张图叠在一起的典型场景：叠图之后连坐标轴都要手动关掉重画（`xaxt = "n"` / `yaxt = "n"`），稍有疏忽就会出现"左右轴各自代表的量纲错位"的错误，读者却毫无察觉。**要比较两个不同量纲的指标，宁可用两张上下对齐的图（共享横轴），或者先把两个指标都标准化/取指数化，也不要用双纵轴。**

顺便两个常见变体：

- **用"均数 ± SD 直条图"代替分布图**：两组均数几乎相同、但一组对称、一组双峰（比如一组是"全都接近平均值"，另一组是"一半偏高一半偏低"），直条图完全看不出来，箱式图或直方图一眼就能发现。只看均数的图，是把分布信息删掉之后再下结论。
- **不等距分组直接画直方图**：末段"80 岁以上"的组距远大于其他组，若不换算（矩形高 = 频数 ÷ 组距）就直接用频数当高度，会把这一组画得过分突出，分布形状被扭曲。

## 在 R 里怎么做

R 的 base 绘图函数与本章图型是一一对应的，先记住这张「图型 → 函数」对照：

| 图型 | base R 函数 | 关键参数 |
| --- | --- | --- |
| 直方图 | `hist()` | `breaks=`（组数）、`freq=FALSE` 画密度 |
| 直条图（单式/复式） | `barplot()` | `beside=TRUE` 复式、`horiz=TRUE` 横放 |
| 百分条图 | `barplot()` + `prop.table()` | 先归一化成 100% 再堆叠 |
| 圆图 | `pie()` | `labels=` 标百分比 |
| 普通线图 | `plot(type="b")` | `type="l"` 只连线、"b" 点线同画 |
| 半对数线图 | `plot(log="y")` | 纵轴取对数（等价于 `log10()` 后画普通线图） |
| 箱式图 | `boxplot()` | 公式写法 `y ~ group` |
| 散点图 | `plot(x, y)` | 默认就是散点，别加 `type="l"` |
| 误差条图 | `barplot()` + `arrows()` | `code=3` 两头都画 |
| 热图 | `heatmap()` / `image()` | `scale="column"` 先标准化 |

下面用 R 自带的 `iris`、`mtcars`、`airquality` 演示，全部可以直接复制运行。

先是最小的四行（四种图各一行）：

```r
hist(iris$Sepal.Length, main = "萼片长度分布", xlab = "长度 (cm)")
boxplot(Sepal.Length ~ Species, data = iris)
barplot(table(mtcars$cyl))
plot(iris$Sepal.Length, iris$Petal.Length)
```

**1. 直方图：分布形状**

```r
hist(iris$Sepal.Length,
     breaks = 12,                     # 组数，试试 6 和 20，形状会变
     main = "150 株鸢尾萼片长度分布",
     xlab = "萼片长度 (cm)",
     ylab = "频数")

# 纵轴换成密度，叠一条密度曲线看偏态
hist(iris$Sepal.Length, freq = FALSE, breaks = 12,
     main = "直方图 + 密度曲线",
     xlab = "萼片长度 (cm)", ylab = "密度")
lines(density(iris$Sepal.Length), lwd = 2)
```

输出怎么读：横轴是连续变量的组段、纵轴是频数、条与条之间**不留空隙**。看它是否左右对称、有没有第二个峰。`breaks` 是唯一需要动手试的参数：组数太少会把双峰抹平成一个峰，太多又会把随机波动画成"假峰"。

**2. 直条图：单式与复式**

```r
# 单式：一个分组因素
barplot(table(mtcars$cyl),
        main = "不同气缸数的车型数",
        xlab = "气缸数", ylab = "车型数")

# 复式：一个统计指标 + 两个分组因素
tab <- table(气缸数 = mtcars$cyl, 变速箱 = mtcars$am)
barplot(tab, beside = TRUE,
        names.arg = c("自动挡", "手动挡"),
        legend.text = rownames(tab),
        args.legend = list(x = "topright"),
        main = "不同变速箱车型的气缸数分布（例数）",
        xlab = "变速箱", ylab = "车型数")
```

输出的纵轴默认从 0 开始 —— 这正好是本章的要求。**不要用 `ylim = c(70, 100)` 这种写法去"放大差别"**，那正是前面说的截断纵轴。

**3. 百分条图：把每一组归一化成 100%**

```r
pct <- 100 * prop.table(tab, 2)      # 按列（变速箱）归一化，每列和为 100
barplot(pct, horiz = TRUE, xlim = c(0, 100),
        names.arg = c("自动挡", "手动挡"),
        legend.text = rownames(pct),
        args.legend = list(x = "bottomright"),
        xlab = "构成比 (%)", ylab = "变速箱",
        main = "不同变速箱车型的气缸数构成")
```

关键是 `prop.table()`：**构成比资料画图前一定要先归一化**，直接把原始例数堆起来画，各条长度不同，比较的就不是构成而是总量了。

**4. 圆图**

```r
n <- table(iris$Species)
pie(n,
    labels = paste(names(n), sprintf("%.1f%%", 100 * n / sum(n))),
    main = "三种鸢尾的构成比")
```

输出旁边那一圈标签就是各部分的百分比。`pie()` 只适合分块不多的构成比；想比较多个构成比，请回到上面的百分条图。

**5. 普通线图**

```r
m <- aggregate(Temp ~ Month, data = airquality, FUN = mean)   # 按月求平均气温

plot(m$Month, m$Temp, type = "b", pch = 19,
     xlab = "月份", ylab = "月平均气温 (°F)",
     main = "纽约 1973 年月平均气温")
```

`type = "b"` 表示点线同画，但**相邻点之间是直线**，没有修匀。千万不要为了"好看"去拟合一条光滑曲线 —— 那会画出你没有观测到的中间值。

**6. 半对数线图：比较变化速度**

```r
year <- 2000:2009
a <- 1000 * 0.9 ^ (0:9)   # 起点高的指标，每年降 10%
b <- 100 * 0.9 ^ (0:9)    # 起点低 10 倍，下降速度完全相同

par(mfrow = c(1, 2))      # 左右两张图对照

plot(year, a, type = "b", pch = 19, ylim = c(0, 1000),
     xlab = "年份", ylab = "发病率 (1/10万)",
     main = "普通线图：算术尺度")
lines(year, b, type = "b", pch = 19)          # 看起来像一条平线

plot(year, a, type = "b", pch = 19, log = "y",
     xlab = "年份", ylab = "发病率 (1/10万，对数刻度)",
     main = "半对数线图：对数尺度")
lines(year, b, type = "b", pch = 19)          # 与上面那条平行

par(mfrow = c(1, 1))      # 记住改回来，否则后面所有图都挤成两格
```

两张图用的是同一批数据：左图里低起点的曲线像一条平线，右图里两条线**平行** —— 平行正说明"下降速度相同"。`log = "y"` 就是半对数线图；没有半对数图纸时，把纵轴数据取常用对数画在算术纸上效果一样：`plot(year, log10(a), type = "b")`。

**7. 箱式图：同时看位置、离散和异常值**

```r
boxplot(Sepal.Length ~ Species, data = iris,
        main = "三种鸢尾萼片长度的分布",
        xlab = "种类", ylab = "萼片长度 (cm)")

# 把五个统计量算出来对照着看
tapply(iris$Sepal.Length, iris$Species,
       function(x) quantile(x, c(0, .25, .5, .75, 1)))
```

`y ~ group` 这种**公式写法**（应变量 ~ 分组变量）在第 9 讲反复出现：箱式图、`aggregate()`、`t.test()` 都用它。图上矩形的上下端是 $P_{75}$、$P_{25}$，中间横线是中位数，越出"须"的圆圈就是 R 按 $1.5\,IQR$ 规则标出的异常值。

**8. 散点图**

```r
plot(iris$Sepal.Length, iris$Petal.Length, pch = 19,
     xlab = "萼片长度 (cm)", ylab = "花瓣长度 (cm)",
     main = "萼片长度与花瓣长度的关系")

abline(lm(Petal.Length ~ Sepal.Length, data = iris),   # 加一条回归线辅助看趋势
       col = "red", lwd = 2)
```

先看图再加线，顺序不能反：图上如果有分组结构或离群点，那条回归线就没有意义。

**9. 误差条图**

```r
m <- tapply(iris$Sepal.Length, iris$Species, mean)
s <- tapply(iris$Sepal.Length, iris$Species, sd)

bp <- barplot(m, ylim = c(0, 9),
              xlab = "种类", ylab = "萼片长度 (cm)",
              main = "均数 ± 1 个标准差")
arrows(bp, m - s, bp, m + s, angle = 90, code = 3, length = 0.08)
```

`barplot()` 会返回每根直条中心的横坐标（存在 `bp` 里），`arrows()` 正是用这个坐标把误差棒画在直条正中。把 `s` 换成 `s / sqrt(n)` 就变成了标准误 —— 误差棒会明显变短，**所以图注里一定要写清楚画的是哪一个**。

**10. 热图**

```r
heatmap(as.matrix(iris[, 1:4]),
        scale = "column",                               # 每列先标准化，否则量纲大的列独占色阶
        labCol = c("萼片长", "萼片宽", "花瓣长", "花瓣宽"),
        main = "四个测量指标的热图")
```

注意输出：左边和上边多出来的两棵树是**层次聚类的树状图**，`heatmap()` 默认会按行、按列聚类并重排，所以行（样本）的顺序和原始数据不一样。只想看相关系数矩阵的话，用 `image()` 更直接：

```r
r <- cor(iris[, 1:4])
image(1:4, 1:4, r, zlim = c(-1, 1), axes = FALSE,
      xlab = "", ylab = "", main = "四个指标的相关系数")
axis(1, 1:4, colnames(r), las = 2, cex.axis = 0.8)
axis(2, 1:4, colnames(r), las = 2, cex.axis = 0.8)
box()
```

### ggplot2 的对照写法

同样的图，ggplot2 用"图层"来描述：`ggplot()` 指定数据与映射，`geom_*()` 决定画什么图型。上面几张图对应的写法：

```r
library(ggplot2)

# 直方图：hist()
ggplot(iris, aes(x = Sepal.Length)) +
  geom_histogram(bins = 12, fill = "grey70", colour = "white") +
  labs(title = "萼片长度分布", x = "长度 (cm)", y = "频数")

# 箱式图：boxplot(y ~ group)
ggplot(iris, aes(x = Species, y = Sepal.Length)) +
  geom_boxplot() +
  labs(title = "三种鸢尾萼片长度的分布", x = "种类", y = "长度 (cm)")

# 复式直条图：barplot(..., beside = TRUE)
ggplot(mtcars, aes(x = factor(cyl), fill = factor(am))) +
  geom_bar(position = "dodge") +
  labs(title = "不同气缸数车型的变速箱构成", x = "气缸数", y = "车型数", fill = "变速箱")

# 散点图：plot(x, y)
ggplot(iris, aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "萼片长度与花瓣长度的关系", x = "萼片长度 (cm)", y = "花瓣长度 (cm)")

# 热图：heatmap() / image()
ggplot(as.data.frame(as.table(cor(iris[, 1:4]))), aes(x = Var1, y = Var2, fill = Freq)) +
  geom_tile() +
  scale_fill_gradient2(low = "steelblue", mid = "white", high = "firebrick", limits = c(-1, 1))
```

**注意**：`geom_histogram()` 里 `bins` 换成 `binwidth`、坐标轴刻度、图例位置、主题（`theme_*()`）等细节，以及 `geom_raster()` 画热图、标度变换、`facet_*()` 分面这些内容，都在 **[《信息技术基础》第 10 讲 ggplot2 包](/intro-it/10-ggplot2)** 里系统讲。本章关心的是"该用哪种图、怎么才不失真"，语法细节去第 10 讲学；如果你还没写过 `ggplot()`，先按上面这段照抄跑通一遍，再回去补语法。

> 实习课上用 SPSS 画图时走的是 `Graphs → Legacy Dialogs` 菜单（Bar / Pie / Line / Boxplot / Scatter），做出来的图型判断和本章一模一样。区别是 SPSS 画出来的图默认标题在上方，要手动挪到下方并把误差棒含义写进图注；改纵轴起点、加对数刻度则要在 Chart Editor → Properties 里改，改之前先想清楚"该不该改"。

## 容易踩的坑

- **把表做成网格。** Excel 默认带竖线、边框、底纹，直接贴进论文就是一张网格表。正确做法是只留顶线、标目分隔线、底线（三线表），竖线和斜线全部删掉；同组数据靠"横行对齐"来读，而不是靠框线。

- **横标目和纵标目放反。** 常见错误是把统计指标（均数、率、例数）放在左侧、把分组（性别、地区）横排在上方 —— 这样读出来是"25.2% 的高血压患病率"，而不是"高血压的患病率是 25.2%"。判断方法就是那口诀：**由左向右读，一行要能读成一句完整的话**。另外要注意标题不能只写"比较表"这种空话，也不能把 `x̄ ± S` 塞进标题。

- **数字不齐、空着不写。** 同一指标小数位数不一致（80.25 和 77.3 混排）、小数点不对齐、表内留空格不写"暂缺/无/0"、把 "0.0" 写成"一"。规范是：同一指标小数位数一致且小数点对齐；暂缺写「…」，无数字写「—」，真的是 0 就写 0。用马克笔在纸上画和用 Word 排版，这条要求是一样的。

- **该用直条图的地方画了直方图（或反过来）。** 两组独立的手术后恢复天数、四个病种的患病率，条与条之间**必须留空隙**；而连续变量的频数分布（身高、血压的组段），各直条**必须紧挨着**，留空隙等于说"这些组之间是断开的"。同理，连续的时间数据该用线图，把它当分类型画成直条图，趋势信息就没了。

- **坐标轴动手脚。** 直条图纵轴不从 0 开始（夸大差异）、半对数线图纵轴从 0 开始、线图把折线修匀成光滑曲线、非等距分组不换算组距直接画直方图 —— 这四条都属于"数字没错但图在说谎"。改坐标轴之前先问自己：改完之后，读者对**差别大小**的印象有没有变？变了就不能改。

- **只画均数不画变异，或者不说明误差棒是什么。** 均数 ± SD 的直条图会让一个双峰分布看起来和对称分布一样；`x̄ ± s` 换成了 `x̄ ± s_{\bar x}`，误差棒会缩短 $\sqrt{n}$ 倍，肉眼看起来"组间差别很明显"。图注里必须写明误差棒代表 SD、SE 还是 95% CI，并且记住误差棒重叠与否**不能**代替假设检验。

- **[《医学大数据分析与决策》第 2 周 数据预处理](/Medical-Big-Data-Analysis/2-data-preprocessing)** —— 画图之前的数据准备都在那一周：缺失值处理、异常值识别、等宽与等频分箱、最小最大规范化与 Z-score 规范化。这些和本章直接咬合：**分箱的结果就是直方图的组段**（等宽/等频分箱对应等距/非等距分组，正是本章"非等距分组要换算矩形高"的来源）；**异常值识别的结果就是箱式图上那些圆圈和星号**（`boxplot.stats()` 用的 1.5 IQR 规则与那一周的描述统计同源）；**Z-score 规范化**则解释了为什么热图必须先把各列标准化 —— 不标准化，量纲大的列会独占整个色阶，图和数据的关系就断了。

## 小结

1. **统计表由标题、标目、线条、数字（加表下备注）五个部件构成**，制表三原则是重点突出、层次清楚、简单明了。自检口诀：**横标目 + 纵标目读出来是一句完整的话**。
2. **三线表只留顶线、标目分隔线、底线**；数字同一指标小数位一致、小数点对齐；数据区不留空格，暂缺「…」、无数字「—」、0 就写 0，注释标 `*` 写在表下方。
3. **选图看资料性质**：独立的分组用直条图，内部的构成用圆图/百分条图，随时间的趋势用普通线图，**比较变化速度用半对数线图**（对数斜率 = 相对改变量的对数），单变量分布用直方图，多组分布比较用箱式图，两变量关系用散点图；加上论文中常用的误差条图、热图，地域分布用统计地图。
4. **图的硬约束**：直条图纵轴必须从 0 开始、等距不折断；直方图纵轴从 0 开始且条间不留空隙，非等距分组要先换算矩形高；线图用直线连点、不修匀；散点图纵轴可不从 0 开始；线图/散点图/箱式图都只是"概略"，精确数值仍用表给出。
5. **图比表直观，也更容易误导**：截断纵轴能凭"起点从 0 改成 70"把 3 个百分点的差距画成 40% 的高度差；圆图分块过多（8.1% 与 8.0% 只差 0.36°）根本读不出顺序；双纵轴里两个刻度是自由参数，可以随意制造"高度吻合"。图注必须写明单位与误差棒含义，改动任何坐标轴之前先问：读者对差别大小的印象会不会变？
