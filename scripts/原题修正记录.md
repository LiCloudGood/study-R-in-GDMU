## 四、第二轮补充修正（数学性错误）

这几处不是错别字，而是**会让学生算错／学错**的内容问题，经作者授权后一并修正。

### 1. `资料/原题/第十二周原题/参数估计.docx` —— 指数区间写成了「乘 S」

| | 写法 |
| --- | --- |
| 原题（修正前） | $(\chi_{\alpha/2}\,S,\ \chi_{1-\alpha/2}\,S)$ —— **乘** $S$ |
| 答案 `test1204.R` | `xa / se`（`se = 2*n*mean(x)`）—— **除** $S$ |
| 统计学正确形式 | $(\chi_{\alpha/2}/S,\ \chi_{1-\alpha/2}/S)$，其中 $S=2n\bar X$ |

**依据**：指数分布下 $2\lambda X \sim \chi^2(2)$，由卡方可加性得
$2\lambda n\bar X \sim \chi^2(2n)$，把 $\lambda$ 解出来必然是**除以** $S$。
而且原题那段**从未定义 $S$**。

**已改为**：三个区间（双侧、右侧、左侧）都改成除号，即
`(χ_{α/2}/S, χ_{1-α/2}/S)`、`(χ_α/S, +∞)`、`(0, χ_{1-α}/S)`。

### 2. `资料/原题/第十三周原题/参数假设检验.docx` —— `alt='left'` 与答案不匹配

原题（3 处）写 `alt='left'` 表示左侧检验，而 `资料/答案/第十三周答案` 的
`switch` 分支名是 **`less`**。

R 的 `switch` 只做**精确匹配**，传 `'left'` 不会报错，而是**静默返回 `NULL`**——
学生照着原题写会得到一个「没有结果又不报错」的诡异现象。

**已改为**：3 处 `alt='left'` → `alt='less'`（与答案一致，也与 `t.test()` 的
`alternative = "less"` 约定一致）。

### 3. `资料/答案/第一周答案/test0107.R` —— 第一个表达式与题目不符

| | 内容 |
| --- | --- |
| 原题公式 | $\dfrac{-b+\sqrt{b^2-4ac}}{2a}$ |
| 原写法 | `sqrt(a^2 + b^2 + c^2 + 2*a*c - 2*a*b + 2*b*c)` |
| 代入 $a{=}2,b{=}5,c{=}{-}1$ | 原写法 = `sqrt(-4)` → **NaN**（负数开根） |

**已改为**：`(-b + sqrt(b^2 - 4*a*c)) / (2*a)`，代入得 $(-5+\sqrt{33})/4 \approx 0.186141$。

## 六、汇总 PDF（已重新生成，后又从仓库移除）

`资料/汇总` 里的 13 份 PDF 原先是用 Quarto 生成的，作者重装系统后手头暂无 Quarto，
无法用原流程重出。改用**系统自带的 Microsoft Edge 无头模式**从**已修正的 HTML** 打印：

```
msedge --headless=new --no-first-run --virtual-time-budget=20000 \
       --no-pdf-header-footer --print-to-pdf=输出.pdf 打印用的HTML
```

为保证效果，打印前对 HTML 做了两处**临时处理**（原始 HTML 未被改动）：

1. 把 `_files/` 下的相对引用改成绝对 `file://` 路径——
   否则图片、样式在临时目录里加载不到（第一次试打印时就踩了这个坑，页数明显不对）；
2. 注入一段打印样式：`@page { size: A4; margin: 18mm 16mm }`，
   并让代码块、图、标题尽量不跨页断开。

**结果**：13 份全部重新生成，A4 版式，文字可选中，图片齐全。
**原件已备份到 `_backup-summary/`**（该目录被 `.gitignore` 忽略），
若要还原原来的 Quarto 排版，把备份复制回 `资料/汇总/` 即可。

> **后续变化（本轮）**：这 13 份 PDF 占 6.6 MB，而 HTML 已经够用，所以已从仓库移除，只保留 `资料/汇总/*.html`。本地备份在 `_dev/汇总-pdf/`（未入库）。

> 版式说明：新 PDF 是「网页打印」样式，与原 Quarto 排版在字体、页眉页脚、
> 目录等方面不同。内容以修正后的 HTML 为准。
