# 术语对照表（中 → 英）

英文版的**唯一用词标准**。翻任何一页之前先查这里；这里没有的词，**补进来再翻**，
不要临场另起一个说法。同一份站里两个地方对同一个概念用两个词，读者会以为是两回事。

> 为什么单独立一份：这个站有 22 万汉字、50 个文件，翻一半改术语等于全部返工。
> 术语表是这套翻译的「规则表」，和选择器的规则表是同一个道理 —— 一处定义，处处一致。

## 一、总则

1. **术语优先用国际统计学的通行写法**（sensitivity、specificity、Youden index……），
   不按中文逐字硬译。中文特有的口径（如「率的标准化」）用国际通行的对应概念表达，并在首次出现处加一句解释。
2. **公式、数值、R 函数名、参数名、数据集名，一律不动**。代码里有三类中文字符要处理：
   - **中文注释** → 翻成英文；
   - **中文的字符串字面量**（`xlab = "灵敏度"`、图例标签、表的行名）→ 翻成英文，
     因为它们是**给读者看的图上的文字**，不是代码逻辑；
   - **函数、参数、变量名** → 一律不译。
   翻完要保证代码仍能直接跑，且**输出里的标签与代码一致**（改了行名，注释里贴的输出也要一起改）。
3. **结论的强度不能变**。原文说「可能」「通常」「必须」，英文照旧（may / typically / must），
   不要把「可能」翻成 can，也不要把「必须」翻成 should。学术写作里这是实质性差异。
4. **不添加原文没有的内容**，也不删原文有的限定条件。
5. **隐私口径照旧**：不出现学校全名、教师姓名、学号、邮箱。学校一律写 **GDMU**。
6. **章节编号与课程编号照旧**：`第 10 章` → `Chapter 10`；`第 10 讲` → `Lecture 10`；
   周次 `第 4 周` → `Week 4`。编号本身不动，因为它和教材、和课程周次是一一对应的。
7. **书名**：中文书名用斜体 + 英文译名，首次出现处可附中文。
8. 语言风格：**英式/美式任选其一，但全站统一用美式**（analyze、center、randomization）。
   句长可以比中文短，但不要为了「读起来顺」而牺牲限定条件。

## 十五、翻译流程（每页照做）

1. **先查这张表**。表里没有的词，先补进表再翻。
2. 对着中文原文逐段翻，**结构（标题层级、表、公式块、代码块）一一对应**，不合并、不省略。
3. 公式、数值、R 代码原样搬过去；代码里的中文注释翻成英文，代码本身不动。
4. 交叉链接照搬结构：href 换成 `/en/` 下的对应页；**该页还没翻的话，仍然指向中文页，
   但要在括号里标明 `(Chinese)`** —— 让读者知道点过去是中文，而不是干脆断链。
   翻好之后再把 href 换成 `/en/` 版并去掉标注。
5. 翻完在 config.mts 的英文侧栏把该条目的 `link` 补上。
6. 页面底部加一行注明译文来源与校对状态（见下）。

## 十六、译文状态标注

每页英文版顶部统一放：

```md
::: info Translation status
Translated from the Chinese original. Numbers, formulas, and R code are identical to the original;
if the two disagree, **the Chinese page is authoritative**.
:::

[中文版](/Health-statistics/xxx)
```

这样读者知道该以哪份为准 —— 双语的站点最怕两份说法不一致却不说哪份算数。
