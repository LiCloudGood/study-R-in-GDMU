# 第 7 章　实验流行病学

> 前面几章都是「观察」——研究者只是记录，不能干预。这一章不一样：**研究者亲手决定谁接受什么**。也正因为如此，它成了观察性研究之外唯一能「确证因果」的手段。

## 这一章要解决什么

队列研究已经能证明「吸烟的人肺癌多」，但它始终有一句没法排除的话：
**是不是爱吸烟的人本来就在别的方面也不一样？**（年龄、职业、遗传、经济条件……）
队列研究只能尽量**测量并调整**这些差异，却无法**制造**两组之间的可比。

实验流行病学的做法是：**把「谁接受什么」交给随机**。

- 同质的研究对象 → **随机**分到实验组和对照组；
- 实验组给干预措施，对照组给对照措施；
- **前瞻性**观察两组的结局差异。

随机分组有一个队列研究永远做不到的性质：**已知的和未知的混杂因素，理论上都会在两组间均衡分布**。
所以两组的差别可以被归因于干预本身。这就是它「能确证因果」的底气。

代价也很直接：**伦理**。你不能随机让人吸烟去研究肺癌——所以实验研究只能用在「干预可能有益」的场合。

## 核心概念

### 定义

> **实验流行病学**（experimental epidemiology），也称实验性研究或流行病学实验，
> 是指根据研究目的，将**同质**的研究对象**随机分配**到实验组和对照组，
> 实验组给予**干预措施**，对照组给予**对照措施**，
> **前瞻性**观察并比较两组结局事件的发生情况，从而判断**干预措施效果**的流行病学方法。

### 原理与方向

```
目标人群
   ↓（选取同质样本）
同质样本 ──随机分组──┬── 实验组（干预措施）── 结局+ / 结局-
                    └── 对照组（对照措施）── 结局+ / 结局-
                          ↑
                    前瞻观察，比较两组结局
```

时间方向仍然是**现在 → 将来**（前瞻），和队列研究一样；区别在于**分组靠随机**，而不是「谁碰巧暴露了」。

### 四个基本特征

| 特征 | 含义 |
| --- | --- |
| **随机分组** | 研究对象有**同等的机会**被分配入试验组或对照组 |
| **施加干预** | 人为给予干预措施：治疗性（药物、器械）、诊断性、预防性（疫苗、健康教育） |
| **设置对照** | 与试验组同质可比、除干预因素外其他条件均衡的受试者集合 |
| **前瞻观察** | 通过前瞻性随访获得结果，而不是靠历史记录或其他方式 |

::: tip 哪一个特征是「最本质」的？
**施加干预**是与**观察性研究**最本质的区别——观察性研究里暴露是客观存在、不受研究者决定的。

而**随机分组**解决的是「组间潜在混杂因素分布不平衡」的问题，
是它能强于队列研究的关键。

两者要分清：**干预**决定它属于实验研究；**随机**决定它能否确证因果。
:::

## 主要类型

### ① 临床试验

> 在**医院或其他医疗环境**下实施，以**病人**为研究对象，以**个体**为单位随机分组，
> 施加干预措施，用以评价**临床干预效果**的试验方法。

**临床试验的五个特点**：

1. 以**病人**为研究对象；
2. 多在医院进行；
3. 多为**治疗性**试验；
4. 随机分配研究对象，并尽可能做到**分配方案的隐藏**；
5. 采用**盲法**。

> **历史坐标**：1948 年，英国医学杂志发表了世界上第一个随机对照试验——
> 链霉素治疗肺结核。试验组接受链霉素并卧床休息，对照组仅卧床休息，
> 以 6 个月生存率和胸部 X 线的明显改善率为主要指标，
> 结果两组 6 个月生存率为 93% 与 73%，明显改善率为 51% 与 8%。
> 这个研究确立了「随机 + 对照」作为疗效评价标准的地位。

其中 **随机对照试验**（randomized controlled trial，RCT）是临床试验的典型形式。

### ② 现场试验

> 在**现场或社区**实施，通常以**未患所研究疾病的人**为研究对象，
> 以**个体或群体**为单位随机分组，施加干预措施，用以评价**干预效果**的试验方法。

**现场试验的五个特点**：

1. 研究对象：**健康人**或未患所研究疾病者；
2. 研究地点：社区、学校、工厂等**现场**；
3. 多为**预防性**试验；
4. 样本量通常**较大**；
5. 尽可能应用盲法。

**现场试验的两种形式**：

| 形式 | 做法 | 例子 |
| --- | --- | --- |
| **个体试验** | 以**个体**为单位随机分组，个体接受干预 | 预防接种、药物预防 |
| **社区试验** | 以**人群整体**（整个社区）为基本单位施加干预 | 食盐加碘、饮水加氟 |

> 社区试验的特点是**干预按群体分配**，所以分析时不能按个体来算——
> 同一个社区里的人不独立，这会影响统计方法的选择（见第 6 章）。

## 临床试验的设计和实施

### ① 明确研究问题：PICO

| 字母 | 含义 | 例子（终末期肾病） |
| --- | --- | --- |
| **P**atient | 临床实践中的病人 | 慢性肾衰竭终末期（尿毒症）病人 |
| **I**ntervention | 干预 | 肾脏移植 |
| **C**ontrol | 对照 | 血液透析 |
| **O**utcome | 结局 | 生存率和生存质量 |

> 临床试验的研究对象是**病人**，伦理学要求特别高：
> 实施前必须制订详细的试验设计书，并提交**医学伦理委员会**批准。

### ② 选择研究对象

| 要点 | 要求 |
| --- | --- |
| **诊断标准** | 统一的、公认的诊断标准，便于结果外推与可比 |
| **代表性** | 最好能代表目标人群，但患者往往**难以随机抽取** |
| **纳入和排除** | 制定严格条件，保证结果合理外推、减少失访 |
| **依从性** | 研究对象能服从试验安排并配合到底 |

### ③ 估计样本含量

按资料类型分：**计数资料**样本量的计算与**计量资料**样本量的计算两套公式
（具体算法见 [卫生统计学 第 17 章](/Health-statistics/17-sample-size)）。

### ④ 随机分组与分组隐匿

**随机分组**是把研究对象随机分配到试验组和对照组，理论上使已知的或未知的影响因素
在两组间分布相同，确保均衡可比，从而避免**选择偏倚**和**混杂偏倚**。

**分组隐匿**（allocation concealment）是把防止随机分组方案提前解密的方法。
它有两个要点：

- 是保证随机分组方案**顺利实施**的关键环节；
- **只有随机分组联合分组隐匿，才能实现真实意义上的随机分组**。

> 随机分组和分组隐匿是**两件事**：
> 随机决定「谁去哪一组」，隐匿决定「在分配之前没人能猜到下一例去哪一组」。
> 只做随机不做隐匿，研究者可能在分配时「无意中」调整顺序，随机就失效了。

### ⑤ 确定干预措施与设立对照

**干预措施**在**设计阶段**就要做出明确、详细的规定；**正式试验中一般不允许改变**。

**四种对照形式**：

| 形式 | 做法 | 注意 |
| --- | --- | --- |
| **阳性对照**（positive control） | 用常规有效药物、标准或现有最佳治疗方案作对照 | 可显示试验组是否优于（或非劣效于）现有疗法；伦理与可行性问题较少 |
| **安慰剂对照**（placebo control） | 用无有效治疗成分的安慰剂（乳糖、淀粉、生理盐水等）作对照 | 能控制**安慰剂效应**；但**存在伦理问题**，只在该病尚无有效防治药物、或安慰剂对病情无影响时才可用 |
| **自身对照**（self-control） | 同一受试者「干预前」与「干预后」比较 | 干预后作试验组、干预前作对照组 |
| **相互对照**（mutual comparison control） | 不同剂量、剂型、给药途径等不同干预措施分组互比 | 用于比较哪种方案最佳 |

### ⑥ 实施盲法

| 级别 | 谁不知道分组 |
| --- | --- |
| **单盲**（single blind） | 只有**研究对象**不知道 |
| **双盲**（double blind） | **研究者和研究对象**都不知道 |
| **三盲**（triple blind） | **研究者、研究对象、资料分析者**都不知道 |

盲法要封住的其实是**四个环节**：

1. **分配者**不知道下一例该去哪组，才不会按自己的意愿挑选病人；
2. **病人**不知道自己接受什么，才不会改变依从性或症状报告；
3. **照护的医师**不知道分组，才不会（哪怕潜意识地）区别对待；
4. **评价结果者**不知道分组，才不会影响测量。

### ⑦ 确定结局变量

- 设计阶段就要明确规定，**一旦确定不能随意改变**；
- 根据研究目的定义，最好有**公认的界定标准**，以便结果外推。

**四条原则**：

1. 与所研究疾病存在**本质上的、特异性的**联系；
2. 最好能被**客观、准确**地测量；
3. **可行性**；
4. **可接受性**（受试者能接受）。

### ⑧ 收集资料

通过**病例报告表（CRF）**收集，包括：

- **基线数据**：人口学特征、所研究指标的基线水平、其他可能影响结果的因素；
- **随访信息**：干预措施执行情况、预后影响因素、结局事件是否发生或结局指标的变化。

## 资料整理与分析

### 一、资料的整理：排除、退出、失访

| 概念 | 定义 | 关键点 |
| --- | --- | --- |
| **排除**（exclusions） | 患者在**随机分组前**因各种原因没有被纳入研究 | 对**内部真实性无影响**，但影响**外推**；被排除者越多，结果能推广的面越小 |
| **退出**（withdrawal） | 研究对象在**随机分配后**或实施过程中脱离试验组或对照组 | 会造成样本量不足、破坏随机化，若两组退出不均衡则影响真实性 |
| **失访**（loss to follow-up） | 因迁移、意外或死于其他病而无法继续获得随访数据 | 一般要求**失访率不超过 10%** |

**退出的三种常见原因**：

1. **不合格**（ineligibility）—— 不符合纳入标准、一次也没接受干预、或没有任何数据；
2. **不依从**（noncompliance）；
3. **失访**（loss to follow-up）。

> 关于「不合格者」有个隐蔽的坑：研究者往往对试验组观察更仔细，
> 试验组里的不合格者更容易被发现，于是试验组剔除得更多；
> 也可能反过来——研究者特别注意效果差的对象并将其剔除，留下的都是效果好的。
> 两种都会造成偏倚。**办法**：把研究对象分成「合格组」和「不合格组」两个亚组分别分析，
> 若结论不一致就要慎重。

### 二、统计分析数据集

| 数据集 | 基于什么原则 | 包含谁 |
| --- | --- | --- |
| **全分析集**（FAS, full analysis set） | **意向性原则** | 全部随机化的受试者 |
| **符合方案集**（PPS, per-protocol set） | **符合方案原则** | 完全按方案设计执行的那一部分 |
| **安全性分析集**（SAS, safety analysis set） | **暴露原则** | 所有至少使用过一剂研究药物、并至少有一次安全性评价的受试者 |

> **疗效分析**应在 FAS 和 PPS 进行；**安全性评价**应在 SAS 进行。

### 三、三种分析方法

| 方法 | 英文 | 比较的是谁 |
| --- | --- | --- |
| **意向性分析** | intention-to-treat, **ITT** | 所有随机化的病人，**不管是否完成、是否真的接受了该组治疗**，都保留在原组分析 |
| **依从者分析** | compliance analysis | 只对完全遵守试验要求、全程依从的受试者比较（对应 PPS） |
| **接受治疗分析** | received treatment analysis | 不受设计限制，对**实际接受**了干预措施的受试者比较 |

**ITT 的目的**：避免**选择偏倚**，使各治疗组之间保持可比性。

### 四、效力与效应

| 概念 | 含义 | 对应分析 |
| --- | --- | --- |
| **效力**（efficacy） | **理想状态**下的治疗效果——参加者真正接受并完成了该治疗 | PPS / 依从者分析 |
| **效应**（effectiveness） | **一般临床状态**下的实际效果——可能不依从、改变治疗方式或间断治疗 | ITT |

> 评价试验效力时，建议**同时使用三种分析**，以获得更全面的信息，使 RCT 结果的解释更合理。

### 五、评价指标

#### 评价临床疗效的主要指标

| 指标 | 定义 |
| --- | --- |
| **有效率**（effective rate） | 治疗有效人数 ÷ 接受治疗总人数 |
| **治愈率**（cure rate） | 治愈人数 ÷ 接受治疗总人数 |
| **复发率**（recurrent rate） | 复发人数 ÷ 接受治疗总人数 |
| **并发症发生率**（incidence of complication） | 并发症人数 ÷ 接受治疗总人数 |
| **N 年生存率**（N-year survival rate） | N 年存活病例 ÷ 随访满 N 年的病例总数 |
| **绝对危险降低率**（ARR） | 对照组结局发生率（CER）− 试验组结局发生率（EER）的**绝对差值** |
| **相对危险降低度**（RRR） | ARR 占对照组发生率（CER）的**比例** |
| **需治疗人数**（NNT） | ARR 的**倒数**——为避免 1 例不良事件发生，需治疗的病人数 |

$$\text{ARR} = \text{CER} - \text{EER}, \qquad
\text{RRR} = \frac{\text{CER}-\text{EER}}{\text{CER}}, \qquad
\text{NNT} = \frac{1}{\text{ARR}}$$

#### 评价预防效果的主要指标

| 指标 | 定义 |
| --- | --- |
| **抗体阳性率**（positive seroconversion rate） | 抗体阳性人数 ÷ 接种总人数 |
| **保护率**（protective rate） | （对照组发病率 − 试验组发病率）÷ 对照组发病率 |
| **效果指数**（index of effectiveness） | 对照组发病（死亡）率是试验组的多少倍 |

### R 代码：算 ARR、RRR、NNT

用一份**构造的示例数据**（仅演示算法）：对照组 500 人发病 60 人，试验组 500 人发病 36 人。

```r
# 两组结局
cer <- 60 / 500     # 对照组结局发生率 0.12
eer <- 36 / 500     # 试验组结局发生率 0.072

ARR <- cer - eer              # 绝对危险降低率
RRR <- (cer - eer) / cer      # 相对危险降低度
NNT <- 1 / ARR                # 需治疗人数

c(CER = cer, EER = eer, ARR = ARR, RRR = RRR, NNT = NNT)
```

结果：$\text{CER}=0.12$、$\text{EER}=0.072$、$\text{ARR}=0.048$、$\text{RRR}=0.4$、$\text{NNT}\approx20.8$。

意思是：**每治疗约 21 名病人，可避免 1 例不良事件**。

::: tip NNT 是最该报的指标
- RRR（40%）听起来很漂亮，但**没告诉你风险基数**：如果基线风险只有 1%，那只是从 1% 降到 0.6%；
- **ARR 和 NNT 才是临床上能直接用的量**：NNT = 21 比「相对降低 40%」有用得多。
- NNT 必须**随基线风险变化**，所以报告 NNT 时要写明研究人群的基线风险。
:::

## 优点与局限

### 优点

1. 研究者可根据目的**预先制订设计**，对研究对象、干预因素和结果分析进行**标准化**；
2. **随机化分组**使各组基本特征相似，提高可比性、**减少偏倚**；
3. **前瞻性研究**，自始至终随访观察，实验组与对照组**同步比较**，能作出**肯定性结论**。

### 局限

1. 设计与实施要求**高、控制严、难度大**，实际工作中有时难以做到；
2. 受干预措施**适用范围**的约束，所选研究对象**代表性不够**，影响结果外推；
3. 样本量大、实施要求严、随访时间长，**依从性不易做好**，影响效应评价。

### 还应注意的四个问题

| 问题 | 说明 |
| --- | --- |
| **伦理与知情同意** | 必须经伦理委员会批准、取得**知情同意**；安慰剂对照、撤药设计尤其要谨慎 |
| **预试验**（pilot study） | 正式试验前先小规模试运行，检验流程可行性 |
| **研究注册** | 试验方案须**提前注册**，防止事后换终点、换分析 |
| **结果报告的完整透明** | 按规范完整报告（含阴性结果与不良事件），不能只报有利的部分 |

## 实验流行病学 vs 队列研究

| | 实验流行病学 | 队列研究 |
| --- | --- | --- |
| **方法分类** | 实验法（实验性研究） | 观察法（分析性研究） |
| **有干预措施吗** | **有**：实验组给干预，对照组给无/安慰剂 | 无（只是**暴露**） |
| **研究对象来源** | 同一总体样本 | 可来自同一人群，也可不同人群 |
| **分组方式** | **随机分组** | 根据是否暴露（或暴露水平）分组 |
| **验证病因假设** | **更强** | 较强 |
| **相同点** | 前瞻性研究；实施难度大、样本量大、随访时间长、依从性不易保证；不适用于发病率较低的疾病 | 同左 |

## 常见误区

::: warning 六个高频错误
- **把「随机」理解成「随便」。** 随机是每个对象有**同等机会**被分到任一组；
  「按入院先后交替分」「按床号分」都不是随机。
- **做了随机却没做分组隐匿。** 研究者能提前猜到下一例去哪组，就可能在分配时做小动作，
  随机化的均衡性被破坏。
- **只报 PPS 不报 ITT。** 只分析「乖病人」会高估疗效（不依从往往与预后差相关），
  ITT 才反映真实世界的效果。
- **失访率超标还按 ITT 硬算。** 失访超过 10% 且两组不均衡时，结论的可信度要大打折扣。
- **把 RRR 当成临床收益。** 相对降低 50% 可能只对应 ARR 1%，务必同时报 ARR / NNT。
- **拿实验研究的结论随便外推。** 受试者经过严格筛选（代表性有限），
  真实世界里的人群更复杂，效力（efficacy）不等于效应（effectiveness）。
:::

## 小结

1. 实验流行病学 = **随机分组 + 施加干预 + 设置对照 + 前瞻观察**；
   **施加干预**是与观察性研究最本质的区别，**随机**是能确证因果的关键。
2. 两类：**临床试验**（病人、医院、治疗性）与**现场试验**（健康人、现场、预防性；
   又分个体试验与社区试验）。
3. 设计八步：PICO → 研究对象 → 样本量 → 随机化与分组隐匿 → 干预与对照 → 盲法 → 结局变量 → 收集资料。
4. **FAS / PPS / SAS** 三套数据集对应 **ITT / 依从者分析 / 接受治疗分析**；
   疗效看 FAS 与 PPS，安全性看 SAS。
5. 关键指标：**ARR、RRR、NNT**（疗效）与**保护率、效果指数**（预防）；
   **NNT = 1/ARR**，最能直接用于临床决策。
6. 优点是标准化、随机、前瞻、能下肯定结论；局限是难做、代表性有限、依从性难保证，
   并受**伦理**约束。
