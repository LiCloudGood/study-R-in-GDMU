# 第 1 章　绪论

> 这一章不教具体算法，它给整门课定坐标系：把医学问题翻译成「总体与样本、参数与统计量、变量与资料、抽样误差、概率」这套语言，并交代统计工作的四个步骤。

## 这一章要解决什么

医学数据天生带着两个麻烦：**个体变异**和**不确定性**。患同一种病的人，症状、疗效、转归可以各不相同；反过来，看起来一样的症状，背后可能是完全不同的疾病。研究者手里的每一个问题，本质上都是「面对一批有变异的数字，怎么下判断」。

- 想摸清全国成年人主要慢性病的流行状况和危险因素，人口太多、时间和经费有限，不可能全体调查，只能抽一部分人。那么：抽多少人才够？该查哪些内容？测出来的患病率能不能代表全国？
- 某药企研发了一种治疗 2 型糖尿病的新药，要评价它的有效性和安全性。那么：需要多少患者参加？怎么分组才能保证两组「除了用药不同，其它影响疗效的因素分布基本一致」？两组血糖的差别究竟是药物引起的，还是碰巧抽到的人不一样？

这两类场景（抽样调查与临床试验）都要靠统计学回答。而回答之前，得先把一批基本概念说清楚：什么是总体、什么是样本，什么能算、什么不能算，误差从哪儿来，多大的差别才值得当回事。**本章就是把这套共同语言立起来**，后面每一章的方法都建立在这些概念之上。

**现代医学之父 Osler 说过：医学是一门不确定性的科学，也是一门概率的艺术。** 说的正是这件事——生物医学里充满个体变异与不确定性，其中有些原因已知、有些未知。内在规律（必然性）总是通过大量偶然现象表现出来，统计学的任务就是透过偶然性去探测规律性，对带变异的数据作出科学推断。

## 核心概念

### 统计学与卫生统计学

**统计学是处理数据中变异性的科学与艺术**，内容包括数据的收集、整理、分析、解释和表达，目的是得到可靠的结果。把它应用到不同领域，就分出了不同分支：

| 分支 | 应用领域 | 侧重 |
| --- | --- | --- |
| 生物统计学 biostatistics | 生物学研究 | 生物测量 |
| 医学统计学 medical statistics | 医学研究 | 临床医学 |
| 卫生统计学 health statistics | 医学研究 | 预防医学与公共卫生 |

三者的边界并不严格，大量内容互相交叉。本课程里，**卫生统计学**的定义是：

> 应用概率论和数理统计学的基本原理和方法，研究居民卫生状况以及卫生服务领域中数据的收集、整理和分析的一门科学。

它是卫生及其相关领域研究中不可缺少的分析问题、解决问题的工具，也是卫生工作者从事科学研究必须掌握的一项基本功：读文献、申请课题、写论文、新药临床试验、执业医师考试与职称考试，都绕不开它。

### 观察单位、同质与变异

**观察单位**（individual），也叫个体，是统计研究中最基本的单位。它可以是一个人、一只动物、一个家庭、一个细胞，也可以是一个采样点——取决于你的研究目的。

**同质（homogeneity）**：观察对象具有相同的特征或属性。比如研究某地区 5 岁男童的生长发育情况，「该地区、男性、5 岁」就是这批对象共同具有的属性，每个男童都是同质的个体。

**变异（variation）**：同质个体之间，某项特征或属性的观察值之间的差异。同一个地区的 5 岁男童，身高、体重、血压、肺活量不可能完全一样。

两句话值得背下来：

- **没有同质性就构不成总体**——「同质」是你划定研究对象的标准；
- **总体内没有变异性就无需统计学**——所有观察值都一样，数一个就够了。

统计学的任务正是在**同质的基础上研究变异**，从而揭示事物内在的规律性。

### 总体与样本

**总体（population）** 是根据研究目的确定的**同质观察单位的全体**；更确切地说，是同质的所有观察单位某种观察值的集合。

总体按范围分两类：

- **有限总体（finite population）**：个体数有限，有特定的时间和空间范围。例如「某地 2007 年正常成年男子的脉搏数」，人、地、时间都定死了。
- **无限总体（infinite population）**：个体数无限，或几乎不可能准确计数，没有时间和空间范围的限制。例如「接受某新药治疗的所有高血压患者的疗效」，没法定出范围。

**样本（sample）** 是从总体中**随机抽取**的、具有**代表性**的部分观察单位的集合。样本包含的观察单位数称为**样本含量（sample size）**，记作 $n$。

为什么必须抽样？医学研究中的总体大多是无限总体，直接观察总体几乎不可能；即便总体有限，若个体数太多，一一观察也要耗费大量人力物力，有时根本做不到——**检验一批鸡蛋的坏蛋率，总不能把所有鸡蛋都打破**。

「随机抽取」四个字不能省：按随机化原则获取样本，才能避免研究者有意或无意地给样本带来偏性。方便取样（谁好找就问谁）得到的样本，人数再多也代表不了总体。

### 参数与统计量

| | 含义 | 记法 | 例子 |
| --- | --- | --- | --- |
| **参数（parameter）** | 反映**总体**特征的指标，一般未知 | 希腊字母 | 总体均数 $\mu$、总体率 $\pi$、总体标准差 $\sigma$ |
| **统计量（statistic）** | 由**样本**观察值算出来的指标 | 拉丁字母 | 样本均数 $\bar{X}$、样本率 $p$、样本标准差 $S$ |

参数是我们想知道却不知道的东西，统计量是我们算得出来的东西。如果样本对总体有较好的代表性，统计量就会与相应的参数比较接近，于是可以**用统计量去估计参数**。例如全国糖尿病的患病率是 4%，从 5 万人样本里算出来是 3.9%，就可以说这个样本代表性不错。

这也解释了整门课的套路：**所有推断都是从统计量出发，去猜参数**。

### 变量、变量值与资料

确定总体之后，研究者要对每个观察单位的某项特征或属性进行观察或测量：

- **变量（variable）**：观察对象的某种特征或属性，如年龄、性别、身高、体重、血型；
- **变量值（value of variable）**：对变量的测得值，也叫观察值（observed value）；
- **资料（data）**：变量值的集合。

变量按取值性质分类：

```text
变量
├── 定量变量 ── 离散型变量（如子女数、脉搏数）
│            └─ 连续型变量（如身高、体重、血压）
└── 定性变量 ── 分类变量 ── 二项分类（如性别：男 / 女）
             │           └─ 多项分类（如血型：O / A / B / AB）
             └─ 有序变量（如疗效：无效 < 好转 < 显效 < 痊愈）
```

相应地，资料分为两大类：

- **定量资料（quantitative data）**，也叫计量资料：变量值是定量的，表现为数值大小，一般有度量衡单位，如身高（cm）、体重（kg）。
- **定性资料（qualitative data）**，也叫分类资料（categorical data）：观察值是定性的，表现为互不相容的类别或属性，一般无度量衡单位。它又可细分：
  - **计数资料（count data）**：按类别清点各组观察单位数所得的资料，包括**二项分类**（性别「男/女」、化验结果「阴性/阳性」、疾病「发病/未发病」）与**无序多项分类**（血型「O/A/B/AB」）；
  - **等级资料（ordinal data）**，也叫有序多分类资料：按程度或等级顺序分组后清点个数所得的资料，各属性互不相容且有程度差别，给人「半定量」的感觉，如疗效的「治愈、显效、好转、无效」。

**资料类型的划分是相对的，彼此可以转化**：

- 定量 → 定性：血红蛋白测出来是数值，按「正常/异常」分就是二项分类资料，按「重度/中度/轻度/正常/增高」分就是等级资料；
- 定性 → 定量：健康状况的「非常好、较好、一般、差、非常差」本是等级资料，若赋值成 5、4、3、2、1，就可以按定量资料处理；性别编码成 0/1，疗效编码成 0、1、2、3 也是同理。

为什么要这么在意类型？因为**不同类型的资料要用不同的统计方法**——定量资料可以算均数、做 t 检验，计数资料只能算率和构成比、做卡方类检验，等级资料通常用秩和检验。判断错类型，后面整套方法就选错了。

### 抽样研究与抽样误差

**抽样研究（sampling research）**：从总体中随机抽取样本，用样本信息推断总体特征的研究方法。

**抽样误差（sampling error）**：由随机抽样造成的**样本统计量与总体参数之间**、以及**样本统计量之间**的差异。它的根源是**个体变异**——只要个体之间有差异，抽到的样本就不可能和总体分毫不差，两次抽样也不会得到完全一样的统计量。

所以抽样误差有两个要点：**它是不可避免的**，但在抽样研究中**有规律可循**，可以用统计方法估计其大小。样本均数的标准误就是常用的度量：

$$S_{\bar{X}} = \frac{S}{\sqrt{n}}$$

其中 $S$ 是样本标准差，$n$ 是样本含量。样本越大，抽样误差越小——但注意，它只会变小，不会消失。

别忘了误差的更大家族（后面讲测量与质量控制时会反复用到）——**误差**指观察值与真实值之间的差异，按性质分两类：

- **随机误差**：不恒定、随机变化的误差，包括随机测量误差和随机抽样误差，**不可避免**；
- **非随机误差**：系统误差（有方向性，可通过设计、校准、盲法等措施消除或减小）和过失误差（记录错、抄错，属于人为失误）。

### 概率与小概率事件

**概率**（probability）是随机事件发生可能性大小的数值度量，常用 $P$ 表示，事件 A 的概率记为 $P(A)$。

$$0 \le P(A) \le 1$$

- $P(A)=0$：不可能事件；
- $P(A)=1$：必然事件；
- $0<P(A)<1$：随机事件，$P$ 越接近 1 发生的可能性越大。

概率怎么理解？想想比赛前裁判掷硬币：我们相信正面和反面出现的概率都是 0.5。历史上有人真的掷过很多次——掷 4040 次时正面比例是 0.5069，掷 10000 次时是 0.5067，掷 24000 次时是 0.5005。次数越多，比例越贴近 0.5。这说明**概率的估计以足够大的样本含量为前提**：在相同条件下独立重复无数次，某事件发生次数的比例才是它的概率。

$$P(A) = \lim_{n \to \infty} \frac{m}{n} \quad (m \text{ 为 } n \text{ 次重复中 } A \text{ 发生的次数})$$

**小概率事件（small probability event）**：当 $P(A) \le 0.05$ 时，统计学中习惯这样称呼它，意思是**在一次实验或观察中，该事件发生的可能性很小，可以视为很可能不发生**。这个约定是后面假设检验的基石——算出 $P \le 0.05$ 就拒绝 $H_0$，靠的正是「小概率事件在一次试验中几乎不会发生」这一条。

**想一想**：某研究者调查所在地区居民对设置家庭病床的认同态度，从居民小区中随机抽了三个小区，却只在小区的**大门口**拦住出入的居民发问卷，结果得出「该地区居民认为不需要设置家庭病床」。

这个结果可靠吗？问题出在哪？

---

家庭病床主要面向长期患病或不能自由活动的老人，因此目标人群是老人以及与他们关系密切的家庭成员。而经常出入小区的大多是相对年轻、能自由活动的人，只调查他们，数据从一开始就有偏差；此外还可能对同一家庭的多名成员重复调查，而家人对这类问题的态度往往相似或趋同，又会加重偏差。这个研究目标人群不明确、收集资料的方式也不妥当（该入户调查却只在门口拦人），结论不可靠。

**要点**：样本「随机」不等于样本「有代表性」——抽样框和调查方式错了，随机化也救不回来。

## 统计工作的四个步骤

统计工作分为**设计、收集资料、整理资料、分析资料**四步。它们不是四个独立环节，而是紧密衔接的整体，任何一步出问题都可能让整个研究白做。

### 一、设计（design）

设计是第一步，也是**最关键的一步**，关系到整个研究的成败。它指制定周密的研究计划，包括资料收集、整理和分析全过程的总体设想和安排，一般含专业设计和统计设计两部分，可分为调查设计、实验设计和临床试验设计。

一句话说明它的分量：**做完实验后才找统计学家，无异于请他做尸体解剖——他能做的全部事情，就是告诉你这个实验死于什么原因。** 如果统计设计本身有缺陷，再高深的方法也于事无补，统计分析只是数字游戏。很多研究者不重视设计，等数据收完了才去咨询统计人员，那时已经来不及了。所以研究之前一定要查阅文献、必要时咨询统计学专业人员、做好周密设计。

### 二、收集资料（collection of data）

设计完成后进入实施阶段，目标是取得**真实、可靠的原始数据**。资料来源大致三类：

1. **统计报表**：国家法定或统一设计的报表（卫生工作报表、传染病报表、职业病报表、医院工作报表等），由有关医疗卫生机构定期逐级上报，要求**完整、准确、及时**；
2. **日常工作记录**：病历、经常性的卫生监测记录、健康检查记录等；
3. **专题调查或实验**：针对某个专题开展的调查或实验研究所收集的资料。

### 三、整理资料（sorting data）

原始资料通常杂乱无章，需要清理，使其系统化、条理化，便于进一步统计分析。内容包括**检查核对、设计分组、汇总并列出整理表**，一般借助计算机软件完成。录入之前还要对数据编码，比如用 1 代表男性、2 代表女性，或用 M、F 表示。

::: tip 在 R 里这一步叫什么
数据清洗、类型转换、缺失值与异常值处理，都属于「整理资料」。比如把性别那一列从字符串转成因子、把有序的疗效水平指定好顺序，就是在为后面的分析铺路。
:::

### 四、分析资料（analysis of data）

根据研究目的计算指标、描述数据的基本特征，选择适当的统计方法进行分析，阐明事物的内在联系和规律。统计分析分两部分：

- **统计描述（descriptive statistics）**：用统计指标、统计表、统计图等，对资料的数量特征及其分布规律进行测定和描述；
- **统计推断（inferential statistics）**：根据样本信息，用恰当的统计方法推断总体的特征，包括**参数估计**和**假设检验**。

后续章节要学的 t 检验、z 检验、方差分析、卡方检验、秩和检验、双变量关联性分析、直线回归、对数秩检验、多重线性回归、logistic 回归、Cox 比例风险回归、Meta 分析等，都属于统计推断的工具箱。

## 在 R 里怎么做

本章几乎没有公式，但概念必须落到手上才算学会。下面用 R 自带的数据集 `faithful`（美国黄石公园老忠实间歇泉 272 次喷发的记录）算一遍**统计量**，体会「用样本统计量估计总体参数」。

```r
# 样本：每次喷发的持续时间（分钟），共 272 次观测
x <- faithful$eruptions

n    <- length(x)        # 样本含量 n
xbar <- mean(x)          # 样本均数 X̄ —— 统计量，用来估计总体均数 μ
s    <- sd(x)            # 样本标准差 S
se   <- s / sqrt(n)      # 样本均数的标准误，抽样误差大小的度量

n; xbar; s; se
```

输出怎么读：

- `n` 为 `272`，这是样本含量；
- `xbar` 约 `3.488`，是样本均数——注意它是**统计量**，不是参数，换个样本它就会变；
- `s` 约 `1.141`，反映喷发时长的变异程度；
- `se` 约 `0.069`，比 `s` 小了十几倍，说明**均数的抽样误差远小于个体间的变异**，而且样本越大它越小。这就是为什么「多抽点人」能提高估计精度，也是后面参数估计一章的出发点。

变量类型决定了能算什么。用 `str()` 看一眼数据结构，是分析前的第一件事：

```r
str(faithful)   # 272 obs. of 2 variables：eruptions 与 waiting 都是数值型（num）
```

定性变量和等级变量在 R 里用**因子**（factor）表示；等级变量还要显式说明水平的先后顺序，否则 R 只会把它当无序类别：

```r
# 无序多分类变量
blood <- factor(c("O", "A", "B", "O", "AB"))
table(blood)                 # 清点各类别个数 —— 计数资料的整理

# 有序分类变量（等级资料）：用 ordered = TRUE 并给出水平顺序
effect <- factor(c("好转", "痊愈", "无效", "显效"),
                 levels = c("无效", "好转", "显效", "痊愈"),
                 ordered = TRUE)
effect
# [1] 好转 痊愈 无效 显效
# Levels: 无效 < 好转 < 显效 < 痊愈
```

`levels` 的顺序就是等级资料里「程度」的顺序，顺序定错，后面秩和检验之类的结论就会反。顺手看一眼本页涉及的基础函数：`mean()`、`sd()`、`length()`、`table()`、`factor()`、`str()`——都是操作向量和数据框的通用工具。

## 容易踩的坑

- **资料类型判断错，整套方法就选错。** 等级资料（如「无效、好转、显效、痊愈」）虽然可以编码成 0、1、2、3，但那只是排序用的标签，不能当定量资料算均数，也不能说「显效比好转好 1 个单位」；反过来，定量资料一旦并成等级，就丢掉了数值信息。类型决定了你后面能用哪些方法。
- **把「总体」当成随手抓到的一批人，以为样本够大就没问题。** 总体是由研究目的界定的同质观察单位全体：某地、某年、某年龄段、正常成年男子——地点、时间、人群三个限定词缺一不可；研究目的改了，总体就变了。另外，「方便样本」（在门口拦人、只查好找的人）人数再多也是有偏的，它带来的是偏倚，不是靠大样本就能摊平的抽样误差——抽样误差源于个体变异，不可避免，只能通过合理设计和增大样本含量来减小。
- **把统计量当参数用。** $\bar{X}$、$p$ 是从数据里算出来的，$\mu$、$\pi$ 是未知的、算不出来的。写论文时「本样本患病率为 3.9%」和「总体患病率为 3.9%」是两句完全不同的话，后者需要区间估计支撑。
- **用构成比代替率，直接比数字大小下结论。** 「64 例银屑病患者中 O 型血占 46.88%，居首位，所以 O 型的人最容易得银屑病」是站不住脚的：算的是患者的血型构成比，而不是各血型人群的患病率。同样，抽样调查里两个率（如男性 0.55% 与女性 0.33%）看起来不同，也不能直接下「谁更高」的结论——这中间的差别可能只是抽样误差，必须做假设检验。
- **等数据收完再找统计学。** 设计阶段就要定好样本含量、分组方式、观察指标和统计方法。到了分析阶段才发现样本量不够、关键变量没测、两组不可比，是任何方法都补不回来的。

## 小结

1. **统计学是处理数据中变异性的科学与艺术**；卫生统计学 = 概率论与数理统计学的基本原理和方法，用在居民卫生状况与卫生服务领域的数据收集、整理和分析上，偏向预防医学与公共卫生。
2. **四个基本概念必须分清**：同质是个体可比的前提、变异是统计学存在的理由；总体由研究目的界定（分有限/无限），样本靠随机抽取获得代表性；参数属于总体、未知，统计量属于样本、可算；同质基础上的个体差异 → 抽样误差不可避免但有规律。
3. **变量分定量与定性，定性再分分类与有序**；资料相应分为定量资料、计数资料、等级资料。类型是相对的、可以相互转化，但**类型决定统计方法**。
4. **概率度量随机事件发生的可能性**，$0 \le P(A) \le 1$；概率要以足够大的重复次数为前提；$P \le 0.05$ 的事件称为小概率事件，在一次试验中可视为几乎不发生——这是假设检验的基石。
5. **统计工作四步：设计 → 收集资料 → 整理资料 → 分析资料**。设计最关键，统计设计有缺陷，后面做什么都补不回来；分析分统计描述与统计推断两部分。在 R 里，这四步的动手形态就是：`str()` 看清数据结构、`mean()`/`sd()`/`length()` 算统计量、`factor()` 把定性变量做成因子、`ordered = TRUE` 给等级变量定好顺序。
