# 流行病学

欢迎光临 **《流行病学》**！

本板块按课程章节整理，共 7 章。写法与其他板块一致：每一章讲清楚
「这一章解决什么问题、核心概念是什么、指标怎么算、容易踩什么坑」，
并在末尾指向《卫生统计学》《信息技术基础》里对应的内容。

::: tip 读法建议
流行病学的章节是**一条线**，不是并列的知识点：

**描述**（疾病在人群里怎么分布）→ **提出假设** → **分析**（队列 / 病例对照，检验假设）
→ **排除偏倚** → **因果推断**（这些关联能不能算作因果）→ **实验**（最后确证）。

所以第 3~6 章最好连着读：队列研究和病例对照研究是「怎么找关联」，
偏倚和因果推断是「找到的关联能不能信、能不能算因果」。
:::

## 四大研究方法的关系

| 方法 | 研究者做什么 | 时间方向 | 能否确定因果 |
| --- | --- | --- | --- |
| **描述性研究** | 只观察、只描述分布 | 横断面 | 不能 |
| **分析性研究** | 观察 + 设对照 + 比较 | 前瞻或回顾 | 较强 / 较弱 |
| **实验性研究** | 人为施加干预 + 随机分组 | 前瞻 | 最强 |
| **理论性研究** | 建立数学模型 | — | — |

> 一条主线：**描述提出假设 → 分析检验假设 → 实验证实假设**。

## 关于「筛检与诊断试验」

课程的这一章讲的是**怎么评价一个检查手段准不准**（灵敏度、特异度、预测值、ROC、联合试验），
它和《卫生统计学》已有的「诊断试验评价」专题是同一件事。

为避免两处讲重复，本站把它**并入**
[卫生统计学 · 诊断试验评价](/Health-statistics/diagnostic-test)，
并在那里补上了联合试验、似然比、样本量等内容。
