# 第 1 章　流行病学概论

> 临床医学看**一个人**，流行病学看**一群人**。这一章要立的是这门学科的「坐标系」：研究对象是谁、研究什么、用什么词描述、按什么原则做研究。

## 这一章要解决什么

同样是「高血压」，两种问法完全不同：

- 临床医生问：**这位**患者血压多少、该吃什么药？
- 流行病学要问：**这个地区**有多少人血压高？**哪些人**更容易高？**为什么**？**怎么防**？

前一个问题靠个体诊断回答，后一个问题需要**群体**才行——而且答案不是看一两个人，而是看分布、看比例、看对比。
这就引出了这门学科的两个本质概念：**人群**和**分布**。

## 定义：一句话里有四个要害

> **流行病学**是一门研究**人群中疾病与健康状况的分布及其影响因素**，
> 并研究和制定**防制疾病及促进健康的策略和措施**的科学。

这句话短，但每个成分都在定义这门学科：

| 成分 | 说的是什么 | 对应的问题 |
| --- | --- | --- |
| **人群** | 研究对象不是个体，是群体 | who |
| **疾病与健康状况的分布** | 研究内容与核心方法 | when / where / who |
| **分布的影响因素** | 找病因与危险因素 | why |
| **策略和措施** | 最终目的：防制疾病、促进健康 | how |

### 第一个本质概念：人群

群体的特征是流行病学**区别于其他医学学科最显著的标志**。
流行病学是从群体的角度宏观地认识疾病和健康的状态。

> 临床上实施的是**个体诊断**；流行病学实施的是「**群体诊断**（mass diagnosis）」。

### 研究内容的三个层次

| 层次 | 具体包括 |
| --- | --- |
| **疾病** | 传染病、寄生虫病、地方病、非传染性疾病等一切疾病 |
| **伤害** | 意外、残疾、智障、身心损害等 |
| **健康** | 身体生理生化的各种机能状态、疾病前状态、长寿等 |

注意这里的「健康」也是研究内容——流行病学不只研究「病」，也研究「没病」和「亚健康」。

### 第二个本质概念：分布

**分布**（distribution）指疾病在不同**人群**、不同**时间**、不同**地区**的存在状态及其发生发展规律，
合称「**三间分布**」：

| 维度 | 问的是 | 对应 |
| --- | --- | --- |
| **人间分布**（人群分布） | 哪些人容易得？ | **who** |
| **时间分布** | 什么时候多？ | **when** |
| **空间分布**（地区分布） | 哪里多？ | **where** |

### 分布的影响因素

分布的影响因素指的就是**病因和危险因素**。**研究病因和危险因素是流行病学最重要的任务。**

于是定义里的四个问句就串起来了：**分布回答 who / when / where，影响因素回答 why，
策略措施回答 how。**

## 用 6 个 W 概括基本任务

流行病学研究的基本任务，可以用 6 个 W 概括：

| 6W | 含义 |
| --- | --- |
| **who** | 什么人 |
| **when** | 在何时 |
| **where** | 何地 |
| **what** | 发生何事 |
| **why** | 为什么发生 |
| **how** | 如何处理 |

最终达到**预防和控制疾病、增进人群健康**的目的。

> 记住这条主线：**揭示现象（分布）→ 找出原因（影响因素）→ 提供措施（策略与措施）**。
> 这也是流行病学任务的三个阶段。

## 五大基本原理

这五条是这门学科的「世界观」：

| 原理 | 核心意思 |
| --- | --- |
| **疾病分布论** | 疾病在不同人群（人群、时间、地区特征）中的发生是**非随机**的，因此可以通过描述分布来阐明流行特征 |
| **病因论** | 任何疾病的病因都**不是单一的**，而是多种原因综合作用的结果；这些原因及其相互关系是复杂、多样、可变的——**多因论、概率论**的观点逐渐被接受 |
| **健康—疾病连续带理论** | 个体从健康到疾病是一个**连续过程**；群体同样如此，在「健康高分布（问题低分布）」与「健康低分布（问题高分布）」之间连续移动 |
| **疾病预防控制论** | 根据疾病发生、发展和健康状况变化的规律，预防控制可以采取**三级预防策略** |
| **疾病流行数理模型** | 疾病与健康受机体、环境、社会等多因素影响，其间存在一定函数关系，可用**数学模型**描述其变化规律，并在一定条件下预测未来趋势 |

## 四条基本原则

这四条是「做研究时的纪律」：

| 原则 | 含义 | 违反了会怎样 |
| --- | --- | --- |
| **群体原则** | 从人群的各种分布入手，把分布作为研究一切问题的出发点 | 退化成个体研究，失去流行病学意义 |
| **现场原则** | 人群是生活在社会中的人群，必须把人群与周围环境（社会环境、自然环境）联系起来 | 脱离现场的人群对流行病学毫无意义 |
| **对比原则** | **流行病学的核心是比较**——只有通过对比，才能发现病因、考察诊断正确性和治疗有效性 | 没有对照，描述结果说明不了任何问题 |
| **代表性原则** | 样本必须具有代表性，结论才能推论到总体 | 结论不能外推 |

关于**代表性**要说清楚：样本要有代表性需满足两条 —— **样本的产生是随机的**，
以及**样本量要足够大**。两条缺一不可。

> 「对比原则」是最容易被忽略的一条。即使只是一般的描述结果，
> **也必须与相应人群、时间和地点的结果相比较才能说明问题** —— 孤立的一个率没有意义。

## 研究方法：三步走

流行病学的方法体系可以概括为三个递进的阶段：

```
提出假设  →  检验假设  →  证实假设
（描述）      （分析）      （实验）
```

| 阶段 | 对应研究方法 | 回答什么 |
| --- | --- | --- |
| **提出假设** | 描述性研究（现况研究、生态学研究等） | 分布是什么样？可能有什麼原因？ |
| **检验假设** | 分析性研究（病例对照研究、队列研究） | 这个因素和疾病真的有关吗？关联多强？ |
| **证实假设** | 实验性研究（临床试验、现场试验） | 干预它，疾病会减少吗？ |

此外还有**理论性研究**（数学模型），既不属于观察也不属于实验。
所以按大类分，流行病学研究方法一般分为**观察性研究、实验性研究、理论性研究**三类。

> 这条主线是整门课的骨架，后面每一章都挂在这三步上。

## 研究设计的七个基本内容

一项流行病学研究在设计阶段要依次想清楚七件事：

1. **明确研究目的** —— 目的要具体、可望又可及；
2. **确定研究内容** —— 研究内容是说明目的的要素，是论证结论的依据；范围与指标多少都要适当；
3. **选择研究方法** —— 根据目的与内容选（观察 / 实验 / 理论），可单用一种，也可几种联合；
4. **选择研究对象** —— 明确规定纳入标准与排除标准，并考虑依从性；
5. **设计调查表格** —— 把研究内容具体化为标准提问形式，它既是现场工作的提纲，也直接决定资料质量；
6. **保证研究质量** —— 研究的各个环节都可能存在**偏倚或混杂因素**，设计阶段就要包含质量控制措施
   （既有组织措施，也有防偏倚的技术措施）；
7. **得出正确结论** —— 理顺分析思路：分组要在医学上合理、在逻辑上成立，再选恰当的统计方法。

> 第 6 条值得单独记：**质量控制必须设计在前，不能靠事后补救。**

## 用途

流行病学的用途可以列五条：

1. **描述人群中疾病及健康状况的分布** —— 最基本、最常用；
2. **探讨疾病的病因和危险因素** —— 这是最重要的任务；
3. **完整揭示疾病自然史** —— 从暴露到发病、转归的全过程；
4. **疾病预防及控制效果的评价** —— 措施有没有效，要靠对比；
5. **疾病预防** —— 把前面的结论落到干预上。

## 常见误区

::: warning 五个容易踩的坑
- **把流行病学当成「统计方法课」。** 统计是工具；流行病学关心的是**设计、因果与人群**。
  同样的卡方检验，用在横断面资料和队列资料上，能得出的结论强度完全不同。
- **用个体推论群体，或用群体推论个体。** 群体诊断不等于个体诊断；
  群体水平的关联推到个体可能完全失效（**生态学谬误**，见第 6 章）。
- **只描述、不对比。** 「某地发病率 3%」这句话本身没有信息量，必须跟什么比才成立。
- **以为「分布」只是列表画图。** 三间分布是**提出病因假设的主要来源**，
  不是「描述一下就完了」的准备工作。
- **忘了「健康」也是研究内容。** 定义里写的是「疾病与**健康状况**」，不只是病。
:::

## 小结

1. 流行病学的研究对象是**人群**，核心概念是**分布**，最终目的是**防制疾病、促进健康**。
2. 定义可拆成四块：人群、分布、影响因素、策略措施（对应 who / when / where / why / how）。
3. **三间分布** = 人间（who）+ 时间（when）+ 空间（where）。
4. 五大原理：疾病分布论、病因论、健康—疾病连续带、疾病预防控制论、流行数理模型；
   四条原则：群体、现场、对比、代表性。
5. 方法三步：**提出假设（描述）→ 检验假设（分析）→ 证实假设（实验）**。
6. 五条用途：描述分布、探讨病因、揭示自然史、评价效果、疾病预防。
