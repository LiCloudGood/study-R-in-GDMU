# 第 4 章　定量资料的统计描述

> 拿到一列测量值，先用频数表和频数图看清分布长什么样，再用「集中趋势 + 离散趋势」两组指标把它概括成几个数，最后借正态分布的规律算出比例、定出医学参考值范围。

## 这一章要解决什么

身高、体重、血压、潜伏期、抗体滴度……这些指标测出来的每一个值都是数，有大小、有单位，这类资料叫**定量资料**（也叫计量资料）。一次调查测了 120 个 10 岁男孩的身高，得到 120 个数；一篇论文写出来，不可能把 120 个数全列上，读者也不关心第 37 个人是 143.6 cm。

于是问题变成：**怎样用最少的几个数，把这批数据的数量特征说清楚？** 反过来，当我们看到「某地 10 岁男孩平均身高 143.35 cm、标准差 4.79 cm」时，也要能判断这组数说明数据集中在哪里、彼此差多少。

第一步永远是看分布：把原始数据整理成频数表、画成直方图，先弄清它是对称还是偏态。第二步才是算指标——描述**集中趋势**（平均水平在哪）和**离散趋势**（各人之间差多少）的指标必须成对报告，只给一个是不完整的：两组动物的平均进食量都等于 28 mg/g，但一组基本都在 28 附近，另一组却有一个 64，这两组数据的「28」含义完全不同。

这套描述性指标还是后面所有推断的基础：t 检验、方差分析、相关回归都要求资料近似正态，而判断正态与否用的正是这一章的标准差 $s$、均数 $\bar x$，以及正态分布的面积规律。

## 核心概念

### 频数表：把一列数排成分布

**频数**（frequency）是某个取值（或某个组段）出现的次数。把变量取值和它的频数列成一张表，就是**频数分布表**，简称**频数表**。连续型定量资料一般先分组再计数，编制分四步：

1. **求极差**。找出一组观察值中的最大值与最小值，两者之差即极差（全距），记作 $R$。例：120 名 10 岁男孩身高最大值 155.4、最小值 130.2，$R = 25.2$。
2. **确定组数和组距**。组数按样本含量和研究目的定，一般取 8～15 组（样本小时可少些，大时可多些）。组距 $i = R \;/\; 组数$，再取一个整齐的数值。上例 $25.2 \div 10 = 2.52$，取组距 $i = 2$。
3. **确定组段**。每个组段的起点叫**下限**、终点叫**上限**，各组的上、下限之差等于组距。第一组段必须包含最小值（所以下限取略小于或等于最小值的整数，上例取 130），最后一段必须包含最大值。每个组段包含的数值范围是「大于等于下限、小于上限」，为避免重叠，**除最后一段同时写出上下限外，其余组段只写下限**：130~、132~、134~、……、154~156。
4. **归组计数，整理成表**。把每个观察值归入相应组段，得到频数；由此再算出**频率**、**累计频数**和**累计频率**。

离散型定量资料的变量值不连续，不必分组，直接列出各个取值及其频数即可。

频数表有三个用途：

- **揭示频数分布的特征和类型。** 特征指**集中趋势**（多数人身高集中在中间组段）与**离散趋势**（由中间组段向两侧频数逐渐减少）两个方向；类型指**对称分布**与**偏态分布**。高峰偏在数值小的一侧叫**正偏态**（右侧拖着长尾），偏在数值大的一侧叫**负偏态**（如冠心病、恶性肿瘤等慢性病患者的年龄分布）。分布类型不同，后面该选哪种平均数、哪种变异指标、哪种检验方法都不同。
- **便于进一步计算指标。** 有了频数表才能用加权法算均数、标准差，才能用频数表法算中位数和百分位数。
- **便于发现可疑值。** 某个远离人群的组段里孤零零地有 1、2 个观察值，往往提示记录错误或有特殊个体，需要回头核对。

### 频数图：直方图与直条图

以变量值为横坐标、频数为纵坐标（等距分组时纵坐标也可以改用频率；不等距分组时要用「频率／组距」作纵坐标，否则高度不能直接比较）画出的图形就是**频数图**，每个长方形的面积代表该组的频数（或频率）。

连续型资料的频数图中各长方形相连，叫**直方图**（histogram）；离散型资料的变量值不连续，长方形之间留有空隙，叫**直条图**（bar graph）。频数图和频数表用途相同，但表达分布特征和类型更直观；两者常常一起给出。

### 集中趋势（一）：算术均数

**算术均数**（arithmetic mean），简称**均数**，是一组同质观察值相加再除以观察值个数，反映平均水平或集中位置。样本均数记作 $\bar x$，总体均数记作 $\mu$。

样本含量较小时用直接法：

$$\bar x = \frac{x_1 + x_2 + \cdots + x_n}{n} = \frac{\sum x}{n}$$

其中 $\sum$（读作 sigma）是求和符号，$n$ 是样本含量。

相同观察值较多或资料已编成频数表时用**加权法**：把每个组段的**组中值**（组段上、下限之和的一半）当作该组所有观察值的代表，再按频数加权：

$$\bar x = \frac{\sum f_i x_i}{\sum f_i}$$

其中 $k$ 为组段数，$x_i$ 为第 $i$ 组的组中值，$f_i$ 为该组频数。上例身高资料代进去：$\bar x = 17202 / 120 = 143.35$ cm。

**适用条件**：均数适用于**对称分布、特别是正态分布**的资料。此时均数位于分布正中，既表示集中位置，又表示数量上的平均水平。资料明显偏态时均数会被长尾上的极值拽走，不再代表「大多数人的水平」。

### 集中趋势（二）：几何均数

抗体滴度 1/4、1/8、1/16、1/32、1/64、1/128、1/256 这样一组数，各值之间是**倍数**关系，最大值是最小值的 64 倍。若把滴度取倒数后直接算均数，得到 72.5，还原成滴度就是 1/72.5：7 个滴度里有 5 个都比它大，说明这个平均数被 128、256 这两个较大的数值拽偏了，代表性很差——均数对个别极端值太敏感。

**几何均数**（geometric mean，记作 $G$）是 $n$ 个观察值乘积的 $n$ 次方根，又称**倍数均数**，正好适合这种数据：

$$G = \sqrt[n]{x_1 x_2 \cdots x_n}$$

实际计算时先取对数（把乘法变成加法），求出对数的均数，再取反对数还原：

$$G = \lg^{-1}\!\left(\frac{\sum \lg x}{n}\right)$$

已编成频数表的资料用加权法：

$$G = \lg^{-1}\!\left(\frac{\sum f_i \lg x_i}{\sum f_i}\right)$$

上例：$\lg^{-1}(10.5361/7) = \lg^{-1}(1.5052) = 32$，即 7 个人的平均滴度为 1/32。50 名麻疹易感儿接种疫苗后的血凝抑制抗体滴度资料中 $\sum f_i \lg x_i = 86.9977$，用加权法算得 $G = \lg^{-1}(86.9977/50) = \lg^{-1}(1.7400) \approx 54.9$，平均滴度约为 1/55。

**两条使用前提**（非常重要）：

1. 适用于**对数对称分布（含对数正态分布）**的资料，即数据取对数后成对称或正态分布；也适用于**等比级数资料**，即观察值之间呈倍数或近似倍数变化，如抗体滴度、抗体效价。
2. 计算时观察值中**不能有 0，也不能同时有正有负**——0 没有对数，正负号混在一起时「乘积开方」也没有实际意义。

滴度资料通常先取倒数变成 4、8、16、32……再算几何均数，这也是上面例子里绕个弯的原因。

### 集中趋势（三）：中位数与百分位数

把观察值从小到大排成一列，位于中间位置的那个数就是**中位数**（median，记作 $M$）。它是一种**位置平均数**：小于它和大于它的观察值各占一半。

**百分位数**（percentile，记作 $P_x$）是把有序数列平均分成 100 等份后，对应第 $x$ 个分割位置的数值。理论上 $x\%$ 的观察值比 $P_x$ 小，$(100-x)\%$ 比它大。中位数就是第 50 百分位数：$M = P_{50}$。$P_{25}$、$P_{50}$、$P_{75}$ 把全部观察值四等分，合称**四分位数**，其中 $P_{25}$ 叫下四分位数 $Q_L$，$P_{75}$ 叫上四分位数 $Q_U$。

**直接法**（观察值个数较少时）：先将数据排序，奇数个取中间那个，偶数个取中间两个的平均：

$$M = x_{\left(\frac{n+1}{2}\right)} \qquad M = \frac{1}{2}\left(x_{\left(\frac{n}{2}\right)} + x_{\left(\frac{n}{2}+1\right)}\right)$$

例：10 只小白鼠染毒后的生存时间（分钟）排序后为 35、60、62、63、63、65、66、68、69、69，$n$ 为偶数，$M = (63+65)/2 = 64$ 分钟。

**频数表法**：先在频数表里找到中位数所在的组段（累计频率第一个超过 50% 的那一段），再在该组段内按比例插值：

$$M = L + \frac{i}{f_M}\left(\frac{n}{2} - \sum f_L\right)$$

其中 $L$ 为该组段下限，$i$ 为组距，$f_M$ 为该组段频数，$\sum f_L$ 为小于 $L$ 的各组段累计频数。200 名食物中毒患者的潜伏期资料中，累计频率 50.5% 是第一个大于 50% 的值，说明 $M$ 落在「12~」组段：

$$M = 12 + \frac{12}{71}\left(\frac{200}{2} - 30\right) = 23.8\;(\text{小时})$$

其他百分位数把 $n/2$ 换成 $n \cdot x\%$ 即可，中位数公式是它取 $x=50$ 的特例：

$$P_x = L + \frac{i}{f_x}\left(n \cdot x\% - \sum f_L\right)$$

同一批资料：$P_{25} = 12 + \frac{12}{71}(200\times 25\% - 30) = 15.4$ 小时，$P_{75} = 24 + \frac{12}{49}(200\times 75\% - 101) = 36.0$ 小时。

**适用条件**：中位数常用于描述①偏态分布资料；②频数分布的一端或两端**没有确切数值**的资料（如「>5 年」「<0.1」这类开口数据）；③总体分布不明的资料。百分位数则用来描述某个百分位置上的水平，多个百分位数合起来能较全面地刻画分布，也是制定非正态资料参考值范围的工具；但它要求样本含量足够大，否则不宜取太靠近两端的百分位数。

### 集中趋势怎么选：一张判据表

| 资料的分布特点 | 该用的集中趋势指标 | 该用的离散趋势指标 |
| --- | --- | --- |
| 对称分布，特别是正态分布 | 算术均数 $\bar x$ | 标准差 $s$（或方差 $s^2$） |
| 偏态分布；一端或两端无确切值；分布不明 | 中位数 $M$ | 四分位数间距 $Q$ |
| 对数正态分布；等比级数资料（滴度、效价） | 几何均数 $G$ | 对数变换后的标准差再取反对数（几何标准差） |

判断「该用哪个」的顺序是：先看图形和专业背景 → 不明确就做正态性检验 → 偏态或开口数据直接上中位数 + 四分位数间距。**别用均数去描述明显偏态的数据**，那是最常见的错误。

因为滴度值之间是倍数关系，最大值与最小值差了 64 倍；取倒数后直接算均数得到 72.5，它被 128、256 这两个大数值「拉」高了（7 个倒数里有 5 个都比它小），代表性很差。

### 离散趋势（一）：极差

只有集中趋势不够。看两组各 9 只动物的每日进食量：A 组是 24、25、…、32，B 组是 20、21、…、27、64，两组均数都是 28 mg/g。但 A 组数据分布对称、极差只有 8，B 组极差达 44，中间还夹着一个离群的 64——「28」对 A 组有代表性，对 B 组没有。

**极差**（range，记作 $R$），亦称**全距**，是一组同质观察值中最大值与最小值之差：

$$R = x_{\max} - x_{\min}$$

极差大说明数据分散，小说明集中。它计算最简单，但有两个硬伤：①**只用到最大和最小两个值**，组内其他观察值的变异完全没反映；②**样本含量越大，抽到极端值的可能性越大**，极差就越大——所以样本含量相差悬殊时，不能用极差直接比较。它一般只用来初步了解数据大致在什么范围内。

### 离散趋势（二）：四分位数间距

**四分位数间距**（inter-quartile range，记作 $Q$）是上四分位数与下四分位数之差：

$$Q = Q_U - Q_L = P_{75} - P_{25}$$

从位置上看，它是**中间 50% 观察值的极差**，所以基本不受两端个别极值的影响，比极差稳定。潜伏期例中 $Q = 36.0 - 15.4 = 20.6$ 小时。

**适用条件**：与中位数配对使用，常用于偏态分布资料，以及一端或两端无确切数值的资料。它的缺点是不能概括全部观察值的变异（两头各 25% 的数据它管不到）。

### 离散趋势（三）：方差与标准差

极差只用两个数、四分位数间距只用中间一半，要**全面**利用每个观察值，就得看每个值与均数差多少。这个差 $(x - \mu)$ 叫**离均差**。但离均差有正有负，$\sum (x-\mu) = 0$ 恒成立，直接相加没有意义；于是改成**离均差平方和** $\sum (x-\mu)^2$（记作 $SS$ 或 $l_{xx}$），再除以观察值个数，得到总体**方差**：

$$\sigma^2 = \frac{\sum (x - \mu)^2}{N}$$

方差可以理解成「每个观察值离均差平方的平均水平」：它越大，说明数据围绕均数分布得越分散。

实际工作中 $\mu$ 未知，只能用样本均数 $\bar x$ 代替，这时若分母仍用 $n$，算出来的结果总是偏小。改用 $n-1$ 作分母便可校正，得到样本方差：

$$s^2 = \frac{\sum (x - \bar x)^2}{n - 1}$$

式中 $n-1$ 称为**自由度**（degree of freedom）：$n$ 个离均差受「$\sum (x-\bar x)=0$」这一个条件的约束，能自由取值的只有 $n-1$ 个。

方差的问题是**单位被平方了**（cm²、mmol²/L²），和原始数据没法直接比较。开平方之后就回到原来的度量单位，这就是**标准差**：

$$\sigma = \sqrt{\frac{\sum (x-\mu)^2}{N}} \qquad s = \sqrt{\frac{\sum (x-\bar x)^2}{n-1}}$$

标准差表示每个观察值与均数之间（绝对）距离的平均水平。实际计算常用下面这个恒等变形，少算一步均数：

$$s = \sqrt{\frac{\sum x^2 - \dfrac{(\sum x)^2}{n}}{n-1}}$$

频数表资料则用组中值和频数加权：

$$s = \sqrt{\frac{\sum f_i x_i^2 - \dfrac{(\sum f_i x_i)^2}{\sum f_i}}{\sum f_i - 1}}$$

**适用条件**：方差和标准差都适用于**对称分布、特别是正态或近似正态分布**资料的离散程度。标准差越大，数据围绕均数越分散。报告时均数和标准差要成对写：$\bar x \pm s$。

### 离散趋势（四）：变异系数

看两个问题：

- 5 岁男孩身高均数 115.8 cm、标准差 4.5 cm，体重均数 20.2 kg、标准差 0.56 kg。因为 $4.5 > 0.56$ 就说「身高的变异程度比体重大」——**错**，身高和体重**单位不同**，标准差不能直接比。
- 小白鼠体重均数 22.1 g、标准差 3.2 g；家兔体重均数 1525.3 g、标准差 101.4 g。单位相同，但家兔的标准差大就说明家兔变异大吗？——**也错**，两组均数相差太悬殊（差 69 倍），标准差是绝对量，不能直接比。

这时要用**变异系数**（coefficient of variation，$CV$），即标准差与均数之比：

$$CV = \frac{s}{\bar x} \times 100\%$$

它是**相对**变异指标，没有单位，反映「变异相对于均数有多大」。上面两例：

- 身高 $CV = 4.5/115.8 = 3.89\%$，体重 $CV = 0.56/20.2 = 2.77\%$ → 身高的变异程度更大。
- 小白鼠 $CV = 3.2/22.1 = 14.5\%$，家兔 $CV = 101.4/1525.3 = 6.6\%$ → 小白鼠体重的变异程度更大。

**什么时候必须用 $CV$**：比较**度量单位不同**的两组（或多组）资料的变异程度；或单位相同但**均数相差悬殊**时。注意 $CV$ 是用 $s/\bar x$ 算的，所以它继承了标准差的前提——仍要求资料近似对称（正态），而且均数接近 0 时 $CV$ 会失去意义。

### 正态分布：钟形曲线与面积规律

把 120 名男孩的身高不断细分：观察人数越多、组数越多、组距越小，直方图的矩形越来越窄，顶端连线就慢慢变成一条**光滑的钟形曲线**——高峰在中央（均数处），两侧对称下降，两端无限靠近横轴但永不相交。这条曲线刻画的就是**正态分布**（normal distribution，也叫高斯分布）曲线。

若连续型随机变量 $x$ 的概率密度函数为

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \qquad -\infty < x < +\infty$$

则称 $x$ 服从参数为 $\mu$ 和 $\sigma^2$ 的正态分布，记作 $x \sim N(\mu, \sigma^2)$。$\mu$ 是总体均数，$\sigma^2$ 是总体方差。

**三条特征**：

1. 曲线在横轴上方、均数处最高，以均数为中心左右对称，两端与横轴永不相交，呈钟形。
2. 由两个参数决定：$\mu$ 是**位置参数**（$\sigma$ 固定时，$\mu$ 越大曲线越向右移）；$\sigma$ 是**形状参数**（$\mu$ 固定时，$\sigma$ 越大曲线越平阔，$\sigma$ 越小越尖峭）。
3. 曲线下的面积有固定规律。曲线下总面积为 1（100%），对称于均数的区间面积相等；某区间的面积就是观察值落在这个区间里的比例（概率）。

由于直接积分不方便，先做**标准正态变换**（又叫 $z$ 变换、$u$ 变换）：

$$z = \frac{x - \mu}{\sigma}$$

变换后的 $z$ 服从 $\mu = 0$、$\sigma = 1$ 的**标准正态分布**，记作 $z \sim N(0,1)$，其密度函数为

$$\varphi(z) = \frac{1}{\sqrt{2\pi}}\, e^{-\frac{z^2}{2}}, \qquad -\infty < z < +\infty$$

标准正态曲线下某区间的面积**只取决于 $z$**，于是可以查表（附表 3 给出的是 $-\infty$ 到 $z$ 的**左侧累计面积**，即下侧累积面积）。查表要点：①已知 $\mu$、$\sigma$ 和 $x$，先算 $z$ 再查表；②$\mu$、$\sigma$ 未知而 $n$ 足够大时，用 $\bar x$、$s$ 代替；③算出的 $z$ 常常不能直接读出所需面积，要结合对称性和总面积为 1 换算。

例：某地 18 岁男大学生身高 $x \sim N(173.50, 3.42^2)$，问身高在 166.8 cm 及以下者占多大比例？

$$z = \frac{166.8 - 173.5}{3.42} = -1.96$$

查表得 $-1.96$ 左侧面积 0.025，即约占 **2.5%**。

**三个必须记住的区间**：

| 区间 | 标准正态分布 | 一般正态分布 | 面积占比 |
| --- | --- | --- | --- |
| 中间 1 个标准差 | $(-1,\ 1)$ | $(\mu-\sigma,\ \mu+\sigma)$ | 68.27% |
| 中间 1.96 个标准差 | $(-1.96,\ 1.96)$ | $(\mu-1.96\sigma,\ \mu+1.96\sigma)$ | 95% |
| 中间 2.58 个标准差 | $(-2.58,\ 2.58)$ | $(\mu-2.58\sigma,\ \mu+2.58\sigma)$ | 99% |

### 正态性怎么判断

判断一份资料能不能按正态处理，按下面的顺序来：

1. **看频数表或频数图。** 高峰在中间、两侧大致对称，就偏向正态；明显偏一侧说明是偏态。
2. **凭专业知识。** 同质群体的身高、红细胞数、血红蛋白量、血清胆固醇，以及实验中的随机误差，通常呈正态或近似正态；潜伏期、住院天数、尿汞值这类指标天然偏态。
3. **粗筛一下 $\bar x$ 与 $s$ 的关系。** 若 $s$ 不超过 $\bar x$ 的 1/3（$3s \le \bar x$），多数情况下可按近似正态处理；若 $s$ 已经大于或等于 $\bar x$，基本可以怀疑资料严重偏态。
4. **做正态性检验。** 图示法有 P-P 图、Q-Q 图（点基本落在一条直线上即提示正态）；统计检验法常用 W 检验（Shapiro-Wilk）、D 检验和矩法（偏度系数、峰度系数）。

第 3 条只是经验判断，用来快速排除明显不像正态的情形，**不能代替检验和图形**。

### 医学参考值范围

**医学参考值范围**（旧称正常值范围）指大多数「正常人」的解剖、生理、生化等指标的波动范围。要注意「正常人」不等于「绝对健康的人」，而是**排除了影响所研究指标的疾病和有关因素的同质人群**。

制定时的四步：

1. **确定一批样本含量足够大的「正常人」**，测量方法、仪器、条件要统一，控制测量误差。
2. **选定合适的百分界值** $1-\alpha$，如 80%、90%、95%、99%，常用 **95%**；并判断是否需要按性别、年龄分组。
3. **确定单侧还是双侧**——这取决于专业上「异常」出现在哪一侧：白细胞计数过高过低都异常 → 双侧；转氨酶过高才异常 → 只取单侧上界；肺活量过低才异常 → 只取单侧下界。
4. **按资料的分布特点选计算方法**：正态或近似正态资料用**正态分布法**，偏态或末端无确切数值的资料用**百分位数法**。

| 方法 | 适用资料 | 95% 双侧 | 95% 单侧 |
| --- | --- | --- | --- |
| 正态分布法 | 正态或近似正态 | $\bar x \pm 1.96\,s$ | 上界 $\bar x + 1.645\,s$；下界 $\bar x - 1.645\,s$ |
| 百分位数法 | 偏态、末端无确切值 | $P_{2.5}$～$P_{97.5}$ | 上界 $P_{95}$；下界 $P_{5}$ |

正态分布法的一般形式：双侧 $1-\alpha$ 界值为 $\bar x \pm z_{\alpha/2} s$，单侧上界为 $\bar x + z_\alpha s$、下界为 $\bar x - z_\alpha s$。常用 $z$ 值查表：

| 参考值范围（%） | 单侧 $z_\alpha$ | 双侧 $z_{\alpha/2}$ |
| --- | --- | --- |
| 80 | 0.842 | 1.282 |
| 90 | 1.282 | 1.645 |
| 95 | 1.645 | 1.960 |
| 99 | 2.326 | 2.576 |

两个例子：

- 身高服从正态，双侧参考值范围，18 岁男大学生 95% 参考值范围 = $172.70 \pm 1.96 \times 4.01 = 164.84 \sim 180.56$ cm。
- 200 名正常人尿汞值呈偏态分布，且只有过高才算异常，取百分位数法的单侧上界：$P_{95} = 36 + \frac{4}{5}(200 \times 95\% - 186) = 39.2$ μg/L。

::: warning 关于 95% 参考值范围的两个常见误解
**误解一：范围外面的人就是病人。** 95% 双侧参考值范围只覆盖中间 95% 的**正常人**，两端各有 2.5% 的正常人落在范围之外——这不是「假阳性」，而是范围本身定义的必然结果。参考值范围用于筛查和提示，确诊还要结合临床。

**误解二：单侧、双侧随便选。** 它由专业上「异常」出现在哪一侧决定：白细胞计数过高过低都异常，用双侧；转氨酶只有过高才异常，用单侧上界（95% 对应 $P_{95}$，不是 $P_{2.5}$～$P_{97.5}$）；肺活量只有过低才异常，用单侧下界。
:::

### 正态分布的另外两个用途

- **质量控制。** 实验中的随机误差服从正态分布，于是用 $\bar x \pm 2s$ 作上下**警戒限**、$\bar x \pm 3s$ 作上下**控制限**，配合中心线画成质量控制图。检测值落到警戒限外，甚至控制限外，提示可能存在系统误差等非随机误差。
- **作为许多统计方法的理论基础。** $t$ 分布、$F$ 分布、$\chi^2$ 分布都是在正态分布基础上推导出来的，$z$ 检验更是直接以正态分布为基础；$t$ 分布、二项分布、Poisson 分布的极限分布也是正态分布，条件满足时可以按正态规律处理。

### 补充两个常用指标：众数与调和均数

**众数**（mode）是一组观察值中出现次数最多的那个数值，它也是一种位置指标，适合粗略描述集中位置；缺点是资料不同取值的频数可能很接近，众数不稳定，也不唯一。**调和均数**是观察值倒数均数的倒数，用于某些特殊的平均速率、平均浓度问题，卫生统计中远不如均数、几何均数、中位数常用。

### 1. 一组指标一次算完

```r
# iris：R 自带的鸢尾花数据，每条记录是一株花，Sepal.Length 是花萼长度（cm）
x <- iris$Sepal.Length

length(x)                # 样本含量 n = 150
mean(x)                  # 算术均数 = 5.843333
median(x)                # 中位数 = 5.8
sd(x)                    # 标准差 s = 0.8280661
var(x)                   # 方差 s^2 = 0.6856935
range(x)                 # 最小值、最大值：4.3 7.9（注意：不是极差！）
diff(range(x))           # 极差 R = 3.6
quantile(x)              # 0%  25%  50%  75% 100% → 4.3 5.1 5.8 6.4 7.9
IQR(x)                   # 四分位数间距 Q = P75 - P25 = 1.3
sd(x) / mean(x) * 100    # 变异系数 CV = 14.17113（%）
summary(x)               # 4.300 5.100 5.800 5.843 6.400 7.900
```

怎么读输出：

- `quantile()` 默认给出 5 个数：最小值、$P_{25}$、中位数、$P_{75}$、最大值，其中 $P_{25}/P_{50}/P_{75}$ 就是四分位数。要别的分位点直接指定，例如 `quantile(x, c(0.025, 0.975))`、`quantile(x, 0.95)`。
- `summary()` 的输出顺序是「最小值、$P_{25}$、中位数、**均数**、$P_{75}$、最大值」，第 4 个是均数，其余是五数概括。若数据里有 `NA`，需要加 `na.rm = TRUE`，如 `mean(x, na.rm = TRUE)`。
- 比较 `mean(x)` 与 `median(x)`：这里只差 0.043，说明分布接近对称；偏态资料两者会明显不同（正偏态时均数大于中位数）。
- `quantile()` 默认用第 7 种算法（R 的 `type = 7`），SPSS 的百分位数算法与之略有差异，跨软件核对数字时留意。

### 2. 频数表与直方图：用 `cut()` + `table()`

```r

hist(x, breaks = brk, right = FALSE,
     main = "150 株鸢尾花花萼长度的频数图",
     xlab = "花萼长度（cm）", ylab = "频数")
```

- `cut()` 负责按界限把连续数值「归组」，`table()` 负责计数，这两个函数组合起来就是频数表的编制过程；「累计频率」列里**第一个超过 50% 的位置**就是中位数所在组段。
- `hist()` 的 `breaks` 既可以是组距（一个数），也可以像这里一样直接给一组界限，这样各组的划分就和频数表完全一致。
- `hist()` 默认纵坐标是频数；想画密度直方图（矩形面积=频率，可直接叠加 `lines(density(x))`）就加 `freq = FALSE` 或 `probability = TRUE`。

也可以用教材的**加权法**复算一遍，体会「组中值代替组内每个观察值」带来的近似：

```r
mid <- (head(brk, -1) + tail(brk, -1)) / 2   # 各组段的组中值
f   <- as.integer(freq)

sum(f * mid) / sum(f)                        # 加权法均数 = 5.893（真值 5.843333）
sqrt((sum(f * mid^2) - (sum(f * mid))^2 / sum(f)) / (sum(f) - 1))
                                             # 加权法标准差 = 0.824（真值 0.8280661）
```

组距越粗，组中值离组内真实取值越远，误差越大——所以有原始数据就不要用频数表法。

### 3. 几何均数

```r
# 抗体滴度取倒数后的 7 个观察值
titer <- c(4, 8, 16, 32, 64, 128, 256)

exp(mean(log(titer)))                        # 几何均数 = 32，即平均滴度 1/32

f <- c(1, 3, 6, 10, 13, 10, 7)               # 各滴度的例数（频数表资料）
exp(weighted.mean(log(titer), f))            # 加权几何均数 = 54.94819，即 1/54.9
```

怎么读输出：base R 没有现成的几何均数函数，公式就是「先取对数 → 求均数 → 再取反对数」，`exp(mean(log(x)))` 一行搞定；有频数时把 `mean()` 换成 `weighted.mean(log(x), f)`。用自然对数配 `exp()`、用常用对数配 `10^()` 都行，**只要取对数与取反对数的底一致**，结果相同。

### 5. QQ 图与正态性检验

```r
x <- iris$Sepal.Length
qqnorm(x, main = "iris 花萼长度的正态 QQ 图")
qqline(x, col = "red")          # 参考直线：点基本落在线上就提示正态

shapiro.test(x)                 # W = 0.97609, p-value = 0.01018
shapiro.test(airquality$Temp)   # W = 0.97617, p-value = 0.009319（n = 153）

y <- faithful$eruptions         # 老忠实间歇泉的喷发时长（分钟），n = 272
qqnorm(y, main = "faithful 喷发时长的正态 QQ 图")
qqline(y, col = "red")
shapiro.test(y)                 # W = 0.84592, p-value = 9.036e-16
```

怎么读输出：

- QQ 图的横轴是理论正态分位数、纵轴是实际数据的分位数。点基本贴着直线 → 提示正态；**中间一段平、两头翘成 S 形 → 提示偏态或双峰**。`qqline()` 画的是参考直线，不加就只能靠眼睛比。
- `shapiro.test()` 的原假设是「资料服从正态分布」，$p < 0.05$ 就是拒绝正态。`faithful$eruptions` 的 $p$ 值约 $9 \times 10^{-16}$，它其实是**双峰**分布（短喷发和长喷发两群），完全不能用 $\bar x \pm s$ 概括。
- 反过来，$p > 0.05$ **不等于**「证明了正态」，只是「没有足够证据说它不是正态」。$n$ 越大检验越敏感：`iris$Sepal.Length` 的 $p = 0.0102$ 虽然小于 0.05，但它的 QQ 图几乎是直线，轻微偏离主要来自数据本身的离散取值。**结论要图形、检验、专业知识一起看。**
- `shapiro.test()` 只接受 $3 \le n \le 5000$ 的样本；样本更大时改用 `nortest::ad.test()`、`nortest::lillie.test()` 等方法。想画 P-P 图可以用 `plot(ecdf(x))` 配合 `pnorm()`，或 `car::qqPlot()`。

### 6. 参考值范围：正态分布法 vs 百分位数法

```r
# 纽约 1973 年 5—9 月每日最高气温（华氏度），n = 153，近似对称
x <- airquality$Temp
mean(x); sd(x)                          # 77.88235；9.46527

# 正态分布法：95% 双侧
mean(x) + c(-1, 1) * 1.96 * sd(x)       # 59.33042  96.43428

# 百分位数法：95% 双侧
quantile(x, c(0.025, 0.975))            # 57.8  93.2

# 只有「过高算异常」时的单侧上界（95%）
mean(x) + 1.645 * sd(x)                 # 93.45272
quantile(x, 0.95)                       # 92
```

```r
# 换成明显非正态的资料，正态分布法就会算出没有实际意义的界值
y <- faithful$eruptions
mean(y) - 1.96 * sd(y)                  # 1.250695：比实测最小值 1.6 还小
min(y); max(y)                          # 1.6  5.1
quantile(y, c(0.025, 0.975))            # 1.75  4.907425
```

怎么读输出：

- 上面两组数字成对比较很有意义：气温资料近似对称，两种方法给出的界值相差不大（59.33/57.8、96.43/93.2），用哪个都能接受；`faithful` 是双峰资料，正态分布法给出的下界 1.25 分钟比实测最小值还低，等于凭空造出一个不存在的范围——**偏态/双峰资料必须用百分位数法**。
- 单侧界值别写错：只有过高异常时用单侧上界，95% 对应 $z = 1.645$（不是 1.96），用百分位数法就是 $P_{95}$。

### 7. 标准化与用正态分布算比例

```r
# 标准正态变换：减均数、除标准差
x <- iris$Sepal.Length
z <- (x - mean(x)) / sd(x)
c(mean(z), sd(z))            # -4.484318e-16  1.000000e+00 → 均数 0、标准差 1
all.equal(z, as.numeric(scale(x)))   # TRUE：scale() 做的就是同一件事

# 用 pnorm()/qnorm() 代替查附表 3
pnorm(168.0, mean = 172.70, sd = 4.01)                       # 0.1205845 ≈ 12.06%
pnorm(183.05, 172.70, 4.01) - pnorm(162.35, 172.70, 4.01)    # 0.9901499 ≈ 99%
pnorm(-1.96)                                                  # 0.0249979 ≈ 0.025（附表 3 的查表结果）
qnorm(0.975)                                                  # 1.959964，即查表用的 1.96
qnorm(0.95)                                                   # 1.644854，即查表用的 1.645
```

怎么读输出：`pnorm(a, mean, sd)` 给的是「小于 $a$ 的比例」，也就是附表 3 的左侧累计面积，$a$ 换成 $z$ 值就得到查表的结果；求两个界值之间的比例就用两个 `pnorm()` 相减。`qnorm(p)` 是反函数：给累计概率，返回 $z$ 值，所以 $z_{0.975}$、$z_{0.95}$ 这些常用值不必记，敲一下就有。

### 8. SPSS 里的对应菜单

想在 SPSS 里做同样的事，菜单路径是：

| 目的 | 菜单 |
| --- | --- |
| 频数表（频数、频率、累计频率） | 分析 → 描述统计 → 频率 |
| 均数、标准差、极差、偏度、峰度 | 分析 → 描述统计 → 描述 |
| 箱式图、Q-Q/P-P 图、正态性检验（S-W、K-S） | 分析 → 描述统计 → 探索（图、正态性检验选项） |
| 直方图 | 图形 → 旧对话框 → 直方图 |
| 按组分别描述（分组比较） | 分析 → 描述统计 → 探索，因子列表放分组变量 |
| 生成标准化 z 值 | 分析 → 描述统计 → 描述 → 勾选「将标准化值另存为变量」 |

SPSS 的「探索」会同时输出 Kolmogorov-Smirnov 和 Shapiro-Wilk 两行结果，两种检验针对的样本量区间不完全相同（通常小样本更看 S-W、大样本更看 K-S），所以**报告时一定要写清楚用了哪种检验、样本量是多少**，不要只丢一个 $P$ 值。

## 容易踩的坑

- **`range()` 不是极差。** `range(x)` 返回的是最小值和最大值这两个数，极差得写 `diff(range(x))`。直接把 `range()` 的结果当 $R$ 用是很常见的失分点。
- **别用标准差直接比「谁变异大」。** 单位不同（身高 cm 和体重 kg）、或单位相同但均数相差悬殊（小白鼠 22.1 g 和家兔 1525.3 g）时，必须换成变异系数 $CV = s/\bar x \times 100\%$ 再比。反过来，$CV$ 只有在资料近似对称、均数不为 0 附近时才有意义。
- **几何均数有硬性前提。** 观察值中不能有 0，也不能同时有正有负；滴度这类资料要先取倒数（1/4、1/8 → 4、8）。还要注意它只适用于对数对称（等比级数）的资料，普通偏态资料该用中位数，不是「偏态就上几何均数」。
- **频数表法算出来的均数和标准差只是近似值。** 组中值代替了组内的每一个观察值，组距越粗误差越大。它是在没有原始数据、只有频数表时的补救办法，手里有原始数据就直接用 `mean()`、`sd()`。
- **正态性检验的 $P$ 值要会读。** $P > 0.05$ 只是「没有足够证据拒绝正态」，不等于证明了正态；$P < 0.05$ 也不等于「资料就不能用 t 检验」——大样本下轻微偏离也会显著。还要记住 `shapiro.test()` 只支持 $3 \le n \le 5000$，并且判断正态要图形、检验、专业知识三者合看。

## 小结

- 定量资料的统计描述 = **统计图表**（频数表、直方图、箱线图、QQ 图）+ **两组指标**（集中趋势、离散趋势），先看分布类型，再决定用哪一组。
- 集中趋势三选一：对称/正态用**算术均数** $\bar x$，偏态或开口数据用**中位数** $M$，对数正态/等比资料（滴度、效价）用**几何均数** $G$。
- 离散趋势与集中趋势**配对使用**：均数配**标准差**，中位数配**四分位数间距**；单位不同或均数相差悬殊要比较变异程度时，改用**变异系数** $CV = s/\bar x \times 100\%$。
- 正态分布由 $\mu$（位置）和 $\sigma$（形状）两个参数决定，曲线下面积有固定规律：$\mu \pm \sigma$ 内 68.27%、$\mu \pm 1.96\sigma$ 内 95%、$\mu \pm 2.58\sigma$ 内 99%。做 $z = (x-\mu)/\sigma$ 变换后查标准正态分布表即可求任意区间的比例。
- 正态分布最常用的两个落地场景是**估计频数分布**和**制定医学参考值范围**（正态资料用 $\bar x \pm z_{\alpha/2}s$，偏态资料用百分位数法，注意区分单侧与双侧），此外还用于质量控制（$\bar x \pm 2s$ 警戒限、$\bar x \pm 3s$ 控制限）并作为众多统计方法的理论基础。
