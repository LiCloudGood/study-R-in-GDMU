# 一致性信度

> 前面各章比的是**组与组之间**有没有差别。这一节问一个不同的问题：**同一批对象、反复测或换人测，结果一不一致？** 两位医生看同一张片子会不会得出同一个诊断？同一台仪器今天明天测同一个样本，读数差多少？这个问题叫**信度**（reliability），它决定了你测出来的数到底能不能用 —— 一个不可靠的测量，再怎么分析都是分析噪声。所用的指标是 Kappa（分类资料）和 ICC（定量资料）。

## 这个专题要解决什么

临床和科研里到处是「重复测量」：两位病理医生判同一批切片、两台仪器测同一批血样、同一份量表隔两周重测。

要评价这类资料，需要回答：**测量结果里，有多少变异来自「对象本身真的不同」，有多少来自「测量误差」？**

$$信度 = \frac{真实变异}{真实变异 + 误差变异}$$

信度接近 1 表示测出来的差别基本是对象之间的真实差别；接近 0 表示测出来的东西基本是噪声。

::: warning 相关不等于一致 —— 这一节最要紧的一句话
两把尺子，一把量的是真实长度，另一把量出来的永远是真实长度的 **2 倍**。
两者**相关系数正好是 1** —— 完美相关。但它们能互相替代吗？显然不能：一个量出 10 cm，另一个说 20 cm。

**相关描述「同增同减」，一致性描述「数值相同」**。这是两件事。
所以评价一致性**绝不能用 Pearson 相关系数**，必须用 Kappa、ICC 或 Bland-Altman 这类方法。
下面「在 R 里怎么做」会用真实数据把这个差别算给你看。
:::

::: tip 这一节不在课本的 19 章里
《卫生统计学》的 17 章没有把信度分析单独列章（第 14 讲《信息技术基础》里出现过 Kappa 检验），
但量表研制、仪器比对、多中心研究里天天要用，本站把它补成专题。
:::

## 核心概念

### 分类资料：Kappa

两位评定者对同一批对象各判一个类别，把结果交叉列表。**观察一致率** $P_o$ 是两人判断相同的比例：

$$P_o = \frac{\text{对角线上的人数之和}}{N}$$

但 $P_o$ 有个陷阱：**就算两人都在瞎猜，也会有一部分碰巧一致**。这个「碰巧一致」的比例叫**机遇一致率** $P_e$，由两人的边际分布算出：

$$P_e = \sum_i p_{i\cdot}\,p_{\cdot i}$$

其中 $p_{i\cdot}$、$p_{\cdot i}$ 分别是两人判为第 $i$ 类的比例。Kappa 就是把碰巧一致的部分扣掉：

$$\kappa = \frac{P_o - P_e}{1 - P_e}$$

分母 $1-P_e$ 是「扣掉碰巧之后，本来还有多少可能达成一致」。所以 $\kappa=1$ 是完全一致，$\kappa=0$ 是**跟瞎猜一个水平**（注意：不是「完全不一致」）。

::: tip $\kappa$ 可以为负
当两人的一致性比碰巧还差时，$\kappa$ 是负数。实际数据里少见，但出现了说明评定结果**互相对着干**。
:::

### 加权 Kappa：有序资料

如果类别**有顺序**（比如影像的 1~5 级评分），把「1 判成 2」和「1 判成 5」当成同样严重就不合理了。加权 Kappa 给不同程度的偏离赋不同的权重：

- **线性权重**：$w_{ij} = 1 - \dfrac{|i-j|}{k-1}$
- **平方权重**：$w_{ij} = 1 - \dfrac{(i-j)^2}{(k-1)^2}$

完全一致时 $w=1$，差得越远 $w$ 越小。平方权重对大偏差惩罚更狠，所以**算出来的 $\kappa$ 通常比线性权重大**。

判断要不要加权只看一件事：**类别之间有没有天然顺序**。有序资料（疾病分级、Likert 量表、疼痛评分）应当加权；无序资料（血型、诊断类别、阳性/阴性）**不能加权** —— 给无序类别编个 1、2、3 再算加权 Kappa 是没有意义的。

### 定量资料：ICC

连续型测量用**组内相关系数**（intraclass correlation coefficient，ICC）。它本质上是方差分析里「对象间均方」与「误差均方」的比值，所以能同时反映**相关**和**一致性**。

ICC 不是**一个**指标，而是**一族**指标。按 McGraw 与 Wong（1996）的框架，由三个选择组合而成：

| 选择 | 有哪些 | 怎么定 |
| --- | --- | --- |
| **Model**（模型） | 单向随机、双向随机、双向混合 | 评定者是不是从更大的人群里随机抽的？ |
| **Type**（类型） | 单次测量、$k$ 次测量的均值 | 实际使用中，你打算用一次测量还是几次平均？ |
| **Definition**（定义） | 一致性（consistency）、绝对一致（absolute agreement） | 你介意的只是「排序一致」还是「数值相同」？ |

三者组合出 10 种形态。Shrout 与 Fleiss（1979）的记号写法是两个数字，例如：

- **ICC(2,1)**：双向随机效应、绝对一致、单次测量；
- **ICC(3,1)**：双向混合效应、一致性、单次测量。

::: tip 选哪几个，一句话版
- **同一批评定者评所有对象，还想把结论推广到「同类的其他评定者」** → 双向随机（model 2）；
- **评定者就是这几个、不打算推广** → 双向混合（model 3）；
- **实际只测一次** → type 1；**实际要用 $k$ 次的平均值** → type $k$；
- **关心数值是否相同**（多数临床场景，比如两台仪器能不能换用）→ **绝对一致**；
  只关心排序（比如两次量表评分排序是否一致）→ 一致性。

**重测信度和同一评定者的重复测量，一律用双向混合 + 绝对一致。**
:::

**绝对一致与一致性的区别很实际**：
「一致性」允许评定者之间有**恒定的系统偏移**（甲比乙永远高 3 分，$\text{ICC}=1$）；
「绝对一致」不允许，系统偏移会直接把 ICC 拉下来。所以**要判断两台仪器能不能互换，必须用绝对一致**。

### 怎么解读这些数字

::: warning Kappa 的分档（Landis & Koch, 1977）
| $\kappa$ | 一致性强度 |
| --- | --- |
| 0.00 | Poor（差）|
| 0.01 ~ 0.20 | Slight（轻微）|
| 0.21 ~ 0.40 | Fair（尚可）|
| 0.41 ~ 0.60 | Moderate（中等）|
| 0.61 ~ 0.80 | Substantial（相当好）|
| 0.81 ~ 1.00 | Almost perfect（几乎完全一致）|

这套分档出自 Landis 与 Koch 1977 年发表在 *Biometrics* 的文章，
原文就说明这些界线是**约定俗成的描述性标签，不是检验标准**。别把它当成及格线。
:::

::: warning ICC 的分档（Koo & Li, 2016）
| ICC | 信度 |
| --- | --- |
| $<0.5$ | Poor（差）|
| $0.5 \sim 0.75$ | Moderate（中等）|
| $0.75 \sim 0.9$ | Good（好）|
| $>0.9$ | Excellent（很好）|

Koo 与 Li 2016 年那篇指南有两条比数字更重要的提醒：

1. **要按 95% 可信区间来定档，不是按点估计**。
   点估计 0.93 看着是「很好」，可如果可信区间是 0.88~0.97，那只能说「好到很好之间」；
   只有当**区间的下限都超过 0.9**，才敢说「很好」。
2. **样本太小、评定者太少时，ICC 本身就不可信**。他们建议**至少 30 个异质性样本、至少 3 位评定者**。
   样本量不够，可信区间会宽得没法看 —— 下面例子里的 CI 就宽到包含 0。
:::

## 在 R 里怎么做

### 一、无序分类：Cohen's Kappa 与 Fleiss' Kappa

用 `irr` 包自带的 `diagnoses`：30 位患者，6 位评定者，各判 5 个诊断类别之一。

```r
library(irr)
data(diagnoses, package = "irr")

# 两位评定者之间：Cohen's kappa
kappa2(diagnoses[, c("rater1", "rater2")])
#  Cohen's Kappa for 2 Raters (Weights: unweighted)
#   Subjects = 30   Raters = 2   Kappa = 0.651
#          z = 7   p-value = 2.63e-12

# 六位评定者之间：Fleiss' kappa
kappam.fleiss(diagnoses)
#  Fleiss' Kappa for m Raters
#   Subjects = 30   Raters = 6   Kappa = 0.43
#          z = 17.7   p-value = 0
```

后面那个 `p-value = 0` 是 R 打印时的下溢，意思是**小于 2.2×10⁻¹⁶**，不是真的等于 0。

**rater1 与 rater2 的 $\kappa = 0.651$**（Substantial），**6 位评定者合起来的 $\kappa = 0.430$**（Moderate）。

两个数差得不小，这件事本身值得注意：**评定者越多，整体一致性越难高**。所以报告时必须说清楚
是「哪两位之间」还是「全体之间」，这两个数不能混着用。

手算核对一遍（$P_o$ 和 $P_e$）：

```r
two <- diagnoses[, c("rater1", "rater2")]
Po <- mean(two$rater1 == two$rater2)          # 0.7333
tb <- table(two$rater1, two$rater2)
Pe <- sum(rowSums(tb) * colSums(tb)) / nrow(two)^2   # 0.2356
(Po - Pe) / (1 - Pe)                          # 0.6512
```

$P_o = 0.7333$，$P_e = 0.2356$，$\kappa = \dfrac{0.7333-0.2356}{1-0.2356} = 0.6512$ ✓

### 二、有序资料：加权 Kappa

用 `irr::anxiety`：20 位患者的焦虑评分，3 位评定者，1~6 级。

```r
data(anxiety, package = "irr")
ax <- anxiety[, c("rater1", "rater2")]

kappa2(ax, weight = "unweighted")$value   # 0.1195
kappa2(ax, weight = "equal")$value        # 0.1892  ← 线性权重
kappa2(ax, weight = "squared")$value      # 0.2968  ← 平方权重
mean(ax$rater1 == ax$rater2)              # 观察一致率 0.3000
```

同一批数据，三个数：**0.120 / 0.189 / 0.297**。

- 不加权时，把 1 和 2 的差别、1 和 6 的差别算成同样严重，$\kappa$ 只有 0.12；
- 用线性权重（差 1 级扣一点、差 5 级扣很多）涨到 0.19；
- 用平方权重（对大偏差惩罚更狠）涨到 0.30。

**数值差别是权重约定不同造成的，不是数据变了**。所以报加权 Kappa 时必须写明**用了哪种权重**。
（`irr` 里线性权重写作 `"equal"`，平方权重写作 `"squared"`。这篇数据的三位数都是自己手算复核过的。）

顺带注意 $P_o = 0.30$：**这两位评定者的实际一致率只有三成**，无论怎么加权都谈不上可靠。

### 三、定量资料：ICC

同一批数据（20 例 × 3 位评定者）当连续评分处理：

```r
library(psych)
ICC(anxiety)$results[, c("type", "ICC", "lower bound", "upper bound")]
#                          type       ICC lower bound upper bound
# Single_raters_absolute   ICC1 0.1750225 -0.07744650   0.4843362
# Single_random_raters     ICC2 0.1979983 -0.03891068   0.4935740
# Single_fixed_raters      ICC3 0.2160493 -0.04625793   0.5222590
# Average_raters_absolute ICC1k 0.3889259 -0.27492318   0.7380652
# Average_random_raters   ICC2k 0.4254988 -0.12658288   0.7451493
# Average_fixed_raters    ICC3k 0.4525861 -0.15292145   0.7663308
```

`irr::icc` 给出同样的结果，可以用来交叉核对：

```r
library(irr)
icc(anxiety, model = "twoway", type = "agreement", unit = "single")$value   # ICC(2,1) = 0.1980
icc(anxiety, model = "twoway", type = "agreement", unit = "average")$value  # ICC(2,k) = 0.4255
```

怎么读这几个数：

- **ICC(2,1) = 0.198**：按单次测量算，信度很差（$<0.5$，Poor）；
- **ICC(2,k) = 0.4255**：如果每次取 3 位评定者的平均值，信度提高不少，但仍然不够；
- **ICC(2,1) 的 95% 可信区间 −0.039 ~ 0.494**：**宽到包含 0**。这说明 20 例样本太少，
  连「信度到底是不是正数」都说不准 —— 正是 Koo 与 Li 提醒的那种情况（他们建议至少 30 例、至少 3 位评定者）。

**ICC 是怎么算出来的**，用方差分析的均方直接算一遍就明白了：

```r
icc_hand <- function(mat) {
  n <- nrow(mat); k <- ncol(mat); grand <- mean(mat)
  MSR <- k * sum((rowMeans(mat) - grand)^2) / (n - 1)   # 对象间均方
  MSC <- n * sum((colMeans(mat) - grand)^2) / (k - 1)   # 评定者间均方
  SST <- sum((mat - grand)^2)
  MSE <- (SST - k * sum((rowMeans(mat) - grand)^2) -
          n * sum((colMeans(mat) - grand)^2)) / ((n - 1) * (k - 1))  # 误差均方
  c(MSR = MSR, MSC = MSC, MSE = MSE,
    ICC21 = (MSR - MSE) / (MSR + (k - 1) * MSE + k * (MSC - MSE) / n),
    ICC2k = (MSR - MSE) / (MSR + (MSC - MSE) / n),
    ICC31 = (MSR - MSE) / (MSR + (k - 1) * MSE))
}
icc_hand(as.matrix(anxiety))
#      MSR      MSC      MSE    ICC21    ICC2k    ICC31
# 2.645556 4.816667 1.448148 0.197998 0.425499 0.216049
```

**MSR = 2.6456、MSC = 4.8167、MSE = 1.4482**，代进公式得到 ICC(2,1) = $0.1980$、ICC(2,k) = $0.4255$、
ICC(3,1) = $0.2160$，和 `psych::ICC`、`irr::icc` 完全一致。

看这三个均方能读出意思：
**MSC = 4.82 比 MSR = 2.65 还大**，说明**评定者之间的系统性差异比对象之间的真实差异还大** ——
也就是说这批评分里，「谁在评」比「评的是谁」影响更大。这样的测量当然不可靠。

### 四、相关 ≠ 一致：把它算出来

拿 `anxiety` 的 rater3 的评分 $x$，人为造出第二组评分 $y = x + \text{偏移} + \text{小随机噪声}$，
模拟「第二位评定者普遍打分偏高」：

```r
x <- anxiety$rater3
for (off in c(0, 1, 3)) {
  set.seed(7)   # 每次都设同一个种子：三行之间只有「偏移」不同，噪声完全一样
  y <- x + off + rnorm(length(x), 0, 0.5)
  cat(sprintf("偏移 %d 分：r = %.4f   ICC(2,1) = %.4f\n",
              off, cor(x, y), icc_hand(cbind(x, y))["ICC21"]))
}
# 偏移 0 分：r = 0.8905   ICC(2,1) = 0.8824
# 偏移 1 分：r = 0.8905   ICC(2,1) = 0.6254
# 偏移 3 分：r = 0.8905   ICC(2,1) = 0.2239
```

**相关系数一动不动，全是 0.8905；ICC 从 0.88 掉到 0.22。**

原因很直白：把一组数整体加个常数，**同增同减的关系一点没变**（所以 $r$ 不变），
但两组数之间已经隔了 3 分（所以一致性崩了）。**相关系数对系统偏移完全免疫** ——
这就是评价一致性不能用相关系数的根本原因。

再极端一点，不加噪声、纯偏移 1 分：

```r
y <- x + 1
cor(x, y)                       # 1.0000  ← 完美相关
icc_hand(cbind(x, y))["ICC21"]  # 0.7826  ← 绝对一致掉了
icc_hand(cbind(x, y))["ICC31"]  # 1.0000  ← 但「一致性」定义下仍是 1
```

$r = 1.000$，ICC(2,1) 只有 0.783，而只看排序的 **ICC(3,1) 仍是 1**。
这一段同时说明了两件事：**相关不等于一致**，以及**「绝对一致」与「一致性」两种定义的区别是真实存在的**。

::: tip 连续资料的另一个选择：Bland-Altman
ICC 给一个概括性的数，但看不出偏倚有多大、误差是什么形态。
配合 **Bland-Altman 图**（横轴是两法均值、纵轴是两法差值）更直观：
上面那个偏移 1 分、噪声 SD = 0.5 的例子，差值均数 = 1.22、差值 SD = 0.62，
一致性界限就是 $1.22 \pm 1.96\times0.62$。

**两者互补**：ICC 回答「能不能区分对象」，Bland-Altman 回答「差多少、差得稳定吗」。
:::

### 五、Kappa 悖论：一致率很高，Kappa 却不高

这是初学者最容易被搞糊涂的地方。下面这张构造的表，两位评定者判断「正常 / 异常」：

| | 乙：正常 | 乙：异常 |
| --- | --- | --- |
| **甲：正常** | 85 | 5 |
| **甲：异常** | 5 | 5 |

```r
Po <- (85 + 5) / 100                                # 0.90
Pe <- (90 * 90 + 10 * 10) / 100^2                    # 0.82
(Po - Pe) / (1 - Pe)                                 # 0.4444
```

**观察一致率高达 90%，Kappa 只有 0.444**（Moderate）。

为什么？因为**两人都倾向于判「正常」**（各判了 90 个），所以哪怕随便划，也很容易一致 ——
机遇一致率 $P_e$ 就有 0.82。分母 $1-P_e = 0.18$ 被压得很小，稍微一点不一致就会让 $\kappa$ 明显下降。

**这叫 Kappa 悖论**（ prevalence/边际分布不均衡导致的 Kappa 偏低）。
它提醒两件事：

1. **报 Kappa 时应当同时报 $P_o$ 和两个变量的边际分布**，否则读者无法判断 Kappa 低是「真的不一致」还是「边际偏斜」；
2. 阳性率很低或很高时（比如罕见病的诊断一致性），**Kappa 会天然偏低**，
   这时候可以补充报告 **$P_o$**、**阳性一致率**（positive agreement）或 **Gwet 的 AC1**。

## 容易踩的坑

::: warning 七个常见错误
**① 用 Pearson 相关系数评价一致性。** 上文算过：整体加个常数，$r$ 纹丝不动。
相关只管「同增同减」，一致性管「数值相同」。**这是本专题第一大坑。**

**② 用配对 $t$ 检验或两组比较的检验评价一致性。** 配对 $t$ 检验只能发现**平均差是否为 0**，
发现不了「每次差得都不一样」这种随机误差；而且「差异没有统计学意义」不等于「一致」
（可能只是样本量不够）。评价一致性要用专门的指标。

**③ 给无序分类算加权 Kappa。** 血型、诊断类别、阴/阳性之间没有大小顺序，
强行编成 1、2、3 再加权是在制造不存在的信息。

**④ 报 ICC 不说清是哪种形态。** ICC(1,1)、ICC(2,1)、ICC(3,1) 在**同一批数据上能差出好几倍**
（上面例子里 0.175 / 0.198 / 0.216 是单次测量，换成均值形态又变成 0.389 / 0.425 / 0.453）。
规范做法是连**软件、模型、类型、定义**一起写清楚，并报告 **95% 可信区间**。

**⑤ 用 ICC 的点估计直接下结论。** 点估计 0.93 但 CI 是 0.88~0.97 时，只能说到「好到很好之间」。
**必须看区间**。

**⑥ 样本量太小就报信度。** 上面 20 例的例子，ICC 的 CI 宽到从 −0.039 开始。
Koo 与 Li 建议至少 **30 个异质性样本**、至少 **3 位评定者**；评定者越多、样本越同质，
ICC 越容易低或者不稳定。

**⑦ 把「信度」和「效度」混为一谈。** 信度高只说明**测得稳定**，
不说明**测的是想测的东西**。一台永远显示 0 的血压计信度完美（每次都一致），
效度是零。**先有效度，再谈信度。**
:::

## 小结

| 资料类型 | 用什么 | 关键提醒 |
| --- | --- | --- |
| 无序分类（两人） | Cohen's Kappa | $\kappa$ 已扣除碰巧一致；注意边际偏斜会让它偏低 |
| 无序分类（多人） | Fleiss' Kappa | 评定者越多，整体一致性越难高；和两两之间的 Kappa 不是一回事 |
| **有序**分类 | 加权 Kappa | 必须写明用**线性**还是**平方**权重，两者能差出不少 |
| 定量（连续） | ICC | 必须写明**模型 / 类型 / 定义**，并报 95% 可信区间 |
| 定量（要看偏倚） | Bland-Altman | 和 ICC 互补：一个说「能不能区分对象」，一个说「差多少」 |

**三句话记住这一节**：

1. **相关 ≠ 一致** —— 系统偏移对相关系数完全隐形，对 ICC 和 Bland-Altman 一目了然；
2. **分类用 Kappa、定量用 ICC，有序要加权，ICC 要说清是哪一种**；
3. **所有信度指标都要带 95% 可信区间**，点估计好看不代表靠得住；样本少于 30 例、评定者少于 3 位时要格外小心。
