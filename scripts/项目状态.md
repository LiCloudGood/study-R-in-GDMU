### 自定义组件速查

`README.md` 现在只面向学生，技术细节挪到这里。四个组件都在
`docs/.vitepress/theme/index.ts` 里全局注册，任意 Markdown 页面直接用，不用 import。

| 组件 | 用途 | 关键属性 |
| --- | --- | --- |
| `<AnswerBlock>` | 参考答案卡片（默认收起） | `code`（必填）、`title`、`description`、`output`、`images`、`defaultOpen` |
| `<ClickAnswer>` | 折叠解答（可放 Markdown / 公式） | `initially-open`、`show-text`、`hide-text`、`theme`、`animation`、`icon-position` |
| `<TrackList>` | 学习进度清单（存 localStorage） | `tasks` |
| `<ChoiceFlow>` | 统计方法选择器 | `show-detail-link`；题库在 `public/tree-{normal,med,expert}.json` |

```md
<AnswerBlock
  title="实验题 1 · 参考答案"
  :code="code1101"
  :output="out1101"
  :images="['/figures/10-ggplot2/unnamed-chunk-7-1.png']"
/>
```

坑：

- **不要再加 `:packages` / `:files`**：那是 WebR 时代的属性，现在不生效，
  各讲里遗留的 14 处已经清理掉了。
- **raw HTML 里的图片必须写 `:src="withBase('...')"`**，并在该页
  `<script setup>` 里 `import { withBase } from 'vitepress'`；
  VitePress 只给 Markdown 语法的图片自动补 base，raw HTML 不会。
  `<AnswerBlock>` 的 `images` 属性内部已经自动补好了。
- 自闭合标签批量插属性时容易把 `/>` 劈成两半，插完要 `npm run docs:build` 验一次。

## 三、已知问题 / 待办

### A. 已解决的问题（保留记录，避免后人重走弯路）

1. ~~`Cannot convert object to primitive value`~~ —— **随 WebR 一起废弃了**。
   WebR 的 `captureR` 在 R 报错时返回的 `error` 项，其 `data` 是 **RObject** 而不是字符串。
   老代码在 `docs/.vitepress/theme/webr.ts` 里加过 `conditionText()` 做降级处理。
   **现在本站不再在线执行 R，这个坑不存在了。**

2. ~~绘图没有显示出来~~ —— **同上，已废弃**。
   现在图是预先跑好、直接放在 `public/figures/` 下的静态图片。

3. ~~脚本里的「错误」会中断后续代码~~ —— **这正是放弃 WebR 的主要原因之一**。
   例如 `test0501.R` 的 `dts - 30`（题目本来就要求它报错）、
   `test0601.R` 的 `object 'num' not found`、`test0801.R` 的 `count_even()`，
   这些报错是**题目的考点**，但在 WebR 里一旦报错后面的代码就不再执行，
   反而破坏了教学效果。现在结果都是静态的，不受影响。

### B. 作者提过的想法

- **把「在线运行」换成「预先生成的静态结果」** —— **已实施**（见上文「已完成」）。
  图片直接取自 `资料/汇总/第N周——xxx_files/figure-html/`，
  也就是作者当年用 Quarto 渲染出来的原始配图，**不需要跑 R**。
  第 10 讲按文件名里的 chunk 序号 7~12 与实验题 1~6 一一对应（已用源码内容核对过）。

  > 注意：文字输出的覆盖率只有 11/85。**不是漏做**——
  > 讲义里不少答案代码是重写的解法，和 汇总 源码逐句比对不一致时，
  > 贴 汇总 的输出会导致「结果与代码对不上」，宁可不贴。
  > 比对脚本思路见 `_extract-outs.mjs` / `_outdiff.mjs`（未纳入版本管理）。

- **第十周「初级绘图函数」不在网站上**：`资料/原题/第十周原题` 有 docx 和 8 个脚本，
  但**没有答案、也没有汇总**。若补成第 14 讲，需要给 ggplot2 之后的 4 讲顺号
  （URL 会变）。
- **不做**：把「原题+答案」额外导出成 Markdown。
  理由：已有 docx / HTML 两份副本，站点讲义本身就是更适合学生读的
  Markdown，再导一份只会增加不同步的风险。
