# study R in GDMU

gdmu 课程的在线讲义，目前包含三门课：

- **信息技术基础** —— 14 讲，从装机到统计检验的 R 语言入门
- **医学大数据分析与决策** —— 8 讲，R 在医学数据分析中的应用（回归、关联规则、分类、聚类、神经网络）
- **卫生统计学** —— 17 章知识点归纳，覆盖从统计描述到生存分析；另配一个统计方法选择器帮你挑方法

🌐 在线阅读：**<https://licloudgood.github.io/study-R-in-GDMU/>**

## 怎么用

1. 打开上面的网址，挑一门课，从第 1 讲开始按顺序看；
2. 每讲都有实验题，**先自己做**，做不出来再点「👀 查看参考答案」；
3. 答案里的代码点「📋 复制」，直接粘贴到 RStudio 里就能跑；
4. 不会装 R 的先看《信息技术基础》第 1 讲，把 R 和 RStudio 装好再往下；
5. 手上有一份数据、不知道该用哪个统计方法，就去**卫生统计学**板块里的
   **方法选择器**走一遍三步问答；那一页上还有一张完整的决策速查表，
   各种情况该用哪个方法都列在上面。

> 答案默认是收起来的，点开才看得到，这样不会一上来就被剧透。
>
> 《医学大数据分析与决策》每一讲开头都会列出**当讲要用到的 R 包和装法**，
> 跑之前先装好，不然脚本会在 `library()` 那一步直接报错。
>
> 《卫生统计学》是按章整理的**知识点归纳**，不是课程资料的搬运 ——
> 每一章讲清楚「这一章解决什么问题、核心概念是什么、在 R 里怎么做、容易踩什么坑」，
> 并链到前面两门课里对应的练习。

## 自己跑起来

```bash
npm install
npm run docs:dev      # 本地预览 http://localhost:5173/study-R-in-GDMU/
npm run docs:build    # 构建静态站点到 docs/.vitepress/dist
npm run docs:preview  # 预览构建结果
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

node scripts/generate-selector-page.mjs   # 页面正文 + 速查表 → choice.md
node scripts/test-selector.mjs            # 真浏览器把 33 条路径点一遍（需先起预览）
