# 第 3 章　队列研究

> 队列研究回答的问题很直接：**同样一群人，暴露于某个因素的与没暴露的，过一段时间之后谁更容易发病？** 它先分「因」、再等「果」，所以是观察性研究里**唯一能直接算出真实发病率、能直接算 RR** 的一类。

## 这一章要解决什么

描述性研究能告诉你「某病在吸烟的人里多见」，但这还只是**现象**。要说
「是吸烟导致了这个病」，至少在时间上得满足一件事：**先有吸烟，后有病**。

队列研究就是为这件事设计的：研究开始时，所有人都是**没得这个病**的；
按有没有暴露分成两组；然后**等**——看谁先发病。因为分母是真实的人、时间是真实的随访，
所以它能直接算出两组的**发病率**，进而算出「暴露组发病是暴露组的几倍」。

问题也随之来了：

- 谁能保证两组除暴露外其他条件一样？一堆人随访十年，失访跑掉三成，结果还可信吗？
- 样本要多大？随访要多久？
- 发病率算出来之后，光有一个「几倍」够不够？

这一章就按「概念 → 设计 → 资料分析 → 指标解释 → 优缺点」这条路走一遍。

## 核心概念

### 三个必须先分清的东西

**1. 暴露（exposure）**

指接触过某种物质、具备某种特征或处于某种状态。这些特征、因素或状态统称**暴露因素**。
注意它是**广泛的**：吸烟、饮酒、职业接触、放射线照射，甚至年龄、性别、亚健康状态，都可以算暴露。

**2. 队列（cohort）**

有共同经历或有共同暴露特征的一群人。按进出队列的时间不同，分两种：

| 类型 | 成员变化 | 结局频率该用什么 |
| --- | --- | --- |
| **固定队列**（fixed cohort） | 随访期间**既没有新成员加入**，也没有因结局以外的事件退出 | **累积发病率** |
| **动态队列**（dynamic cohort） | 成员不断退出、也不断有新成员加入 | **发病密度**（以人时为分母） |

> 这个区分不是抠字眼：**人群是固定的**，分母就是「起点的总人数」，算出来的叫累积发病率；
> **人群是动态的**，每个人被观察的时间长短不一，分母必须换成「人时」，否则分母无意义。

**3. 危险因素（risk factor）**

泛指能引起某特定不良结局，或使其发生概率增加的因子，包括个人行为、生活方式、环境和遗传等方面。
它与保护因素相对，两者都可作为研究因素，统称**决定因素**或**影响因素**。

### 基本原理

按研究对象**是否暴露**于某研究因素（或其不同水平），分成**暴露组 E** 与**非暴露组 Ē**，
随访一定时间，比较两组所研究结局的**发生率**差异，从而分析暴露与结局之间的关系。

需要说明的两点：

- 暴露不是研究者人为给予的，也不是随机分配的，而是**研究之前就已经客观存在**的——
  这正是队列研究区别于实验研究的根本。
- 分组可以不止两组：也可以按暴露**水平**分成高、中、低剂量组，为后面分析剂量-反应关系做准备。

### 研究方向：由因及果

队列研究的起点是**现在**，终点是**将来**：先确知暴露，再纵向观察结局。
因为暴露在结局之前就已确定，所以它**天然符合因果的时间顺序**——这是它检验因果假设能力较强的原因。

## 四个基本特点

| 特点 | 具体含义 |
| --- | --- |
| **观察法** | 暴露不是人为给予、不是随机分配，不受研究者意志决定 —— 这是与实验研究的分界 |
| **设立对照** | 设计阶段就设对照组；对照可以与暴露组来自同一人群，也可以来自不同人群 |
| **由因到果** | 一开始（疾病发生之前）就确立暴露情况，而后探求因果，符合时间顺序 |
| **检验因果联系能力较强** | 掌握了暴露状况并随访到结局，能**准确计算结局发生率**，估计暴露人群的危险程度 |

## 用途

1. **检验病因假设** —— 这是队列研究最主要的目的。一次研究可以只检验一种暴露与一种疾病
   （如吸烟与肺癌），也可以同时检验一种暴露与多种结局（如吸烟与肺癌、冠心病、慢性支气管炎）。
2. **评价预防措施效果** —— 当预防措施是研究对象的**自发行为**（多吃蔬菜、戒烟）时，
   可用队列研究评估其效果，这类情况也叫「**人群自然实验**」。
3. **研究疾病的自然史** —— 临床上只能观察单个病人从起病到痊愈或死亡；
   队列研究能观察**人群**暴露后疾病发生、发展直至结局的全过程，包括亚临床阶段。
4. **新药的上市后监测** —— 三期临床试验样本量和观察时间有限，上市后的大样本随访
   实质上是一项观察时间更长、样本量更大的队列研究，结局多为各种不良反应。

## 三种研究类型

按「研究对象进入队列的时间」与「观察终止时间」的关系分：

| 类型 | 暴露与结局信息 | 时间跨度 | 特点 |
| --- | --- | --- | --- |
| **前瞻性队列研究** | 研究开始时结局尚未发生，需随访才能获得 | 现在 → 将来 | 最基本类型；资料准确、偏倚少，但费时费钱 |
| **历史性队列研究**（回顾性队列） | 暴露和结局**都已经存在**于历史资料中 | 过去 → 现在 | 短时间即可完成，省时省力；前提是历史资料准确完整 |
| **双向性队列研究** | 历史资料 + 继续前瞻随访 | 过去 → 现在 → 将来 | 兼有两者优点，一定程度弥补各自不足 |

> 三种类型**性质上都是由因及果**，区别只在「资料是回头去找，还是往后去等」。

## 设计与实施

### ① 研究因素（暴露因素）

- 一次队列研究**通常只研究一种暴露因素**（一种暴露可对应多种结局）。
- 设计时必须做到**明确的定义、选择和测量**。例如研究吸烟与肺癌时，要把「吸烟者」
  定义成「平均每天吸烟一支及以上、持续一年以上者」——定义不明确，结果就没法解释。
- 定量因素要有明确的度量单位；不易获得准确定量数据时，可按暴露水平**分成等级**，
  同时记录**暴露方式**和**暴露时间**，以便后续分析剂量-反应关系。
- 测量方法要**敏感、精确、简单、可靠**。

### ② 研究结局（结局变量）

指观察对象出现的预期结果事件。主要包括：

- 发病、死亡、机体生理生化指标的变化；
- 健康状况和生命质量的改变；
- 既有定量变量（血压、血糖的改变），也有定性变量（发病、康复）。

要点：**判断标准必须明确统一并在研究过程中严格执行**；结局是**个体观察的终止**
（出现结局者不再随访，未出现者随访至观察期结束）；观察的结局越多，
组间需要均衡的因素就越多、工作量越大。

### ③ 研究对象

**研究现场**是研究对象的来源地，要具备：符合条件的研究对象数量足够、医疗条件好、
当地重视配合、人口相对稳定、交通便利 —— 目的都是**减少失访**。

原则：**代表性、未患所研究疾病、可比性**。两组在研究开始时都未出现结局，但随访中可能发生。

**暴露组的四种来源：**

| 来源 | 适用情形 |
| --- | --- |
| **职业人群** | 研究可疑职业暴露与疾病/健康状况的关系 |
| **特殊暴露人群** | 研究某种**罕见暴露**（如放射线照射与白血病） |
| **一般人群** | 暴露因素在一般人群中暴露率较高（遗传特征、饮食习惯、生活嗜好） |
| **有组织的人群团体** | 医学会、学校、部队等，便于有效随访（如从注册医师中选吸烟组） |

**对照组的四种形式**（核心要求：除不暴露外，其他可能影响结局的因素都要尽可能与暴露组相同）：

| 形式 | 做法 | 优点 / 注意 |
| --- | --- | --- |
| **内对照** | 在同一群研究对象内部，把暴露者作暴露组、其余作对照 | 最省事、可比性最好，能从总体上了解发病率；定量暴露可按剂量分级，以最低水平为对照 |
| **外对照** | 在暴露人群之外另选一组 | 暴露人群特殊时用；可比性要额外把关 |
| **总人口对照** | 以全人群的发病/死亡率为参照 | 资料易得，但人群构成往往不可比，通常要做**标准化** |
| **多重对照** | 同时用上述两种以上对照 | 结论更稳健，工作量更大 |

### ④ 样本量

- 对照组样本量**不宜少于**暴露组，通常取等量。
- 必须**预先估计失访率**，按比例扩大样本量。

### ⑤ 资料的收集与随访

**基线资料**：暴露资料、与结局判断有关的资料、人口学资料，以及可能引起混杂作用的因素。
收集途径：查阅已有档案、现场询问、体格检查、实验室检查、环境调查与检测。

**随访**：明确随访对象、内容、方法、期限。

## 资料整理与分析

### 第一步：描述一般特征 + 可比性分析

描述两组在年龄、性别、民族、职业、居住地区等方面的分布，并做**组间均衡性检验**，
判断两组是否可比。这是所有后续分析的前提。

### 第二步：选对分母 —— 累积发病率 vs 发病密度

| 队列类型 | 指标 | 分母 | 取值范围 |
| --- | --- | --- | --- |
| **固定队列** | **累积发病率**（cumulative incidence） | 研究开始时的总人数 | 0 ~ 1 |
| **动态队列** | **发病密度**（incidence density） | **人时**（人年） | 0 ~ ∞ |

为什么动态队列不能再用「总人数」当分母？因为观察时间长、人口不稳定：进入时间先后不一、
迁移或竞争性死亡造成失访、各人出现终点的时间不同 —— 每个人**被观察的时间**根本不一样。
退出的人如果坚持到随访结束，本来仍有发病的可能，直接按总人数算等于把他们的贡献抹掉了。

### 人时的计算

**人时** = 观察人数 × 观察时间，常用单位是**人年**。三种算法：

1. **以个人为单位**精确计算（每人从进入到退出/发病的实际时间相加）；
2. **近似法**（用平均人数 × 观察年数）；
3. **寿命表法**（按时间段分段计算，适合大样本、只知道分组信息的情况）。

### 第三步：标化比（SMR）

当研究对象数量少、结局发生率低，**不宜直接计算率**时，以全人口的发病（死亡）率为标准，
算出该人群的**预期**发病人数，再与实际观察人数相比：

$$\text{SMR} = \frac{\text{实际死亡（发病）数}}{\text{预期死亡（发病）数}}$$

- $\text{SMR} = 1$：研究人群的危险 = 标准人群；
- $\text{SMR} > 1$：高于标准人群，是标准人群的 SMR 倍；
- $\text{SMR} < 1$：低于标准人群。

适用条件：结局事件发生率低、不宜直接计算率、以全人群为对照。
注意 **SMR 不是率，而是一个比**，流行病学意义与效应指标 RR 类似。

### 第四步：显著性检验

两组率有差别时，首先要排除抽样误差：**发病率高**时用 $z$ 检验或 $\chi^2$ 检验；
**发病率低**时用二项分布或泊松分布。

## 关联强度：五个指标

这是本章的重点。五个指标分两类：**比值**（RR）和**差值**（AR 族）。

### 相对危险度 RR

$$\text{RR} = \frac{\text{暴露组发病率}}{\text{非暴露组发病率}} = \frac{I_e}{I_0}$$

意义：**暴露组发病或死亡的危险是非暴露组的多少倍**。RR 越大，暴露的效应越大、关联越强。

| RR 范围 | 关联强度 |
| --- | --- |
| 0.9 ~ 1.0 或 1.0 ~ 1.1 | 无 |
| 0.7 ~ 0.8 或 1.2 ~ 1.4 | 弱 |
| 0.4 ~ 0.6 或 1.5 ~ 2.9 | 中 |
| 0.1 ~ 0.3 或 3.0 ~ 9.9 | 强 |
| < 0.1 或 10 ~ | 很强 |

由于样本 RR 只是总体 RR 的点估计，受抽样误差影响，要给出 **95% 可信区间**
（常用 Miettinen 法或 Woolf 法）。**区间包含 1，就不能说有关联。**

### 归因危险度 AR

$$\text{AR} = I_e - I_0$$

意义：暴露组与非暴露组相比**多出来的发病数量**；也等于**消除暴露后在暴露人群中可减少的发病数**。
又称危险度差。

### 归因危险度百分比 AR%（病因分值 EF）

$$\text{AR}\% = \frac{I_e - I_0}{I_e} \times 100\%$$

意义：暴露人群中的发病（死亡）**归因于暴露的部分，占全部发病的百分比**。

### 人群归因危险度 PAR

$$\text{PAR} = I_t - I_0$$

其中 $I_t$ 为总人群率，$I_0$ 为非暴露组率。
意义：暴露导致**一般人群**所增加的疾病发生率；消除暴露后总人群可减少的发病数量。

### 人群归因危险度百分比 PAR%

$$\text{PAR}\% = \frac{I_t - I_0}{I_t} \times 100\% \quad\text{或}\quad \text{PAR}\% = \frac{P_e(\text{RR}-1)}{P_e(\text{RR}-1)+1} \times 100\%$$

其中 $P_e$ 为总人群的暴露比例。
意义：总人群全部发病（死亡）中**归因于暴露的百分比**。

### ★ RR 与 AR 的区别（最容易考、也最容易混）

| | RR | AR |
| --- | --- | --- |
| 类型 | 比值（相对量） | 差值（绝对量） |
| 回答的问题 | 暴露者发病是**非暴露者的几倍** | 暴露让**人群多发生多少例** |
| 意义 | **病因学意义** —— 判断因素是不是病因 | **公共卫生/预防意义** —— 消除暴露能救多少人 |
| 典型结论 | 吸烟对**肺癌**的 RR 大，说明吸烟是肺癌的重要病因 | 戒烟对**心血管疾病**的 AR 大，说明戒烟的公共卫生收益更大 |

> 一句话记法：**RR 看「倍数」，AR 看「人数」**。
> 一个因素可能 RR 很高但 AR 很低（罕见病的强危险因素），也可能 RR 不高但 AR 很高
> （常见病的弱危险因素）—— 前者适合做病因研究，后者适合做人群干预。

## R 代码：把五个指标算一遍

下面用一份**构造的示例数据**（仅用于演示算法，不代表真实研究结论）：

- 吸烟组 1000 人，发病 50 人；非吸烟组 2000 人，发病 20 人。

```r
# 四格表：行 = 是否暴露，列 = 是否发病
a <- 50    # 暴露组发病
b <- 1000 - a   # 暴露组未发病
c <- 20    # 非暴露组发病
d <- 2000 - c   # 非暴露组未发病

# 两组发病率
Ie <- a / (a + b)        # 暴露组 0.05
I0 <- c / (c + d)        # 非暴露组 0.01

RR <- Ie / I0            # 相对危险度
AR <- Ie - I0            # 归因危险度
ARp <- AR / Ie           # 归因危险度百分比

# 总人群
It <- (a + c) / (a + b + c + d)
PAR <- It - I0           # 人群归因危险度
PARp <- PAR / It         # 人群归因危险度百分比
Pe <- (a + b) / (a + b + c + d)   # 人群暴露比例

cbind(Ie, I0, RR, AR, ARp, It, PAR, PARp, Pe)
```

结果：$I_e=0.05$、$I_0=0.01$、$\text{RR}=5$、$\text{AR}=0.04$、$\text{AR}\%=80\%$、
$I_t\approx0.0233$、$\text{PAR}\approx0.0133$、$\text{PAR}\%\approx57.1\%$、$P_e\approx0.333$。

可以用 $P_e$ 那条公式回代验算 PAR%：

$$\frac{0.333\times(5-1)}{0.333\times(5-1)+1} = \frac{1.333}{2.333} \approx 57.1\%$$

::: tip 两个常见的手算错误
1. **把 AR% 的分母写成 $I_0$**。AR% 的分母是**暴露组**发病率 $I_e$（问的是「暴露人群的发病里有多少归因于暴露」）；
   PAR% 的分母才是**总人群**率 $I_t$。
2. **RR 的可信区间算了却没有看**。RR 是个点估计，必须配 95% CI；
   **区间跨过 1 就直接说明没有统计学关联**，不要再拿点估计去解读倍数。
:::

## 优点与局限

### 优点

1. **符合因果关联的时间顺序** —— 先有暴露、后有结局，这是它最强的立论基础；
2. **资料较为准确可靠** —— 暴露资料与结局判断都是前瞻收集、标准统一；
3. **可以直接估计 RR 和 AR 等关联强度指标** —— 因为能直接算发病率（病例对照研究做不到）；
4. **一次调查可观察到多种疾病** —— 一种暴露对应多种结局，效率高。

### 局限

1. **耗费人力、物力、财力和时间** —— 随访周期长，尤其前瞻性研究；
2. **失访偏倚** —— 失访者往往不是随机缺失的，这是队列研究最需要防的问题；
3. **研究设计要求高、实施过程复杂**；
4. **不适于发病率很低的疾病的病因研究** —— 需要极大样本量；
5. **随访过程中可能有未知变量引入或已知变量改变** —— 使分析复杂化。

## 常见误区

::: warning 别踩这几个坑
- **「队列」不是「一群同期的人」那么简单。** 固定队列和动态队列的分母不一样，
  用错了指标（例如给动态队列算累积发病率），数字就没有意义。
- **把 RR 当成「发病率」**。RR 是两组率的**比值**，无量纲；说「RR = 5」不是「发病率 5%」。
- **只报 RR 不报 AR。** 公共卫生决策更需要 AR —— 罕见病即使 RR 很高，人群层面的收益也可能很小。
- **失访率高还照常下结论。** 失访率一般要求控制在 10% 以内；失访者在两组分布不均衡时，
  结论会被系统性地带偏，而且**加大样本量无法补救**。
- **把历史性队列研究当成病例对照研究。** 两者都用历史资料，但分组依据不同：
  历史性队列按**暴露**分组，病例对照按**结局**分组 —— 前者仍是由因及果。
:::

## 小结

1. **队列研究按暴露分组、随访比较结局发生率**，方向是由因及果，是观察性研究里
   检验因果假设能力最强的一类。
2. **固定队列用累积发病率，动态队列用发病密度（人时）** —— 分母选错，全盘皆错。
3. **五个关联指标**：RR（倍数）、AR（差值）、AR%（暴露人群归因占比）、
   PAR（总人群多出的发病）、PAR%（总人群归因占比）。
4. **RR 是病因学指标，AR 是公共卫生指标** —— 这是本章最该记住的一句话。
5. 优点是时间顺序清楚、资料可靠、能直接算 RR/AR、一因多果；
   缺点是费钱费时、易失访、不适于罕见病。
