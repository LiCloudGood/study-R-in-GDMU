# 第 5 章　偏倚及其控制

> 前一章说「病例对照研究产生偏倚的机会较多」。这句话到底指什么？这一章把「结果为什么会偏」拆成三大类、13 种，并给出每一个环节的对策。**这是全课程里最实用的一章**——读文献时判断一篇研究可不可信，主要就看它有没有交代偏倚。

## 这一章要解决什么

一个反直觉的事实：**偏倚不能靠加大样本量解决**。

抽样误差是「运气问题」，样本越大越接近真值；
而偏倚是「方向问题」，样本越大，**错误的结论只会被估计得更精确**。

举个最经典的例子：某研究在企业里选「健康工人」作调查对象，分析某暴露与健康的关系。
这些工人本来就是因为身体好才能上岗的，所以发病率天然比一般人群低——
这就是**易感性偏倚**（也叫健康工人效应）。你再招十万人，这个偏差一分都不会减少。

所以这一章要回答三件事：

1. 什么算偏倚（和随机误差怎么分）？
2. 偏倚有哪几类、各是怎么产生的？
3. 在**设计、实施、分析**三个阶段分别怎么防？

## 一、偏倚的定义

### 误差的两大类

研究结果偏离真实值，原因只有两类：

| 类型 | 来源 | 特点 | 能否消除 |
| --- | --- | --- | --- |
| **随机误差**（抽样误差） | 个体变异 + 抽样 | **无方向**，围绕真值上下波动 | 不能消除，只能通过设计和大样本**减小** |
| **系统误差** | 测量、选择、混杂等 | **有方向**，系统性地偏高或偏低 | **可以避免**，靠良好的设计与分析 |

**系统误差在流行病学中又称为偏倚。**

### 定义

> **偏倚**（bias）是指由一些**已知或可控制**的原因引起的，
> 使研究结果或推论**系统地偏离真实情况**的现象。

这句话里有三个要点：

1. **系统性** —— 不是随机的上下波动，而是朝一个方向偏；
2. **源于已知或可控制的原因** —— 所以它是**可以避免的**，这也是研究设计的意义所在；
3. **偏离真实情况** —— 包括「结果本身偏」和「推论偏」（外推时出错）。

::: warning 偏倚 ≠ 抽样误差
- 抽样误差：样本少了，**碰巧**抽到的不是典型的一批人 → 加大样本可以减小；
- 偏倚：**选择方法、测量方法、分析思路**本身有问题 → 加大样本**只会把错误估得更准**。

看到「样本量大所以可信」这种说法，就要警觉：**大样本不能救设计**。
:::

## 二、偏倚的分类

按产生环节分三大类：

```
偏倚
├── 01 选择偏倚  ←  研究对象是怎么选进来的
├── 02 信息偏倚  ←  资料是怎么测出来、问出来的
└── 03 混杂偏倚  ←  有没有第三个因素在捣乱
```

### 01 选择偏倚（selection bias）

**定义**：在流行病学的研究过程中，由于**选择方法不当**，导致**入选的研究对象与未入选对象之间存在系统差异**，
由此造成的偏倚称为选择偏倚。

**为什么会产生**：由于疾病症状的严重程度、患者就医的条件、人群对某一疾病的认识程度，
以及医疗保健制度和社会文化经济等因素的差异，使病人出现了**不同的入院率**，
因而可能会**夸大或掩盖**某因素与某疾病的真实联系。

**七种常见类型**：

| 类型 | 含义 | 典型场景 |
| --- | --- | --- |
| **入院率偏倚**（Berkson 偏倚） | 以医院病人为对象时，因不同疾病的**入院率不同**，导致病例组与对照组在某些特征上的差异被虚假地放大或缩小 | 医院为基础的病例对照研究 |
| **检出症候偏倚** | 某因素本身能**引起所研究疾病的症状**，使患者更早就医、更易被检出，于是该因素与疾病出现虚假关联 | 某药引起轻微出血 → 患者就诊增多 → 查出更多早期病变 |
| **现患病例-新发病例偏倚**（Neyman 偏倚） | 用**现患病例**作研究对象时，病程长、存活久的人被选中的机会更大；若暴露与生存有关，结果就被歪曲 | 只选存活病人研究致死性因素的效应 |
| **无应答偏倚** | 调查对象**拒绝回答或未回答**，且无应答者的特征与应答者系统不同 | 健康调查中病人不愿意配合 |
| **失访偏倚** | 研究对象**中途退出**，且失访者在两组间分布不均衡 | 队列研究随访多年 |
| **时间效应偏倚** | 研究对象在**不同时间**进入研究，经历了不同的外部环境变化，造成组间不可比 | 多年累积入组的病例 |
| **易感性偏倚** | 研究对象因**自身易感性**与目标人群不同而造成偏倚 | **健康工人效应**：能上岗的工人本身更健康 |

> 「易感性偏倚」和「健康工人效应」是同一个东西的两种叫法，
> 本质是**被选进来的人本来就更健康**。

### 02 信息偏倚（information bias）

**定义**：在收集资料的过程中，由于**测量方法、询问方式、诊断标准**等方面的缺陷，
使研究结果与真实情况之间产生系统误差。

**六种常见类型**：

| 类型 | 含义 | 典型场景 |
| --- | --- | --- |
| **回忆偏倚** | 研究对象对**既往暴露**的回忆不准确、不完整，且病例与对照的回忆质量不同 | 病例更努力回忆自己的暴露史 |
| **报告偏倚** | 研究对象因**顾虑或利害关系**而隐瞒或夸大某些信息 | 询问性行为、收入、吸烟量 |
| **诊断怀疑偏倚** | 因研究者**已知研究假设**，在诊断时对暴露组更仔细地查找疾病 | 队列研究中暴露组被查得更细 |
| **暴露怀疑偏倚** | 研究者**已知结局**，在追问暴露时对病例组问得更仔细 | 病例对照研究中追问病例更详尽 |
| **测量偏倚** | 测量仪器、试剂、方法、操作者不一致或有系统偏差 | 不同批号试剂、不同操作者 |
| **发表偏倚** | **阳性结果更易被发表**，导致文献中效应被高估 | Meta 分析（见 [卫生统计学 第 16 章](/Health-statistics/16-meta-analysis)） |

> **回忆偏倚 vs 报告偏倚**：前者是「**想不起来**」（记忆问题），
> 后者是「**不想说**」（意愿问题）。两者的控制办法完全不同：
> 回忆偏倚靠**客观记录**（病历、化验单），报告偏倚靠**匿名化**和**消除顾虑**。

> **诊断怀疑 / 暴露怀疑**都是「研究者知道得太多」造成的——
> 所以对策是**盲法**。

### 03 混杂偏倚（confounding bias）

**定义**：混杂偏倚是指**研究因素与疾病之间的关联程度受到其他因素的歪曲或干扰**。

导致混杂产生的因素称为**混杂因素**（confounder），它有两个条件：

1. **与疾病有关联**；
2. **与研究因素存在相关**。

若混杂因素在比较的人群组中**分布不均衡**，就可以**掩盖或夸大**研究因素与疾病之间的真实联系。

::: tip 混杂因素成立的三个条件（合起来才算）
1. 与所研究的**疾病**有关（是疾病的危险因素）；
2. 与所研究的**暴露**有关（在暴露组与非暴露组中分布不同）；
3. **不是**暴露与疾病之间因果链上的**中间环节**。

第 3 条最容易被忽略：如果某因素是「暴露 → 该因素 → 疾病」链条上的一环，
它就是**中介变量**，控制它反而会把真实的效应抵消掉。

一个经典例子：血清甘油三酯与冠心病单看确实相关，但冠心病还与低密度脂蛋白胆固醇、
高密度脂蛋白胆固醇等有关；用统计方法平衡这些因素后，联系就消失了。
:::

### 三类偏倚的对照

| | 选择偏倚 | 信息偏倚 | 混杂偏倚 |
| --- | --- | --- | --- |
| **出问题的环节** | 选谁进来 | 怎么测/怎么问 | 分析时有没有第三个因素 |
| **本质** | 两组**本来就不可比** | 两组的**测量不准且程度不同** | 效应被**第三个因素**混进来 |
| **典型代表** | 入院率偏倚、健康工人效应 | 回忆偏倚、测量偏倚 | 年龄、性别、病情程度 |
| **能不能事后补救** | **基本不能**（木已成舟） | 部分可以（用客观记录） | **可以**（分层、多因素分析） |

> 这个对照很有用：**选择偏倚最难补救**（人已经选完了），
> **混杂偏倚最好处理**（分析阶段还能控制），**信息偏倚居中**。

## 三、偏倚的控制

按研究进程分三个阶段，每个阶段各有侧重：

### 设计阶段（最重要的阶段）

| 针对 | 措施 |
| --- | --- |
| **选择偏倚** | **随机抽样**；明确**入选和排除标准**；设立**多种对照** |
| **信息偏倚** | 尽量采用**客观指标**（化验、记录），少依赖主观报告 |
| **混杂偏倚** | **随机化**、**限制**（只选某一层次的人）、**匹配**（使两组在某因素上一致） |

### 实施（资料收集）阶段

| 针对 | 措施 |
| --- | --- |
| **选择偏倚** | **严格按设计执行**，不随意更换对象、不随意剔除；提高应答率，减少失访 |
| **信息偏倚** | **统一培训**调查员；采用**盲法**；**仪器与试剂标准化**；统一调查表与询问方式 |
| **混杂偏倚** | 完整、准确地记录可能的混杂因素（为分析阶段控制留出余地） |

### 分析阶段

| 针对 | 措施 |
| --- | --- |
| **选择偏倚** | **标准化**（消除构成差异）；分层、多因素；必要时做**敏感性分析** |
| **信息偏倚** | 一般**无法在分析阶段纠正**——只能靠前面的设计和实施。可做敏感性分析估计影响大小 |
| **混杂偏倚** | **分层分析**、**标准化**、**多因素分析**（把混杂因素作为协变量） |

::: warning 一条铁律
**偏倚的控制必须「设计在前」。**

选择偏倚一旦发生，事后几乎无法纠正（你没法把没选进来的人补回来）；
信息偏倚一旦测偏，原始数据就是错的；
只有混杂偏倚还能在分析阶段靠分层和多因素模型部分挽救。

所以**研究设计是唯一真正的防线**。这也是为什么评价一篇文献时，
先看它的**设计**，而不是先看它的 **P 值**。
:::

## 常见误区

::: warning 六个高频错误
- **以为样本大就没有偏倚。** 恰恰相反，样本越大偏倚的后果越严重——它会让错误结论看起来更「确凿」。
- **把随机误差和偏倚混为一谈。** 随机误差靠**增大样本**减小，偏倚靠**改进设计与测量**避免。
- **在病例对照研究里忽略了入院率偏倚。** 医院里不同疾病的入院率不同，医院对照天然不可比。
- **只选现患病例研究致死性因素。** 会低估效应甚至出现方向反转（现患—新发病例偏倚）。
- **把中介变量当混杂因素控制。** 会把真实效应「控制没了」，得出「无关联」的错误结论。
- **只在分析阶段想办法。** 设计阶段没控制住的选择偏倚，分析阶段基本无从补救。
:::

## 小结

1. **误差分两类**：随机误差（无方向、可减小不可消除）与系统误差（**即偏倚**，有方向、可避免）。
2. **偏倚有三类**：
   - **选择偏倚** 7 种：入院率、检出症候、现患—新发病例、无应答、失访、时间效应、易感性（健康工人效应）；
   - **信息偏倚** 6 种：回忆、报告、诊断怀疑、暴露怀疑、测量、发表；
   - **混杂偏倚**：混杂因素需同时满足「与疾病有关」「与暴露有关」「不是中间环节」。
3. **控制按阶段**：
   - **设计阶段**——随机抽样、纳入排除标准、多种对照、随机化、限制、匹配、客观指标；
   - **实施阶段**——严格按设计、统一培训、盲法、仪器试剂标准化；
   - **分析阶段**——标准化、分层、多因素分析。
4. **选择偏倚最难补救，混杂偏倚最好处理，信息偏倚居中**——所以设计是唯一真正的防线。
