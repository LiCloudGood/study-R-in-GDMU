# 第 2 章　描述流行病学

> 一切流行病学研究都从「摸清情况」开始：这个病**在什么人身上、什么时间、什么地区**多？先把这幅图画出来，才谈得上找原因。这一章上半部讲**怎么算**（频率指标），下半部讲**怎么查**（现况研究）。

## 这一章要解决什么

拿到一份疾病数据，最先要回答的其实是三个很朴素的问题：

- 这个病到底**多不多**？（该用哪个指标？发病率还是患病率？）
- 这些病人在**什么人、什么时间、什么地区**集中？（三间分布）
- 想自己去做一次调查，**人怎么抽、抽多少、怎么问**？（现况研究）

前两个问题决定了后面所有分析的基础——**指标选错、分母搞错，后面全错**。
第三个问题是绝大多数流行病学工作的起点，也是最容易出偏倚的环节。

# 第一部分　疾病分布与测量指标

## 基本指标：率、相对比、构成比

这是描述疾病分布最基本的三类指标，**用错是最常见的低级错误**。

| 指标 | 定义 | 例子 |
| --- | --- | --- |
| **率**（rate） | 某种现象实际发生的例数与**可能发生该现象的总例数**之比 | 发病率、患病率、死亡率、病死率 |
| **相对比**（ratio） | 两个有关事物指标之比，说明一个指标是另一个的几倍或百分之几 | 性别比、相对危险度 |
| **构成比**（proportion） | 事物或现象**内部各组成部分**的比重 | 死因构成、年龄构成 |

::: warning 构成比 ≠ 率
「某院收治的 1907 例麻疹患儿中 1 岁组占 37.49%，所以 1 岁儿童麻疹发病率最高」——**这句话是错的**。

那个 37.49% 的分母是「收治的患儿」，属于**构成比**；要说明「谁容易得病」，
分母必须是「各年龄组的儿童总数」，那才是**发病率**。

判断口诀：**看到「更容易、更严重、高发」这类词，就必须用率，不能用构成比。**
:::

## 发病频率指标

### 发病率（incidence rate）

> 一定期间内，一定范围人群中某病**新发生病例**出现的频率。

$$\text{发病率} = \frac{\text{期间内新发病例数}}{\text{同期暴露人口数}} \times K$$

$K$ 可取 100%、1000‰、10000/万等。

**计算时必须考虑三件事**：

1. **新发病例数** —— 以**第一次就诊**为准，旧病例不计入；同一个人患两次流感要计**两个**新病例；
2. **暴露人口数** —— 必须是「**可能发生**该病的人」。算麻疹发病率时，
   已患过麻疹（终身免疫）的人不应计入；
3. **观察时间** —— 一般为一年。

**应用**：了解疾病流行特征、探讨病因因素、提出病因假说、评价防制措施的效果。

### 罹患率（attack rate）

> 测量某人群某病新病例发生频率的指标，通常指**某一局限范围内短时间**的发病率。

公式与发病率相同，但观察时间**较短**，可以日、周、旬、月为单位，使用灵活。
优点是能根据**暴露程度**较精确地测量发病频率。

**常用于**：食物中毒、职业中毒、传染病的暴发及流行。

### 续发率（secondary attack rate, SAR）

> 也称二代发病率。指在某传染病**最短潜伏期到最长潜伏期之间**，
> **易感接触者**中发病人数占所有易感接触者总数的百分比。

$$\text{SAR} = \frac{\text{易感接触者中发病人数}}{\text{易感接触者总数}} \times 100\%$$

**用途**：比较传染病**传染力的强弱**、分析流行因素（年龄、性别、家庭儿童数、家庭人口数、
经济条件等）、评价防疫措施效果（免疫接种、隔离、消毒等）。

> 续发率是「**在已有一个原发病例之后**，接触者里又病了几个」——它衡量的是**传播能力**，
> 所以分母只算**易感**接触者，已经免疫的人要排除。

## 患病频率指标

### 患病率（prevalence rate）

> 也称现患率。指**某特定时间内**总人口中某病**新旧病例**所占的比例。

$$\text{患病率} = \frac{\text{某时点新旧病例数}}{\text{该时点人口数}} \times K$$

$K$ 可取 100%、1000‰、10000/万、100000/10 万等。

按观察时间分：**时点患病率**（某一时点）与**期间患病率**（一段时间内）。

### 影响患病率的因素

这是理解患病率的关键——它同时受**发病率**和**病程**影响：

| 方向 | 具体因素 |
| --- | --- |
| **升高** | 新病例增加（发病率增高）；治疗水平提高使患者免于死亡但未痊愈，**病程延长**；未治愈者寿命延长；病例迁入；健康者迁出；易感者迁入；诊断水平提高；报告率提高 |
| **降低** | 新病例减少（发病率下降）；**病死率增高**；病程缩短；治愈率提高；健康者迁入；病例迁出 |

### 患病率、发病率与病程的关系

用一个「蓄水池」来理解：

```
        新发病例（流入）
              ↓
        ┌───────────┐
        │  现患病例  │  ← 患病率 = 池子里的水量
        └───────────┘
              ↓
   痊愈 / 死亡 / 迁出（流出）
```

当某地某病的**发病率和病程在相当长时间内保持稳定**时：

$$\text{患病率} = \text{发病率} \times \text{病程}$$

这条关系式解释了一个反直觉的现象：**治疗进步反而可能让患病率上升**——
病人活得更久、但没治愈，池子里的水就积得更多。

### 发病率与患病率的比较

| 分类 | 发病率 | 患病率 |
| --- | --- | --- |
| **资料来源** | 疾病报告、疾病监测、队列研究 | 现况调查 |
| **计算分子** | 观察期间**新发**病例数 | 观察期间病例数（**新、旧**病例） |
| **计算分母** | 平均人口数或暴露人口数 | 调查人数或平均人口数 |
| **观察时间** | 一般为 1 年或更长 | 较短，一般 1 个月或几个月 |
| **适用疾病** | 各种疾病 | 慢性病或病程较长疾病 |
| **特点** | **动态**描述 | **静态**描述 |
| **用途** | 疾病流行强度 | 疾病现患状况或慢性病流行情况 |
| **影响因素** | 相对少（流行情况、诊断水平、报告质量） | 较多（含影响发病率的因素、病后转归、病程） |

### 感染率（infection rate）

> 在某时间内被检人群中某病原体**现有感染者**人数所占的比例，通常用百分率表示。

性质与患病率相似。**应用广泛**，特别适合调查**隐性感染、病原携带者、轻型和不典型病例**。
可通过检出病原体发现感染者，也可用血清学、分子生物学方法检出。

常用于研究传染病或寄生虫病的感染情况、评价防制效果，也是评价人群健康状况的常用指标。

## 死亡与生存频率指标

### 死亡率（mortality rate）

> 一定期间内，某人群中总死亡人数在该人群中所占的比例，是测量人群死亡危险最常用的指标。

$$\text{死亡率} = \frac{\text{同期内死亡总数}}{\text{某年平均人口数}} \times K$$

**应用**：反映一个人群总死亡水平，衡量某一时期、某一地区人群死亡危险性的大小。

::: warning 粗死亡率不能直接比较
不同年龄组死亡率差别很大（婴幼儿和老年人高、青少年低）。所以当死亡率出现差异时，
可能是**年龄别死亡率**真的不同，也可能只是**人口年龄构成**不同。

规范做法：**分层比较**，或计算**标准化死亡率**（按标准人口年龄构成计算）。
:::

**死亡专率**：按病种、年龄、性别、职业、地区、种族等分类计算的死亡率。

### 病死率（case fatality rate）

> 一定时期内**因某病死亡者**占**该病患者**的比例，表示某病患者因该病死亡的危险性。

$$\text{病死率} = \frac{\text{观察期间因某病死亡人数}}{\text{同期该病病人数}} \times 100\%$$

**应用**：表示确诊某病者的死亡概率，可反映疾病的**严重程度**，也可反映**医疗水平**和诊治能力。
常用于急性传染病，较少用于慢性病。

> **病死率与死亡专率的分母完全不同**：病死率的分母是**病人**，死亡专率的分母是**人口**。
> 住院病人的病死率不能代表地区的病死率（住院病人病情普遍较重、且未必来自同一地区）。

### 婴儿死亡率（infant mortality rate, IMR）

> 婴儿出生后不满周岁死亡人数与出生人数的比率。

$$\text{IMR} = \frac{\text{某年未满周岁死亡数}}{\text{同年活产总数}} \times 1000‰$$

分子包括：上一年出生、本年死亡的未满周岁婴儿数 + 本年出生、本年死亡的未满周岁婴儿数。

**意义**：反映一个国家或地区**居民健康状况、医疗卫生条件、社会经济发展水平**的重要指标，
也是衡量人口素质的重要依据之一。

### 生存率（survival rate）

> 接受某种治疗的病人或某病患者中，经 $n$ 年随访**尚存活**的病人数所占的比例。

**应用**：反映疾病对生命的危害程度，可用于评价某些**病程较长**疾病的远期疗效
（慢性病，如癌症、心血管疾病、结核病等）。

> 生存率与死亡率的区别在于它**动用了随访**，而且分母只算「随访满 $n$ 年」的人——
> 这正是[卫生统计学 第 14 章 生存分析](/Health-statistics/14-survival-analysis)要展开的内容。

## 疾病流行强度

**流行强度**指一定时期内，某病在某地区某人群中**发病率的变化**及其**病例间的联系程度**。

| 强度 | 定义 | 要点 |
| --- | --- | --- |
| **散发**（sporadic） | 发病率呈**历年的一般水平**，各病例间在发病时间和地点上无明显联系 | 一般与当地**近三年**该病发病率比较 |
| **暴发**（outbreak） | 在一个**局部地区或集体单位**中，**短时间内**突然发生很多症状相同的病人 | 多有相同的传染源或传播途径；病人常同时出现在最短与最长潜伏期之间 |
| **流行**（epidemic） | 某地区某病发病率**显著超过**该病历年发病率水平 | 各病例间有明显的时间和空间联系，具有共同传播因素 |
| **大流行**（pandemic） | 发病率显著超过历年水平，疾病蔓延迅速、涉及地区广，短期内跨越省界、国界甚至洲界 | 世界性流行 |

**散发常见的四种情形**：

1. 病后免疫力持久的疾病，或因预防接种使人群维持一定免疫水平的疾病（如麻疹）；
2. 以**隐性感染**为主的疾病（如脊髓灰质炎、乙型脑炎）；
3. 传播机制不容易实现的传染病（如斑疹伤寒、炭疽）；
4. 某些**长潜伏期**传染病（如麻风）。

> 散发、暴发、流行、大流行的差别是**量级**，不是性质。判断「流行」的关键是
> 「**显著超过历年水平**」——所以必须有历史基线，否则无从判断。

## 疾病的三间分布

> 由于致病因子、人群特征以及自然和社会环境等多种因素的综合作用，
> 疾病在不同人群、不同地区及不同时间的流行强度不一。
> **疾病三间分布的描述是流行病学研究的起点。**

对**已知病因**的疾病，流行特征是判断和解释的依据；
对**病因未明**的疾病，流行特征是病因的外在表现，是**形成病因假设的重要线索**。

### 一、人群分布

描述人群的不同特征（年龄、性别、职业、种族等）与疾病发生的关系。
目的是**确定高危人群、探索病因及流行因素**。

涉及的特征：年龄、性别、职业、种族和民族、社会阶层、行为生活方式、婚姻与家庭、流动人口。

#### 年龄（最重要的因素）

**疾病与年龄的关系比与人群其他特征的关联更强**，是人群分布中最重要的因素。

一般规律：**慢性病随年龄增长发病率增加；急性传染病随年龄增加发病率下降。**

三种典型情形：

1. 无有效计划免疫措施、易于传播且病后免疫力持久的疾病，**儿童发病率最高**（麻疹、百日咳、腮腺炎）；
   实施预防接种后，**高发年龄会后移**。若某地长期无流行，一旦有传染源输入，各年龄组发病率可能无差异。
2. 由于**暴露机会、生活习惯、行为**差异，某些疾病在特定年龄高发：
   交通事故、艾滋病多见于青壮年；恶性肿瘤、糖尿病、冠心病随年龄增长而增加。
3. 同一种疾病可因**流行型别**不同而表现年龄差异。

**研究年龄分布的目的**：探索致病因素、提供病因线索；确定高危人群及重点保护对象；
对传染病还可观察人群**免疫状态**的变化趋势。

#### 年龄分布的两种分析方法

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| **横断面分析**（cross-sectional） | 分析**同一时期**不同年龄组，或**不同年代**各年龄组的发病率、患病率、死亡率变化 | 多用于某时期传染病或**潜伏期较短**的疾病 |
| **出生队列分析**（birth cohort） | 对**同一时期出生**的一组人群随访若干年，观察发病情况 | 把**年龄分布与时间分布结合起来**；评价年龄分布的长期变化趋势、提供病因线索 |

> **为什么需要出生队列分析？** 横断面分析看到的是「不同年龄的人现在的率」，
> 但这些人出生年代不同、经历的环境不同，年龄效应和**世代效应**混在一起。
> 出生队列分析跟踪**同一批人**长大，能把「年龄」这一因素单独剥出来。

#### 性别

差异来自两方面：

- **内在素质**：遗传特征、内分泌代谢、生理解剖特点；
- **暴露特点**：致病因子暴露不同（职业、行为）。

比较时常用**发病率、患病率、死亡率**，也可用**性别比**和**死因构成**表示。

#### 职业

职业中暴露于不同的**物理、化学、生物因素**及**职业性精神紧张**均可导致疾病分布的职业差异。
研究时主要考虑：

- 职业是作业环境、社会经济地位、卫生文化水平、体力劳动强度和精神紧张程度的**综合指标**；
- 疾病的职业分布与**作业环境致病因子暴露**有关；
- 职业相关致病因子的暴露及其作用与**劳动条件、防护设施**有关；
- 不同职业人群疾病种类不同，**防制重点各异**；
- 职业**暴露时间**及**既往职业史**对发病有影响。

#### 其他特征

| 特征 | 要点 |
| --- | --- |
| **种族和民族** | 在遗传、地理环境、宗教、文化、风俗习惯上不同；分析差异时**不能单从一方面找原因**，要综合遗传、风俗、饮食、地理、社会经济与卫生保健 |
| **社会阶层** | 与经济收入、职业、文化程度、生活状况相关，体现各种社会因素的综合 |
| **行为生活方式** | 吸烟、饮酒、吸毒、不良性行为、静坐生活方式等 |
| **婚姻与家庭** | 离婚者全死因死亡率最高，丧偶及独身次之，已婚者最低；家庭成员有共同生活习惯、遗传特性及密切接触，传染病易在家庭内传播，高血压等遗传相关疾病表现为**家庭聚集性** |
| **流动人口** | 人口流动改变暴露机会与免疫状态，影响疾病分布 |

### 二、时间分布

疾病频率随时间动态变化，反映自然环境、社会环境、生物学环境的改变。
通过时间分布可以了解流行规律、提供病因线索、验证可疑致病因素、评价防制效果。

| 类型 | 定义 | 要点 |
| --- | --- | --- |
| **短期波动**（rapid fluctuation） | 持续**几天、几周或几个月**的疾病流行或疫情暴发 | 含义与**暴发**相近；暴发常用于**少量人群**，短期波动常用于**较大数量人群** |
| **季节性**（seasonal variation） | 疾病在**一定季节内**发病率增高的现象 | 两种形式：**严格的季节性**、**季节性升高** |
| **周期性**（cyclic variation） | 疾病频率按一定时间间隔、有规律地起伏波动，**每隔若干年**出现一个流行高峰 | 见下方影响因素 |
| **长期趋势**（secular trend） | 在较长时期（几年或几十年）内，疾病的临床特征、分布状态、流行强度等发生的变化 | 也称长期变异 / 长期变动 |

**影响周期性及间隔时间的常见原因**：

1. 人口密集、交通拥挤和卫生条件差等因素**利于传播**；
2. 传播机制容易实现的疾病，当**易感者积累到足够数量**便可迅速传播；
   流行后新易感者积累的速度（特别是新生儿增加）影响周期间隔——**累积越快，间隔越短**；
3. 病后可形成**稳固免疫**的疾病，流行后发病率迅速下降；人群免疫持续时间越久，**周期间隔越长**；
4. 还取决于**病原体变异**及其变异的速度。

### 三、地区分布

疾病在不同地区的分布特征反映出致病因子在这些地区作用的差别，
根本原因是**危险因素的分布和致病条件不同**。

地区划分有两种方法：**行政区划法**、**自然景观法**。

层次上分：

- **国家间**的分布；
- **同一国家内不同地区**的分布；
- **城乡**分布。

#### 地方性、聚集性、输入性

| 概念 | 定义 | 分类 / 要点 |
| --- | --- | --- |
| **地方性**（endemic） | 由于自然因素或社会因素的影响，某种疾病**经常存在于某一地区**，或只在一定范围人群中发生，而不需自外地输入 | 三类：**统计地方性**、**自然地方性**、**自然疫源性** |
| **地区聚集性**（endemic clustering） | 某地区发病及患病等频率**高于周围地区**的情况 | 提示该地区特定的致病因子对人群健康产生了影响 |
| **输入性疾病** | 本国或本地区不存在、或已消灭的传染病，从国外或其他地区传入 | 又称外来性疾病 |
| **地方性疾病** | 局限于某些特定地区内、相对稳定并经常发生的疾病 | 如地方性氟中毒、地方性砷中毒、碘缺乏病 |

**判断一种疾病是否属于地方性疾病的五条依据**：

1. 该地区居民**发病率高**；
2. 其他地区居住人群发病率低，甚至不发病；
3. **迁入**该地区一段时间后，其发病率与当地居民一致；
4. **迁出**该地区后，发病率下降、症状减轻或自愈；
5. 当地的**易感动物**也可发生同样的疾病。

> 第 3、4 条最关键：它们相当于一次天然的「**移民研究**」——
> 如果是环境造成的，迁入者会逐渐得病、迁出者会好转；如果是遗传造成的，就不会随迁移改变。

# 第二部分　描述性研究与现况研究

## 描述性研究的概念与特点

> **描述性研究**（描述性流行病学）是流行病学研究中最基本、最常用的一类方法。
> 它利用常规监测记录或通过专门调查获得数据，按不同地区、不同时间及不同人群特征分组，
> 描述人群中疾病或健康状态以及有关特征和暴露因素的分布状况，
> 在此基础上进行比较分析，获得三间分布特征，进而获得病因线索、**提出病因假设**。

**五个特点**：

1. 以**观察**为主要研究手段，**不对研究对象采取任何干预措施**；
2. 暴露因素的分配**不是随机的**；
3. 研究开始时**一般不设立对照组**；
4. 暴露与结局的**时序关系无法确定**；
5. 为后续的分析性或实验研究**提供线索**。

**种类**：个案研究、病例报告、病例系列分析、现况研究、历史资料分析、生态学研究。

## 现况研究

### 概念

> 又称**横断面研究**（cross-sectional study），是在特定时间内、特定人群中，
> 收集与疾病或健康状态有关的变量，以描述疾病或健康状况的**分布**及其**有关因素**。

又称**患病率研究**（prevalence study）。按时间分：**时点患病率调查**、**期间患病率调查**。

> 现况研究的关键词是「**同一时点**」：暴露和疾病是**同时**测量的，
> 所以它只能说明「有关联」，**不能判断谁先谁后**，也就**不能确定因果**。

### 两种类型

| 类型 | 做法 |
| --- | --- |
| **普查**（census） | 在特定时点或时期内，对特定范围内的**全部人群（总体）**进行调查 |
| **抽样调查**（sampling survey） | **随机抽样**，调查一个**代表性样本**，以样本统计量估计总体参数所在范围 |

#### 普查

**四个目的**：

1. 早期发现、诊断和治疗疾病；
2. 了解慢性病的患病及急性传染病的疫情分布；
3. 了解当地居民的健康水平；
4. 了解人体各类生理生化指标的**参考值范围**。

**优缺点**：

| 优点 | 缺点 |
| --- | --- |
| ① 不存在**抽样误差** | ① 工作量大，**质量问题难以控制** |
| ② 确定调查对象比较简单 | ② 不适用于患病率低且无简便易行诊断方法的疾病 |
| ③ 能发现目标人群的**全部病例**，较全面描述分布 | ③ **只能获得患病率资料**（得不到发病率） |
| ④ 可同时调查多种疾病或健康状况 | ④ 耗费人力、物力较大，成本高 |

> **普查没有抽样误差，但依然可能有偏倚**（漏查、重查、测量不准），而且这类非抽样误差
> 往往比抽样误差更难控制。

#### 抽样调查

在特定时点、特定范围内的某人群总体中，按一定方法**随机**抽取有代表性的样本，
从样本信息推断总体情况。

**五种概率抽样方法**：

| 方法 | 做法 |
| --- | --- |
| **单纯随机抽样**（simple random sampling） | 每个个体有同等机会被抽到 |
| **系统抽样**（systematic sampling） | 按一定间隔机械抽取 |
| **分层抽样**（stratified sampling） | 先按某特征分层，再在各层内随机抽样 |
| **整群抽样**（cluster sampling） | 按群（如班级、社区）整体抽取 |
| **多阶段抽样**（multi-stage sampling） | 上述方法的组合，分阶段抽 |

**四种非随机抽样**：偶遇抽样、判断抽样、等额抽样、滚雪球抽样。

> 非随机抽样的样本**不能应用推断统计方法作分析**。
> 它只在严格概率抽样几乎无法进行、仅作初步探索、调查对象不确定、
> 或总体内离散程度不大且调查员经验丰富时才考虑。

> **抽样误差大小的顺序**（常考）：
> **分层 < 系统 < 单纯随机 < 整群**。
> 整群抽样误差最大，所以需要**更大的样本量**；多阶段抽样则是它们的组合。

### 样本含量的估计

**两个决定因素**：

- **预期现患率 $p$** —— 现患率越低，需要的样本量越大；
- **容许误差 $d$** —— $d$ 越大，所需样本量越小。

**现患率调查的样本量公式**：

$$n = \frac{z_{1-\alpha/2}^2 \cdot p \cdot q}{d^2}, \qquad q = 1-p$$

流行病学现况研究中常用的抽样条件是 $d = 0.1p$、$\alpha = 0.05$、$z_{1-\alpha/2} \approx 1.96 \approx 2$，
于是公式可简化：

$$n \approx \frac{4pq}{d^2}$$

**计量资料**的样本量另有一套公式（用总体标准差的估计值 $s$ 与容许误差 $d$）。

### R 代码：估算现况研究样本量

假设预期现患率 $p = 0.2$，容许误差 $d = 0.1p = 0.02$，$\alpha = 0.05$：

```r
p <- 0.2          # 预期现患率
d <- 0.1 * p      # 容许误差，取 0.1p
z <- 1.96         # alpha = 0.05 对应的双侧分位数
q <- 1 - p

n <- z^2 * p * q / d^2
ceiling(n)        # 向上取整，得到至少需要的调查人数

# 用简化公式核对（d = 0.1p 时 n ≈ 4pq/d^2）
ceiling(4 * p * q / d^2)
```

两个结果接近。注意 $d$ 一旦定得比 $0.1p$ 更严（比如 $0.05p$），样本量会**成倍增长**——
因为 $n$ 与 $d^2$ 成反比。

### 资料收集

| 环节 | 内容 |
| --- | --- |
| **确定拟收集资料的内容** | 个人的基本情况、职业情况、生活习惯及保健情况、妇女生育情况、环境资料、人口学资料 |
| **调查员培训** | 调查前按标准方法**统一培训**，掌握标准的调查方法，保证收集方法和标准的一致性 |
| **资料收集的途径** | ① 通过调查表询问研究对象；② 通过实验室测定或检查；③ 利用常规资料 |

### 资料分析与结果解释

1. **描述三间分布**：人口学特征、分布特征；
2. **关联分析**；
3. **解释结果**：样本代表性、应答率等情况；**偏倚**；归纳分布规律并提出病因假设。

## 常见误区

::: warning 七个高频错误
- **拿构成比当率。** 本章第一大坑（见开头）。出现「更容易、更严重、高发」就必须用率。
- **分母里混进「不可能发生」的人。** 算某病发病率时分母带着已患病者；
  算麻疹发病率时带着终身免疫者。**写下任何一个率之前，先默念一遍分母的定义。**
- **拿粗率直接比较不同年龄结构的地区。** 必须分层或标准化，且记住标准化率
  **只用于比较、不代表实际水平**。
- **用医院里的数字代替人群指标。** 住院病死率 ≠ 地区病死率；门诊病例算不出人群发病率。
- **以为普查就一定准。** 普查没有抽样误差，但漏查、重查、测量不准带来的是**偏倚**，更难消除。
- **横断面研究里谈因果。** 现况研究**同时**测量暴露与结局，时序不明，只能提假设。
- **抽样方法选了就忘说误差。** 整群抽样误差最大，却常因为「好操作」被误用。
:::

## 小结

1. **三类基础指标**：率、相对比、构成比；**构成比不能当率**。
2. **发病**：发病率（新病例 / 暴露人口）、罹患率（短时间）、续发率（易感接触者）。
3. **患病**：患病率（新旧病例 / 人口）；**患病率 = 发病率 × 病程**（稳定状态下）。
4. **死亡与生存**：死亡率（分母是人口）、病死率（分母是病人）、婴儿死亡率、生存率。
5. **流行强度**：散发、暴发、流行、大流行，判断「流行」的关键是**显著超过历年水平**。
6. **三间分布**：人群（年龄最重要）、时间（短期波动 / 季节性 / 周期性 / 长期趋势）、
   地区（地方性、聚集性、输入性）。
7. **描述性研究**只观察、不干预、不设对照、时序不明，作用是**提出假设**。
8. **现况研究**（横断面）测的是**同一时点**的患病情况；
   普查无抽样误差但有偏倚；抽样调查要注意**抽样误差排序：分层 < 系统 < 单纯随机 < 整群**。
