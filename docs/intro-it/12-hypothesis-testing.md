# 参数假设检验

## 实验目的

- 掌握正态分布参数检验的检验 P 值与临界值的计算方法。
- 掌握非正态分布参数检验的 P 值与临界值的计算方法。
- 掌握参数检验的 R 函数。

::: tip P 值和「接受域」是同一件事的两种说法
假设检验有两套等价的判断方式，本讲两种都要写：

| 思路 | 怎么判断 | 需要什么 |
| --- | --- | --- |
| **P 值法** | $p < \alpha$ 就拒绝原假设 | 算出统计量 → 查分布求尾概率 |
| **接受域法** | 统计量**落在接受域内**就不拒绝 | 算出分位数 → 划出一段区间 |

正因为是一回事，所以每个 `switch` 里都要写两遍——一遍给 `p.value`、一遍给 `interval`。
:::

## 实验题 1：方差未知时正态总体的均值检验

打开脚本文件 **test1301.R**，完成下面任务。

1. 方差未知时均值检验统计量为

   $$T = \frac{\bar{X}-\mu_0}{S/\sqrt{n}} \sim t(n-1)$$

   其中 $n$ 为样本容量。

2. 参数假设检验的检验 P 值的计算方法如下：

   $$p = \begin{cases}
   2 \times \min(p_0,\ 1-p_0) & \text{双侧检验}\\[4pt]
   1 - p_0 & \text{右侧检验}\\[4pt]
   p_0 & \text{左侧检验}
   \end{cases}$$

   其中 $p_0 = P(T \le t_0)$ 的概率，$t_0$ 是统计量的值。

3. 参数假设检验的接受域计算方法如下：
   - 根据统计量 $T$ 的分布和 $\alpha$ 确定分位数 $t_{\alpha/2}$、$t_{1-\alpha/2}$、$t_{\alpha}$、$t_{1-\alpha}$；
   - 返回接受域：双侧检验的接受域为 $[t_{\alpha/2},\ t_{1-\alpha/2}]$；右侧检验为 $(-\infty,\ t_{1-\alpha}]$；左侧检验为 $[t_{\alpha},\ +\infty)$。

4. 请完成自定义函数 `fun1301`，其中参数 `mu` 表示 $\mu_0$，参数 `alt='two.sided'` 表示双侧检验，`alt='greater'` 表示右侧检验，`alt='less'` 表示左侧检验；返回值为 list 对象，包含 `statistic`、`interval`、`p.value` 三个对象。

<AnswerBlock title="实验题 1 · 参考答案" :code="code1301" />

::: tip p0 是「左边的面积」，三种检验都从它变出来
`p0 = pt(t0, n-1)` 算的是 $P(T \le t_0)$，也就是**统计量左边的累计概率**。

| 检验 | P 值 | 直观理解 |
| --- | --- | --- |
| 双侧 | $2\times\min(p_0, 1-p_0)$ | 取**离中心较远的那一侧**的面积，再翻倍 |
| 右侧 | $1-p_0$ | 比 $t_0$ **更大**的面积 |
| 左侧 | $p_0$ | 比 $t_0$ **更小**的面积 |

为什么要写 `min(p0, 1-p0)`？因为 $t_0$ 可能落在右边也可能落在左边，
但「离中心更远」的那一侧永远是概率较小的那一边，取 `min` 就不用分情况讨论了。

**`list()` 返回值**：题目要求一次返回三个东西，R 里就用 `list()` 打包，
调用后可以用 `$` 取：`fun1301(x, 0)$p.value`。

> 提示：左侧检验的参数名用 **`'less'`**（R 的通用约定，`t.test()` 里也是这么写的）。
> `switch` 只做**精确匹配**，名字写错不会报错，而是**悄悄返回 `NULL`**——这是本讲最容易踩的坑。
:::

## 实验题 2：方差已知时两正态总体的均值差检验

打开脚本文件 **test1302.R**，完成下面任务。

1. 方差已知时均值差检验统计量为

   $$Z = \frac{\bar{X}-\bar{Y}}{\sqrt{\sigma_1^2/m+\sigma_2^2/n}} \sim N(0,1)$$

   其中 $m$、$n$ 分别为两总体 $X$、$Y$ 的样本容量，$\sigma_1^2$、$\sigma_2^2$ 分别为两总体 $X$、$Y$ 的方差。

2. 参数假设检验的检验 P 值计算方法如下：

   $$p = \begin{cases}
   2 \times \min(p_0,\ 1-p_0) & \text{双侧检验}\\[4pt]
   1 - p_0 & \text{右侧检验}\\[4pt]
   p_0 & \text{左侧检验}
   \end{cases}$$

   其中 $p_0 = P(Z \le z_0)$ 的概率，$z_0$ 是统计量的值。

3. 请完成自定义函数 `fun1302`，其中参数 `sigma1` 和 `sigma2` 分别表示 $\sigma_1^2$、$\sigma_2^2$，`alt='two.sided'` 表示双侧检验，`alt='greater'` 表示右侧检验，`alt='less'` 表示左侧检验；返回检验 P 值。

<AnswerBlock title="实验题 2 · 参考答案" :code="code1302" />

::: tip 把实验题 1 的结构整个搬过来
对比两道题的代码，会发现**只有三处不同**：

| | 实验题 1 | 实验题 2 |
| --- | --- | --- |
| 统计量 | `(mean(x)-mu)/sd(x)*sqrt(n)` | `(mean(x)-mean(y))/sqrt(σ₁²/m+σ₂²/n)` |
| 分布函数 | `pt(t0, n-1)` | `pnorm(z0)` |
| 接受域 | `qt(...)` 求 t 分位数 | 本题只要求返回 P 值 |

P 值那一段**一模一样**——因为 $2\times\min(p_0,1-p_0)$ 这套逻辑跟具体是 t 分布
还是正态分布无关，只要是**关于 0 对称**的分布就成立。

**`pnorm` / `pt` / `pchisq` 是「分布函数」**：给一个数值，返回累计概率；
而 `qnorm` / `qt` / `qchisq` 是「分位数函数」（第 11 讲学的）：给一个概率，返回数值。
`p` 和 `q` 正好是一对逆运算。
:::

## 实验题 3：均值检验的 R 函数

创建脚本文件 **test1303.R**，选择适当的检验函数完成下面的检验任务。

为了比较两种方法对乳酸饮料中脂肪含量测定结果是否不同，随机抽取 10 份乳酸饮料制品，分别用脂肪酸水解法和哥特里-罗紫法测定，测定结果如下：

- 哥特里-罗紫法：0.840, 0.591, 0.674, 0.632, 0.687, 0.978, 0.750, 0.730, 1.200, 0.870
- 水解法：0.580, 0.509, 0.500, 0.316, 0.337, 0.517, 0.454, 0.512, 0.997, 0.506

问两种方法结果是否不同？其中 $\alpha=0.05$。

<AnswerBlock title="实验题 3 · 参考答案" :code="code1303"
  :output="out1303" />

::: tip 为什么用 paired = TRUE —— 判断配对还是独立
这是做假设检验时**第一步就要想清楚**的问题：

| 情形 | 该用什么 | 判断依据 |
| --- | --- | --- |
| 同一批样品**用两种方法各测一次** | **配对** t 检验 `paired = TRUE` | 每个样品都有「一对」数据 |
| 两组**互不相干**的对象分别测量 | 独立样本 t 检验（默认）| 两组数量可以不同 |

本题是「10 份饮料，每份都分别用两种方法测」——
第 i 份的两种测值天然成对，所以必须用配对检验。

配对检验看的是**每对之差的均值是否显著不为 0**，
这样能消掉「样品本身脂肪含量就有高有低」这个干扰，检验更灵敏。

结论：$p < 0.05$，**两种方法的测定结果有显著差异**。
:::

## 实验题 4：方差齐性检验与均值检验的 R 函数

创建脚本文件 **test1304.R**，完成下面的检验任务。

两组雌鼠，分别饲以两种不同饲料，8 周后记录体重增加量（g）。问两组雌鼠增重的均数差别是否显著？**先做方差齐性检验**（即 F 检验），然后根据方差齐性检验结果选择 t 检验方法，其中 $\alpha=0.05$。

- 组 A：134, 146, 104, 119, 124, 161, 107, 83, 113, 129, 97, 123
- 组 B：70, 118, 101, 85, 107, 132, 94

<AnswerBlock title="实验题 4 · 参考答案" :code="code1304" />

::: tip 两阶段检验的标准流程
```
第 1 步：var.test(x, y)  →  看方差是否齐性
第 2 步：根据上一步结果，二选一
         方差齐   →  t.test(x, y, var.equal = TRUE)   等方差 t 检验
         方差不齐 →  t.test(x, y)                     Welch t 检验（默认）
```

**方向要记清楚**：
`var.test` 的 P 值 **小于** 0.05 表示「方差**不**齐」，这时才需要 Welch 校正。
答案里写的是 `if (ret < 0.05)` 走 `t.test(x,y)`（Welch），否则走 `var.equal = TRUE`——别搞反了。

`(ret = var.test(x,y)$p.value)` 这种**加括号的赋值**会顺手把值打印出来，
是个很方便的小技巧（第 1 讲就出现过类似写法）。

结论：$p > 0.05$，**接受原假设，两种饲料对雌鼠增重无显著差异**。
:::

::: tip 比例检验为什么用 binom.test
这里的数据是「100 次试验中有 45 次成功」，属于**二项分布**的样本，
不是连续型数据，所以不能用 t 检验。


| `alternative` | 拒绝域在哪一侧 | 什么时候用 |
| --- | --- | --- |
| `'two.sided'` | 两侧 | 问「是否**不同**」|
| `'greater'` | 右侧 | 问「是否**高于**」|
| `'less'` | 左侧 | 问「是否**低于**」|

结论：$p < 0.05$，**拒绝原假设**，可认为今年的通过率明显低于 60%。
:::

## 实验题 6：指数分布的参数检验

打开脚本文件 **test1306.R**，完成下面的检验任务。

1. 指数分布参数检验的统计量

   $$Z = 2n\lambda_0\bar{X} \sim \chi^2(2n)$$

   其中 $\lambda_0$ 为检验的目标值，$n$ 为样本容量。

2. 完成自定义函数 `fun1306`，返回检验 P 值。其中参数 `lambda` 表示 $\lambda_0$，参数 `alt='two.sided'` 表示双侧检验，`alt='greater'` 表示右侧检验，`alt='less'` 表示左侧检验。

<AnswerBlock title="实验题 6 · 参考答案" :code="code1306" />

::: warning 卡方分布不对称，双侧 P 值不能翻倍
第 11 讲提过 F 分布不对称，这里 $\chi^2$ 也一样。

对**对称**分布（正态、t），双侧 P 值 = $2\times\min(p_0,1-p_0)$，因为两边面积相等。
但**卡方分布是偏斜的**，左右尾巴不一样厚，直接翻倍会算错。

所以答案里用的是：

```r
two.sided = 2*min(p0, 1-p0)
```

这仍然是个**近似**写法（注释里也给了等价的 `ifelse` 版本）。
严格的双侧 P 值应该找另一侧「同样极端」的点，
但课程要求掌握的就是这个 $2\times\min$ 的套路。

**统计量的自由度是 $2n$**，和实验题 1 的 $n-1$ 不同——
根源在第 11 讲讲过：$2\lambda X \sim \chi^2(2)$，n 个相加就成了 $\chi^2(2n)$。
:::

## 本讲小结

### 参数检验的四类分布

| 场景 | 统计量 | 分布 |
| --- | --- | --- |
| 单正态均值，$\sigma$ 未知 | $\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}$ | `pt(..., n-1)` / `qt(..., n-1)` |
| 两正态均值差，$\sigma$ 已知 | $\dfrac{\bar{X}-\bar{Y}}{\sqrt{\sigma_1^2/m+\sigma_2^2/n}}$ | `pnorm` / `qnorm` |
| 指数参数 | $2n\lambda_0\bar{X}$ | `pchisq(..., 2n)` / `qchisq(..., 2n)` |

### 现成的检验函数

| 函数 | 用途 | 关键参数 |
| --- | --- | --- |
| `t.test(x, y)` | 均值检验 | `paired`（配对）、`var.equal`（方差齐）|
| `var.test(x, y)` | 方差齐性检验 | — |
| `binom.test(k, n, p)` | 比例检验 | `p`（原假设比例）、`alternative` |
| `chisq.test()` | 列联表 / 拟合优度 | 见第 13 讲 |

### `alternative` 三个方向的记忆

| 取值 | 含义 | 对应 P 值 |
| --- | --- | --- |
| `'two.sided'` | 不同 | $2\times\min(p_0,\ 1-p_0)$ |
| `'greater'` | 高于 | $1-p_0$ |
| `'less'` | 低于 | $p_0$ |
