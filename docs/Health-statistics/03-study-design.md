# 第 3 章　实验设计与调查设计

> 前两章算的都是**已经拿到手**的数字；这一章管的是数据还没产生的时候——人怎么选、组怎么分、施加什么、量什么，才能让最后算出来的差别真的能归因于你要研究的那个因素。

## 这一章要解决什么

医学研究拿到的数据，来源只有两大类：**研究者主动施加了干预**（给不给某种药、做不做某种手术），和**研究者只是客观观察**（抽烟的人和不抽烟的人，谁更容易得肺癌）。前者叫实验研究，后者叫调查研究。两类研究的统计方法有重叠，但**设计上的把关点完全不同**：实验研究能随机分组，调查研究不能。

于是有两类典型问题：

- 某药企要评价一种新药的疗效，找了 100 位患者。怎么分两组？按入院先后分？按病情轻重分？——都不行，因为两组一旦在年龄、病程、病情上不一样，最后血糖的差别就说不清是药造成的还是人造成的。
- 要摸清一个市成年人的高血压患病率，人口几百万，只能抽一部分人查。抽多少人？去哪个区、哪些小区、敲门进哪几户？抽出来的 5000 人凭什么能代表全市？

这两类问题都**不能靠事后分析补救**。统计学家 Fisher 有句话说得很难听但很准：做完实验后才去找统计学家，无异于请他做尸体解剖——他能做的只是告诉你这个实验死于什么原因。**所以这一章的位置很特殊：它是整门课里唯一一个「必须在动手之前就做对」的环节。**

## 核心概念

### 医学研究的三大类

| 类型 | 研究者做什么 | 例子 |
| --- | --- | --- |
| **调查研究（survey research）** | 不施加任何干预，客观观察记录现状及其相关特征 | 吸烟与肺癌关系的队列研究 |
| **实验研究（experimental study）** | 人为施加处理因素，控制混杂因素，观察总结其效应 | 新药随机对照试验 |
| **文献研究** | 汇总已有研究的结果 | Meta 分析 |

**实验研究（experimental study）**的定义：研究者根据研究目的人为地对受试对象（人或动物）施加**处理因素**（干预措施），控制混杂因素，观察、总结处理因素的效应的一种研究方法。

它有两个立身之本，也是它比观察性研究「更硬」的原因：

1. **研究者能人为设置处理因素。** 因素可以是物理的（针刺、射线、理疗）、化学的（药物、毒物）、生物的（细菌、病毒），也可以是社会因素。
2. **受试对象接受哪种处理是由随机方法决定的**，不由研究者主观指定，也不由患者自己挑。这一条把大量未知的、没法测量的非处理因素也一并摊平了。

**实验设计（experimental design）**就是对整个实验研究所做的周密计划，覆盖资料收集、整理、分析全过程的设想与安排。做设计时要写清楚：考察哪些实验因素、用什么方案控制重要的非实验因素、选谁做受试对象、用什么指标体现效应、数据怎么收集、将来用什么统计方法分析。

实验研究按研究对象分三类：

- **动物实验（animal experiment）**：条件可以严格控制（温度、湿度、有毒环境都能上），是探索机制的首选；
- **临床试验（clinical trial）**：以病人为对象，不可能像动物那样任意控制，且人有心理和社会活动，必须同时考虑误差控制和伦理要求；
- **社区干预试验（community intervention trial）**：在社区一般人群中进行，持续时间长。因为很难真正做到个体随机分配，常被称为**半试验性研究（quasi-experiment）**。

按研究因素和水平数还可以分成单因素设计、两因素设计、三因素设计（拉丁方、裂区）、多因素多水平设计（析因、正交、均匀）等。

### 三要素之一：处理因素

**处理因素（study factor，treatment）**是研究者根据研究目的施加于受试对象、并引起直接或间接效应的因素。它既可以是主动施加的（药物种类、剂量、浓度、作用时间），也可以是客观存在的（如观察培养基在空气中的污染程度与季节的关系）；有时受试者本身的特征（性别、年龄、职业、文化程度、民族、婚姻状况）也会被当作处理因素来研究。

- **非处理因素**：除处理因素之外，对结果有影响或干扰，但研究者并不打算考察其作用大小的因素。
- **水平（level）**：同一处理因素在数量上或强度上的不同程度。不同药物种类、不同剂量就是不同水平。因素和水平组合起来有四类：单因素单水平、单因素多水平、多因素单水平、多因素多水平。

**混杂因素（confounder）**是一个必须单独记住的概念：它**是影响实验效应的非处理因素，并且与处理因素同时存在**。麻烦在于，如果它在实验组和对照组中分布不均匀，处理因素与实验效应之间的联系就被歪曲了。

举个经典的坑：比较两种疗法治疗某病的有效率，联合用药组 320 人有效率 89.4%，一般疗法组 132 人有效率 90.9%——看着联合用药更差。但拆开病情程度看，联合用药组在轻、中、重各层里的有效率**都更高**，只是入组时重型病人多、对照组轻型病人多，把总率拉反了。这里的**病情程度就是混杂因素**。控制混杂因素有三条路：

| 方法 | 做法 |
| --- | --- |
| **排除法** | 只选某一种病情程度的患者入组，把混杂因素挡在门外 |
| **平衡法** | 先按病情程度分层，每层内再随机分到各组（分层随机化） |
| **标准化法** | 照算不误，但分析时先算标准化率再比较 |

设置处理因素还要守住三条：**抓住实验中的主要因素**（因素太多，分组数和例数都会膨胀，实验难以控制；因素太少又挖不深）、**分清处理因素和非处理因素**（把重要的非处理因素找出来并设法消除其干扰）、**处理因素标准化**（药物要固定厂家、批号、保存方法；手术要规格化操作程序，主刀医师的熟练程度也要尽量接近）。

### 三要素之二：受试对象

**受试对象（study subjects）**是处理因素作用的客体。它可以是人、动物、植物，也可以是人体的离体标本、血清、细胞、某个器官。

受试对象的选择是实验成败的关键，最要紧的是**同质性**——研究对象的种属、生物学特性及其他条件要保持均衡。选择时有六条基本要求：

| 要求 | 含义 |
| --- | --- |
| **敏感性** | 受试对象对被施加的处理因素反应灵敏，容易显示效应 |
| **特异性** | 反应专一，能排除非处理因素的干扰 |
| **稳定性** | 反应有较大的稳定性，减少误差 |
| **同质性** | 种属、生物学特性及其他条件保持均衡 |
| **依从性** | 接受处理因素的合作程度（尤其临床试验） |
| **经济性** | 容易找到，费用低 |

落实到操作上，是把「选谁」写成三层书面标准，缺一不可：

1. **诊断标准（diagnostic criteria）**：尽量采用公认的国际疾病分类标准或全国性学术会议规定的标准。这些标准有权威性，且与同类研究结果可比。若某种疾病确无公认标准，研究者可自行拟定，但要**尽量采用客观指标**——病理学、生物化学、影像学、免疫学、内窥镜检查等。
2. **纳入标准（inclusion criteria）**：在诊断标准基础上，进一步规定符合入组条件的具体条件（年龄、病程、病型、知情同意等）。
3. **排除标准（exclusion criteria）**：符合诊断标准的人也未必适合做受试对象。年龄过小、体质过弱、合并其他并发症、患有另一种可能影响本实验效果的疾病、对药物有不良反应、妊娠哺乳期等，都要排除。

两份标准要用条文明确规定成书面形式，让所有参与研究的医务人员都知道；写论文时也要交代清楚，别人才好引用和对比。

**受试对象的数量**就是样本含量（样本例数）。因素一多，水平组合会让小组数变多，**每个小组里的例数不能太小**。样本含量怎么估，见本节后面的介绍，完整方法**详见第 17 章**。

### 三要素之三：实验效应

**实验效应（effect）**是处理因素作用于受试对象后出现的反应（response）和结局（outcome）。它靠**指标的选择**和**指标的观察**来体现。指标选错了，整个实验就是「问非所答」。

**选指标的五条标准：**

- **客观性**：客观指标是测量或检验的结果，一般属计量资料，比主观指标（一般属分类资料）可靠得多。观察贫血疗效应当选红细胞数、血红蛋白含量，而不是头昏、乏力这类主观感受。
- **灵敏度（sensitivity）**：处理因素发生微小改变，指标也能跟着变。灵敏度高的指标才能把效应充分表现出来。
- **精确性**：包含两个不同的东西——
  - **准确度（accuracy）**：观察值与**真值**的接近程度，反映**系统误差**；
  - **精密度（precision）**：重复测量时观察值与**其平均值**的接近程度，反映**随机误差**。

  两者要同时具备，但首要是准。
- **特异性**：能专一地反映要研究的东西。诊断糖尿病时，测血糖的特异性就比测尿糖高。
- **针对性**：指标要对着研究目的去选。评价一种治疗骨折的药物，选「骨密度」「骨钙素」就不对——这些指标反映的是骨质疏松状况；反映骨折愈合效果，该选骨形态、X 线片、病理检查结果和功能恢复情况。

**主观指标也不是不能用，而是要数量化。** 心理健康、满意度这类研究只有主观指标，那就把答案设置成 5～7 个等级：不要「满意／不满意」两选项（只能得到二分类计数资料），而要「1.非常不满意 2.不满意 3.一般 4.满意 5.非常满意」五级，这样得到的是等级资料，还可以按 Likert 五点标度法赋值成 1～5 分当计量数据处理。

**指标的观察要提防偏倚。** 在临床试验中，研究者或医务人员知道分组和治疗情况，可能因主观成见或不自觉的偏性影响结果；受试对象知道自己的分组，也会产生各种心理影响，导致一些非特异性反应。消除办法是**盲法（blind method）**——在实验结束前，不让有关人员或受试者知道谁分在哪组、接受何种处理。

| 盲法 | 谁不知道 |
| --- | --- |
| **单盲（single blindness）** | 只有受试对象不知道 |
| **双盲（double blindness）** | 受试对象和实验执行者都不知道 |
| **三盲（triple blind method）** | 受试对象、实验执行者、统计分析人员都不知道 |

当主要变量是主观评定的（疼痛、认知功能障碍评分），且评定量表的内容极易由主观因素造成偏倚时，**必须**用双盲。目前双盲法和三盲法是临床试验中最常用的做法。

**指标的标准化**指把指标的采集方法、部位、时间、保存、运输、测定时间、测定方法、测定条件等全部固定下来。不标准化，这些因素要么干扰研究进程，要么直接变成混杂因素，使测定结果不稳定，导致错误结论。

### 四原则之一：对照

**设立对照（control）**是指除了实验组之外，再设一个或多个组进行**同步**试验，以比较实验组的效应。道理很朴素：**有对照才有比较，有比较才有鉴别**。没有对照，说明不了任何处理因素的作用。

对照的意义在于让处理因素和非处理因素的差异有一个科学的对比基准。关键在于，实验组和对照组的受试对象**除了处理因素不同以外，其他影响结果的各种因素都应尽可能相同或相近**。

常用的对照形式有六种，考试里最爱让你辨析：

| 形式 | 对照组接受什么 | 典型场景 |
| --- | --- | --- |
| **空白对照（blank control）** | 什么都不施加 | 动物实验、实验室方法研究，用于评价测量方法的准确度、检测本底值 |
| **安慰剂对照（placebo control）** | 外形、颜色、味觉与试验药一样但无药理作用的「假药」 | 临床试验，用来消除对照组病人与实验组病人心理作用的差异 |
| **标准对照（standard control）** | 公认的有效药物、现有标准方法或常规方法 | 新检验方法能否代替传统方法；新药试验用已知有效药做对照 |
| **实验对照（experimental control）** | 不施加处理因素，但施加与处理因素有关的实验因素 | 强化铁酱油研究里，对照组吃普通酱油（酱油量两组相同） |
| **自身对照（self control）** | 对照与实验在同一受试对象的不同部位或不同阶段进行 | 服药前后的血压比较；左右耳对照 |
| **相互对照** | 不专门设对照组，几个实验组互为对照 | 三种止咳药互为对照，比较疗效强弱 |

几点容易忽略的细节：

- 空白对照虽简单易行，但**在临床试验中涉及伦理问题**，且容易造成试验组与对照组心理上的差异，因此较少使用。它只在处理因素很强、非处理因素很弱时才合适。
- 标准对照**不提倡用现有标准值或参考值代替对照组**：实验组所处的时间、地点和环境，可能与标准值产生的背景不同。
- 自身对照简单易行，但在「不同阶段接受不同处理」的研究中**难以排除时间因素的作用**。服药前后体重下降，可能是药物的作用，也可能是这段时间饮食、运动、心理状态变了。因此自身对照通常还需要设一个**平行的外对照**。

设立对照时的三类常见错误：

1. **无对照**：只有试验组，无法说明处理因素的作用。
2. **对照不足**：有对照，但缺了某些必要的组或因素，可比性差。典型例子是研究「激素 + 某中药」防治骨质疏松，只设了正常对照组、激素组、「中药合用激素组」三组，**漏掉了单用中药组**。这样当两个因素存在交互作用时，第三组的效应里混着激素、中药和两者共同作用，无法拆开。
3. **对照过剩**：该研究的新旧两种药都已反复验证有效，此时再设安慰剂对照组就是多余的，还违背伦理学原则——直接比较新旧两药即可。

### 四原则之二：随机

**随机化（randomization）** 含两件事，缺一不可：

- **随机抽样**：选取样本时，确保总体中任何一个个体都有同等机会被抽进样本 → 保证样本的**代表性**；
- **随机分组**：分配样本时，确保样本中任何一个个体都有同等机会被分入实验组或对照组 → 保证各组的**均衡性**。

严格意义上，还有第三件事：**实验顺序的随机**——每个受试个体接受处理的先后机会均等，以平衡实验顺序的影响。

**随机化到底在防什么？** 是在大量未知或不可控制的非处理因素存在的情况下，用统计学手段保证组间均衡。它避免客观因素和主观因素引起的偏性，减少系统误差，并把各种效应归入总的实验随机误差之中。此外，随机化也是对资料做统计推断的**前提**——只有满足随机化原则的资料，才能真正应用各种统计分析方法。

下面这段设计是反面教材：把 40 位膝骨关节炎患者**按就诊顺序**分成两组，先来的 20 名进对照组，后来的 20 名进实验组，结果实验组疗效优于对照组。问题在于：患者来就诊，在患病严重程度、患病时间上不一定均衡，可能带有某种程度的**聚集性**——某段时间来的多数是重病患者，另一段时间多数是轻病患者。最后两组在某些重要非处理因素上相差悬殊，可比性差，结论就不可靠。

常用的随机分配方法：

1. **简单随机化（simple randomization）**：直接对受试对象做随机分组，分组后各组例数不一定相同。可用抛硬币、抽签、摸球、查随机数字表，或直接用软件产生伪随机数。
2. **区组随机化（block randomization）**：按受试者进入研究的先后顺序，分成若干**内含相等例数**的区组，再在区组内随机分配。好处是任意时刻看，各组例数都基本相等，中途分析时不会一边倒。
3. **分层随机化（stratified randomization）**：简单随机化虽然提高了各组均衡性，但并不能**保证**一定达到良好均衡。当存在对结果影响大的混杂因素时，先按该因素分层，再在每一层内做完全随机化。

此外，「先来的进对照组、后来的进实验组」还有一个隐患：随着试验推进，医护人员的操作熟练度、对方案的理解、甚至季节环境都在变，**这些「时间效应」会和分组效应完全混在一起，永远分不开**。真随机化（哪怕只是抛硬币）恰恰能把这些未知因素摊平到两组去。

**要点**：随机化不是为了「看起来公平」，而是为了让**所有你想到的和没想到的非处理因素**都趋向均衡。

### 四原则之三：重复

**重复（replication）** 指研究样本要有一定的数量，即在保证研究结果具有一定可靠性的条件下，确定**最少**的样本例数。

为什么必须要？因为医学研究观测的指标普遍带有**变异性**——同是正常人，血压有高有低。要反映一个随机变量的变化规律，就必须在相同实验条件下做多次独立重复。重复原则的作用恰恰在于**让随机变量的统计规律性充分显露出来**。

样本例数太少，不能反映必然规律，可产生严重的错误结果；太多了，不易控制实验误差，还浪费人力物力财力。

「重复」在统计学里有三层不同含义，别混：

| 说法 | 做法 | 目的 |
| --- | --- | --- |
| **重复实验** | 相同实验条件下做多次**独立**实验（要用不同的个体或样品，不是在同一个体上做多次） | 看结果的重现性 |
| **重复取样** | 同一时间点从同一受试对象或同一样品中取多个标本 | 看各标本间某指标值的分布是否均匀，检测方法是否有重现性 |
| **重复测量** | 受试对象接受处理后，在不同时间点或对称的不同部位上重复观测 | 看指标随时间推移的动态变化 |

但实验设计中所说的「重复原则」，**主要指「相同实验条件下独立重复实验的次数要足够多」**。落实它有两条：严格按研究目的规定研究对象的性质与范围；保证足够的样本含量。

顺带纠正一个常见的误读：10 例胃炎患者治好 8 例，治愈率 80%，而公认有效药的治愈率是 60%，**不能**据此说新药更好。10 例的波动太大，80% 这个结果可能不具有重现性和稳定性，这违反的是重复原则；而且这属于抽样研究，存在抽样误差，必须经假设检验按 $P$ 值下结论。

### 四原则之四：均衡

**均衡原则（balance）**，又叫**齐同对比原则**：实验组和对照组、或各实验组之间，**除了处理因素以外，其他一切条件应尽可能相同或一致**。

「其他一切条件」具体指什么？以临床研究为例：病情构成（轻、中、重的比例）、平均病程及病程分布、平均年龄及年龄分布、性别构成等，任何可能影响疗效评价的方面都应尽可能一致。它们在统计学上被称为**重要的非处理因素**。

均衡原则是四原则里**最容易被人忽视、同时又是最重要的一条**。很多设计方案只要在均衡性上考虑不周，结论就很容易被推翻。看这个反面例子：比较三种疗法对臀部注射硬结的疗效，纳入 117 例，年龄从 18 个月到 68 岁，病程从 1 周到 15 年，硬结从 $1\text{cm}\times1\text{cm}$ 到 $5\text{cm}\times7\text{cm}$，三组直接拿来比较。可硬结的预后与年龄、病程、硬结大小都有很大关系（年龄小、病程短、硬结小，预后相对好）。这里**年龄、病程、硬结大小就是混杂因素**，不控制它们，结论的可靠性不高甚至可能完全错误。

均衡原则贯穿在随机化、重复和对照之中——这三条原则实施好了，本身就是在实施均衡。它还有两个专门的实施方法：

1. **交叉均衡法**：在各试验组中又各设立试验和对照，使两组的非处理因素均衡一致。
2. **分层均衡法**：将非处理因素按不同水平划分为若干单位组（层），然后在每个层内安排处理因素。

### 样本含量与检验效能

这是实验设计里最需要「算」的一环。**样本含量是用多少动物或人做实验的问题。**

太小了，**检验效能偏低，无法得出统计结论**——明明有差别也检不出来，白做；太大了，操作困难，浪费资源，甚至可能引入更多混杂因素。所以要找的是「在保证结果可靠的前提下，最少需要多少例」。

先明确**检验效能（power）**。做假设检验有两类错误：

| | $H_0$ 实际为真 | $H_0$ 实际为假 |
| --- | --- | --- |
| 不拒绝 $H_0$ | 正确（$1-\alpha$） | **II 类错误**（$\beta$） |
| 拒绝 $H_0$ | **I 类错误**（$\alpha$） | 正确（$1-\beta$） |

$$\text{检验效能} = 1 - \beta$$

它的意思是：**当两组实际上真的有差别时，这次实验能把它检出来的概率。** 习惯上要求检验效能不低于 0.80，也就是有 80% 的把握能检出真实存在的差异。

样本含量与各因素的关系，可以用两样本均数比较的公式看得很清楚：

$$n = \frac{2\left(z_{\alpha/2} + z_{\beta}\right)^2 \sigma^2}{\delta^2}$$

其中 $n$ 为每组所需例数，$\sigma$ 为个体观察值的标准差，$\delta$ 为研究者希望检出的两组均数之差（$\mu_1-\mu_2$），$z_{\alpha/2}$ 和 $z_\beta$ 是标准正态分布的分位数。对照地，单样本或配对设计为

$$n = \frac{\left(z_{\alpha/2} + z_{\beta}\right)^2 \sigma^2}{\delta^2}$$

（配对设计中 $\sigma$ 取**差值**的标准差 $\sigma_d$。）

一眼能看出四条结论：

- **$n$ 与 $\sigma^2$ 成正比**：个体差异越大，需要的人越多。这是为什么「严格限定纳入标准、提高同质性」能省样本量。
- **$n$ 与 $\delta^2$ 成反比**：只想检出大的差别，几十例就够；要检出细微差别，例数要成平方倍地涨。这里的 $\delta/\sigma$ 就是**效应量（effect size）**。
- **要求检验效能越高，$n$ 越大**：把 $1-\beta$ 从 0.80 提到 0.90，例数要明显增加。
- **$\alpha$ 定得越小，$n$ 越大**：把 0.05 收紧到 0.01，代价就是更多例数。双侧检验也比单侧需要更多例数。

一个必须记住的反向推论：**当 $P \gt 0.05$ 时，如果检验效能不足，你只能说「没检出差别」，不能说「两组没有差别」。** 很多「某药无效」的结论，其实是例数太少导致的。

样本含量还与设计类型有关：完全随机设计所需例数较多，配对设计和随机区组设计因为扣掉了配对／区组带来的变异，所需例数较少；析因设计的例数还要乘上因素水平的组合数。完整的估计公式、各类设计的具体算法、以及率的比较等场合的样本量计算，**详见第 17 章**（析因设计、生存分析等场合本课程未覆盖，需要另找资料），这里只需建立起「样本量不是拍脑袋定的，而是由 $\alpha$、$\beta$、$\sigma$、$\delta$、设计类型共同决定的」这个概念。

### 常用设计类型（一）：完全随机设计与配对设计

**完全随机设计（completely random design）**

又称**随机对照试验（randomized controlled trial，RCT）**，属于**单因素**研究设计：把受试对象按随机原则分配到实验组和对照组，接受不同处理，同期观察各组效应，最后比较观察指标有无差别。

- 适用条件：只有一个研究因素，不需要或无法对受试对象进行配伍时。
- **优点**：设计和统计分析都简单，出现缺失值时仍能统计分析。
- **缺点**：一次只能研究一个因素，所需样本量比较大；小样本时均衡性可能较差，抽样误差较大。

分组是它最要紧的一步。标准做法是先把动物按某一特性（如体重）依次编号，再查随机数字表抄取随机数，把随机数从小到大排序，规定排在前面的对应编号进第一组、中间的进第二组、最后的进第三组。**这里的关键是「按体重编号」这一步**——它让体重这个非处理因素在分组时被一并随机化，而不是先分完组再看两组体重差多少。

一个常见的失败设计：把 360 名面神经麻痹患者分成三组各 120 人，例数一样，但三组的患者来源（门诊／住院／社区）分布明显不同。**例数相等不等于均衡。** 正确做法是先把患者按来源分成三类，再把每类中的患者随机分配到三种疗法组里去，保证每个治疗组里都有不同来源的病例。

**配对设计（paired design）**

将受试对象按一定条件配成对子，再随机分配每对中的两个受试对象到不同的处理组。

两种情形要区分开：

1. **自身对照设计**：比较同一受试者实验前后的变量值改变，或同一样本接受两种不同测定方法的结果。适合急性、短期的试验，或病情稳定的慢性病中观察短期对症治疗的效果。**实验时间较长的试验通常不适合**——时间长，其他混杂因素掺和进来的可能性大，试验前后就失去可比性了。
2. **异体配对设计**：把条件相同的个体配成一对，再在对子内随机分派。动物实验里最容易实施，通常把种属、品系、性别、体重、窝别、生长天数作为配对的基本条件。

- **优点**：提高组间均衡性，减少实验误差，提高统计效率。
- **缺点**：配对条件太多会造成配对困难。

有个坑值得单独说：有人宣称做了配对设计，按性别、年龄、病程、病情程度配成 70 对，可一看基线表——试验组平均年龄 45.0 岁，对照组 50.0 岁；病情程度「重」的一组 25 例、另一组 30 例。**声称配了对，就得真的在每对内部平衡了这些条件**，否则只是形式上像配对设计，实际上年龄和病情分布仍不均衡，配对的效率也就拿不到。

### 常用设计类型（二）：随机区组、交叉、析因、重复测量

**随机区组设计（randomized block design）**

又称**配伍设计**，是配对设计的扩大——配对设计是它最简单形式（区组大小 $k=2$）。做法是：把几个条件相同的受试对象划成一个**区组（block）**，区组中观察对象的数量等于对比组的组数；再把区组内的受试对象随机分配到各对比组。

- 它是**两因素设计**：**第一因素是处理因素，第二因素是区组条件**。所以它既能分析处理组间的差别，也能分析区组间的差别。
- **优点**：组间均衡性好，抽样误差小，实验效率高。
- **缺点**：如果实验动物偶然死亡造成缺失，结果一般需改用完全随机设计的方法处理。

三条注意事项：

1. 要分清第一因素（处理因素）和第二因素（区组条件）。
2. **配伍的条件不能太多**，否则难以划分区组；特别不能把**处理因素**当作配伍条件，那叫配伍过头。
3. 动物实验里最容易实施，常把品种、窝别、性别、体重、生长天数作为划分区组的条件。

一个真实教训：有研究把 30 只大鼠按窝别、体重分成 10 个区组来做三种药的降压对比，实验做完才发现这批大鼠不是同一品种。品种不同，药物在体内的代谢可能就不同，**这等于区组内部又埋了一个没被控制的系统差异**，结果不可信。

**交叉设计（cross-over design）**

一种**特殊的自身对照设计**：按事先设计好的试验次序（sequence），在不同时期（period）对同一研究对象先后实施几种处理，以比较各处理组的效应差异。医学上应用最多的是**两阶段交叉设计**——把条件相近的对象配对后随机分两组，一组先 A 后 B，另一组先 B 后 A，两种处理交叉进行，中间留一段洗脱期。

- **优点**：节约样本含量；能控制个体差异和时间对处理因素的影响，效率较高；每个受试对象都既接受处理因素又接受对照因素，这在临床试验中更容易被接受。
- **缺点**：每种处理的时间不能太长；受试对象状态发生变化（死亡、治愈）时后一阶段无法实施；一旦某阶段退出，会造成该阶段及以后的数据缺失，增加分析难度。
- **适用范围**：病程较长的慢性病。**不适合感冒、急性气管炎、肺炎这类病程短的疾病**——一个疗程就治愈了，根本没法执行第二阶段的交叉用药。

**析因设计（factorial design）**

一种**多因素的交叉分组设计**：把两个或多个因素的各个水平排列并交叉组合，试验也交叉分组进行。它同时研究**各因素的主效应**和**因素间的交互作用**，目的是寻找最佳组合。最简单常用的是 $2\times2$ 析因——两个因素各两个水平，共 4 种组合：

| | $B_1$ | $B_2$ |
| --- | --- | --- |
| $A_1$ | $A_1B_1$ | $A_1B_2$ |
| $A_2$ | $A_2B_1$ | $A_2B_2$ |

- **优点**：全面、高效，可同时观察多个因素多个水平的效应；能分析多种交互作用，结论丰富；能直观表达结果并寻找最佳组合。
- **缺点**：统计分析较复杂；临床科研中不易获得适合分析交互作用的资料；因素及水平数都不宜过多，否则计算量和样本量都会激增。

析因设计同样**必须随机分组**。有研究者为比较两种麻醉方式与两种麻醉剂量，按手术顺序把 40 例病人每 10 人一组、依次安排四种组合——这是有意安排而非随机分配，麻醉效果的观察必然产生偏性。正确做法是对手术顺序编号后，用随机数把顺序分成 4 组，再分别给予四种组合。

**重复测量设计**

**重复测量资料（repeated measurement data）**是同一受试对象的同一观察指标在**不同时间点上多次测量**（测量次数 $m \ge 3$）所得的资料，常用来分析该指标随时间的变化特点。全部结果记为 $x_{ijk}$，其中 $i$ 为时间点、$j$ 为受试对象、$k$ 为处理因素。

它的总变异分成两部分：**受试对象间（between subjects）**的变异，和**受试对象内（within subjects）**的变异。对象间变异可再分为处理因素的变异和个体间误差；对象内变异可再分为时间因素的变异、处理因素与时间的**交互作用**、以及个体内误差。

五个特点：

1. 从同一受试对象身上对同一指标做 $m$ 次（$m \ge 3$）重复测量；
2. **不同时间点的重复测量值之间存在自相关性**；
3. 测定时间可以等距，也可以不等距；
4. 有时部分受试对象在最后若干时间点出现缺失数据；
5. 观察指标可以是定量或定性的。

**和随机区组设计的区别（这是本类设计最容易被问到的对比）：**

| | 随机区组设计 | 重复测量设计 |
| --- | --- | --- |
| 区组内的「处理」 | 在区组内的受试者之间**随机分配** | 「处理」在受试对象间随机分配，但**区组内的各时间点是固定的，不能随机分配** |
| 区组内受试者 | 彼此**独立**，每人只接受一种处理 | **彼此不独立**（同一个体测多次） |
| 分析前提 | 常规方差分析 | 若用随机区组方差分析比较处理组间差异，需要满足**球对称**假设 |

**最常见的错误**是用 t 检验逐个时间点比较两组。这是错的：t 检验适用于随机设计的两组计量资料，且要求资料具有**独立性**，而重复测量资料各时点之间恰恰不独立。这样分析既孤立地看待各时点、没有利用观察对象在不同时点间的内在联系，降低了检验效能，又完全没有回答「时间对结果有没有影响」这个重复测量设计本要回答的问题。正确方法是**重复测量资料的方差分析**。

### 调查研究：普查与抽样调查

**调查研究（survey research）**，也称**观察性研究**，指在**没有任何干预措施**的条件下，客观地观察和记录研究对象的现状及其相关特征。

两个特点，正好和实验研究相反：

1. 没有人为对研究对象施加干预措施，只是客观观察记录现状及其相关特征；
2. **不能采用随机分配的方法来平衡或消除非研究因素对研究结果的影响。**

第 2 条是调查研究一切困难的根源：你没法把「吸烟」随机分配给一半人，所以只能靠设计（匹配、分层、多变量分析）去尽量控制混杂，永远不能像 RCT 那样干净。

按抽样比例分两类：

| | **全面调查（普查，complete survey）** | **抽样调查（sampling survey）** |
| --- | --- | --- |
| 做法 | 对研究总体中**每个个体**都进行调查 | 从总体中抽取一定数量观察单位组成样本，用样本信息研究总体 |
| 适用 | 了解总体某一特定「时点」的情况，如时点患病率 | 绝大多数场合 |
| 优点 | **无抽样误差，能获得参数** | 节省资源，容易控制非抽样误差 |
| 缺点 | 耗费资源，可能引入非抽样误差 | **存在抽样误差**；设计、实施和资料分析较复杂 |

注意这里有个反直觉的点：**普查没有抽样误差，但依然可能有偏倚**（漏查、重查、测量不准），而且这类非抽样误差往往比抽样误差更难控制。「普查就一定准」是错的。

按抽样是否依赖概率，抽样调查又分：

- **概率抽样（probability sampling）**：总体中每个个体被抽中的**概率是已知的或可以计算**的。它有统计理论依据，**可以计算抽样误差，可以用样本推断总体**——这是统计分析的前提。
- **非概率抽样（non-probability sampling）**：每个个体被抽中的概率未知或无法计算，一般不能计算抽样误差、不能做统计推断。便利抽样（街头偶遇）、雪球抽样都属于这一类。它**有一定的应用价值**（探索性研究、难以建立抽样框时），但结论不能外推到总体。

### 四种概率抽样方法

| 方法 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **单纯随机抽样**（simple random sampling） | 把总体全部观察单位统一编号，用随机数字表、统计软件或抽签随机抽取 $n$ 个编号 | 操作简单，统计量计算简便 | 总体单位数庞大时逐个编号甚为繁复 |
| **系统抽样**（systematic sampling） | 把总体按某一顺序号等距分隔成 $n$ 个部分，每部分含 $k$ 个单位；从第一部分随机抽第 $i$ 号，再按相等间隔 $k$ 机械地抽出其余单位 | 易于理解、操作简便，**抽样误差一般比单纯随机小** | 总体有单调或周期性趋势时样本会出现偏性；无计算抽样误差的专用公式 |
| **分层抽样**（stratified sampling） | 先按对观察指标影响较大的某项或某几项特征（年龄、性别等）把总体分成若干层，再分别从每层内随机抽取一定数量单位 | **抽样误差小**；各层可独立分析 | 事先要对总体分层，操作麻烦 |
| **整群抽样**（cluster sampling） | 把总体划分为**群**（初级观察单位，各群由次级观察单位组成），随机抽取一部分群，**抽中群的全部次级单位**组成样本 | 适于大规模调查，易于组织操作，节省人力财力 | **抽样误差大** |

**四者的抽样误差大小顺序要背下来：**

$$\text{分层抽样} \lt \text{系统抽样} \lt \text{单纯随机抽样} \lt \text{整群抽样}$$

理解这条顺序的窍门是问「同一个总体里，我利用了多少结构信息」：

- 分层抽样**主动利用了**「层内同质、层间不同质」的结构，把层间变异扣掉了，所以最精确；
- 整群抽样把「群」整体拿进来，群内个体往往相似（一个班的学生、一个村的人），等于白白浪费了群内的信息量，所以最不精确——**代价是为达到同样的精度必须抽更多的群**；
- 单纯随机抽样两者都不用，居中；系统抽样在总体无明显趋势时略优于单纯随机。

四种方法各有各的适用面，实际的大规模调查中常把它们综合起来用，这就是**多阶段抽样（multistage sampling）**。典型做法是分层 → 抽一级单位 → 在抽中的一级单位里抽二级单位 → …… → 最后在最小单位里整群抽户。比如全国性的营养与健康状况调查就采用了多阶段分层整群随机抽样：先按大城市、中小城市、各类农村分层，再逐级抽取县（市区）、乡（街道）、村（居委会），最后整群抽取家庭进行调查。**每一阶段的观察单位都要在设计中写清楚**，它们不一定是「人」——县、乡、村、农户都可以是某一阶段的观察单位。

### 调查设计的基本内容和步骤

调查设计的完整流程是八步：

1. **明确调查目的和指标**——目的无非两类：了解参数以说明总体特征；研究变量之间的关系用于预测或控制（如探索病因）。目的要靠**调查指标**体现，指标要求具体、精选、客观，且精确性、特异度、灵敏度要高。
2. **确定调查对象和观察单位**——调查对象即明确调查总体的**同质范围**（如「某年某地 18～70 岁的全体农村居民」），做参数估计时这一步尤为重要；观察单位是个体，也可以是器官、家庭、采样点。
3. **确定调查方法**——全面调查还是抽样调查；抽样调查还要写明用哪种抽样方法、分几个阶段。
4. **估计样本含量**——考虑所调查指标的变异度、参数估计的精度及可信度，总原则是在保证结果具有一定可靠性的前提下确定最少样本例数（**详见第 17 章**）。
5. **编制调查表**。
6. **制定资料的收集计划**——培训调查人员并制定培训方案；确定收集方式：直接检测、访谈、电话调查、信访、集中调查法。
7. **制定资料的整理与分析计划**——问卷接收与核查、数据录入、资料分组（质量分组与数量分组）、统计学分析、医学专业分析。
8. **制定调查的组织措施**——组织分工、时间进度、宣传发动、培训管理。

### 调查表设计

调查表（问卷）的结构分四块：

| 部分 | 内容 |
| --- | --- |
| **说明部分** | 研究目的、重要性与必要性（写给被调查者看，争取配合） |
| **填写指导** | 统一的填写标准 |
| **核查项目** | 用于核查的质量控制项目（编号、调查员签名、审核员签名等） |
| **调查项目** | **基本信息**（背景资料：姓名、单位、联系方式）、**人口学特征**（年龄、性别、婚姻状况等）、**研究项目**（主要观察指标，核心内容） |

**提问方式**分开放与封闭两类：

- **开放式**：对问题答案不加任何限制。优点是有利于调动调查对象的主观能动性、获得信息丰富；缺点是容易离题、耗时较多、不易整理与分析、拒答率高。
- **封闭式**：根据问题可能的答案，提出两个或多个选项。优点是答案标准化、易于回答、节约时间、记录汇总方便、拒答率低；缺点是容易随便选答而丧失准确性，也难以得到答案以外的其他信息。

**提问必须遵守的四条原则**（这几条是调查表好坏的分水岭）：

1. **简单明了，避免专业术语，就低不就高**——问文化程度时给「文盲／小学／初中／高中或中专／大学」这类具体档位，不要用「受教育年限」这种还要被调查者自己去算的说法。
2. **避免混淆和模糊词语**——「经常」是多久？要量化或界定。问「你是否经常吸烟」得不到可用信息，问「过去 30 天里，你每天都吸烟吗」才行。
3. **避免双重装填的问题**——一个问题里塞两件事，被调查者答哪个都别扭。例如「您父母的文化程度是」如果只允许勾一个选项，父母学历不同的人就无从作答。
4. **避免诱导或强制性问题**——「您最近的睡眠不好吧？」已经把答案喂给对方了，改成「您最近睡眠情况如何」才是中性的。

**项目在调查表上的排列顺序**也有讲究：首先要符合逻辑顺序；一般问题在前、特殊问题在后；易答问题在前、难题在后；**敏感问题放在最后**。

**敏感问题的三种处理技术**：

- **对象转移法**：把「您一周过几次性生活」改成「有人认为正常成年男子一周适宜过 3 次性生活，也有人认为每天适宜 1 次，您同意哪种观点」；
- **假定法**：把「您同意计划生育政策吗」改成「假定人口政策不限制生育，您愿意有几个孩子」；
- **随机应答技术（randomized response technique）**：用概率装置让被调查者在不暴露个人答案的前提下作答，用于最敏感的题目。

调查表还要做**信度与效度**的考核：

- **信度（reliability）**，即可靠性：采用相同测量工具对同一对象重复测量时，各次测量值与其均值接近的程度。它衡量的是**稳不稳**。
- **效度（validity）**：观测结果与试图达到的目标之间的接近程度，是对测量工具有效性的检验。它衡量的是**准不准**。

一个好调查表要求**效度、信度均较高**。注意这两者不对称：效度高一般信度也高，但信度高不代表效度高——每次都稳定地测错同一个东西，也是一种「可靠」。

凡是涉及人的调查，还要处理**医学伦理学问题**：必须提供伦理委员会的批准文件及受试对象的**知情同意书**。知情同意包含两个相互联系的部分：**知情同意文件**（提供研究的目的、过程、计划、潜在的危险和益处以及参加者的权利）和**知情同意过程**（解释、说明和交流，让被调查者作出是否参加的决定）。受试者无行为能力时，应由与他们没有利益或感情冲突的监护人「代理同意」。

### 调查中的偏倚与控制

调查研究的误差同样分两类：**随机误差**（不可避免）和**系统误差**（即**偏倚 bias**）。偏倚在调查的每一个环节——设计、资料收集、整理与分析——都可能产生。按环节分三类：

**（1）选择性偏倚（selection bias）**

由于纳入观察对象的方法不正确而产生：选入实验组和对照组的对象在病情、年龄、性别上差异悬殊。纳入标准和排除标准规定得不明确或不正确，都可能造成选择性偏倚。描述性研究里，它主要表现为**样本的代表性**问题——没有遵循随机化原则，而是使用志愿者、健康人这类特定人群。

控制措施：正确拟定纳入和排除标准；采用分层抽样，按病情、免疫状态、年龄、性别等特征分层后再把各层对象按比例随机分配到各组（**只有对处理因素有影响的那些因素才需要分层，不合理地增加分层反而会造成偏倚**）；正确设立对照，让每个对象都有同等机会被选入任一组；贯彻随机化原则。

社区试验中为便于观察管理，常用**分层整群随机分配**：选定若干条件基本相近的地区人群作为研究群体，按某个特征（如感染率轻重）分层，每层按比例随机分配，以一个自然村作为一个实验组或对照组。这时把群体当作抽样的基本单位，**要求更大的样本含量**。

**（2）测量性偏倚（measurement bias）**

在实验过程中对研究对象进行观察或测量而造成的偏倚。实验研究（尤其社区试验）中常见五种：

| 名称 | 机制 | 后果 |
| --- | --- | --- |
| **沾染（contamination）** | 对照组对象接受了实验组的处理措施 | 对照组有效率被抬高，**缩小组间差异** |
| **干扰（interference）** | 实验组从实验外接受了对实验因素有效的药物或措施 | 实验组有效率被抬高，**扩大组间差异** |
| **依从／非依从（compliance／noncompliance）** | 受试者对干预措施及实验过程的执行程度不够 | 效应不能充分显示 |
| **失访（lost to follow-up）** | 受试者因各种原因中途退出实验 | 有可能**过高估计疗效**；失访率一般不应高于 20% |
| **心理因素干扰** | 医患双方知道处理内容造成心理影响 | 疼痛、咳嗽等症状极易受主观因素影响 |

控制措施：**盲法**（防止各种偏倚的最重要措施）；签订实验合同明确双方义务；检查依从情况（统计实际服药量占应服量的比例，观察副作用，或测血、尿、唾液中的药物浓度）；注意医德，向患者说明参与实验的利弊与副作用解决办法，方案须经医学伦理委员会批准；定期检查研究记录保证完整准确。

**（3）混杂性偏倚（confounding bias）**

在总结分析阶段，由于某些非处理因素与实验因素同时并存并影响观察结果而造成的偏倚。经典例子是血清甘油三酯与冠心病的关系：单看确实「甘油三酯越高，冠心病危险性越大」，但冠心病还与低密度脂蛋白胆固醇高、高密度脂蛋白胆固醇低有关；用统计方法平衡了这些因素之后，甘油三酯与冠心病之间的联系就消失了。**据此认为甘油三酯是冠心病的病因是欠妥的。**

控制措施：设计阶段匹配、标准化；分析阶段分层分析或多变量分析（把重要混杂因素作为协变量）。

最后一句忠告值得记住：**各种偏倚往往同时起作用，必须综合处理；而即便是十分完善的实验设计，也很难保证结果丝毫不受偏倚影响。** 所以读文献和写结论都要持审慎态度，不能绝对化。

### 临床试验的特殊之处

**临床试验（clinical trial）**以病人或正常人作为研究对象，通过施加某些干预措施（新药、新疗法等），观察其对人体的作用和不良反应，以确定治疗措施或药物的效果与安全性。相比动物实验，它有五个特点：

1. **前瞻性研究**——先给予治疗，再观察疗效与安全性；
2. **以人为研究对象**——必须符合《赫尔辛基宣言》等道德原则，需经药品管理部门和医学伦理委员会批准，以及受试对象或家属、监护人的知情同意；
3. **社会因素影响**——人具有社会性，社会因素可影响受试者的心理、精神状态，对结果产生偏性；
4. **主观因素影响**——观察人员的水平、患者的依从性、处理的非标准化都会影响研究；
5. **同一治疗方案**——临床治疗因人而异，临床试验则对所有研究对象采用同一方案，不得因人而异。

临床试验的基本原则是**随机、对照、均衡、重复 + 盲法**。规范依据是**药品临床试验管理规范（Good Clinical Practice，GCP）**，它对试验方案、受试者权益保障、研究人员职责、结果记录与报告、统计分析与数据处理、试验药品管理、质量保证、多中心试验等都有明确要求。

新药临床试验分四期，各期对例数有硬性要求（如 II 期试验组不少于 100 例，III 期不少于 300 例，IV 期不少于 2000 例），这属于法规要求，需按有关部门规定执行，不能只用统计公式算。统计分析阶段则强调**意向性分析（Intention-to-treat，ITT）**——所有被随机分组的病例都按**最初的分组**进行分析，不管他后来是否坚持了治疗、是否换了药、是否中途退出，也就是「一旦随机化，就留在原组」，中途退出者的数据同样要留在分析里。与它相对的是**符合方案分析（Per-protocol，PP）**——只把真正按原定方案完成治疗的那部分病例纳入分析，中途退出、换药的一律剔除。ITT 是临床试验初步分析的首选，PP 只能作为辅助与敏感性分析。理由还是本章那句老话：随机化一旦完成，中途退出的病例也带着随机分组的信息，随意剔除就破坏了随机化带来的均衡。

## 在 R 里怎么做

随机分组和样本含量估计，是本章唯一真正需要动手的部分。R 的 `sample()` 一行就能完成随机分组，`power.t.test()` 和 `power.anova.test()` 则把样本含量、检验效能、效应量之间的关系直接算给你看。

### 随机分组：`set.seed()` + `sample()`

```r
set.seed(2024)                      # 固定随机种子：同样的种子 + 同样的代码 = 同样的分组

n     <- 30                                              # 30 只动物
group <- rep(c("A药", "B药", "对照"), each = 10)          # 三组，每组 10 只，共 30 个标签

id    <- sample(1:n)                                     # 把编号 1~30 打乱，拿到一个随机顺序
d     <- data.frame(编号 = id, 组别 = group)              # 打乱后的编号依次贴标签
d     <- d[order(d$编号), ]                              # 按编号排回来，便于照单贴签

head(d, 6)
table(d$组别)                       # A药 / B药 / 对照 各 10 只
```

输出怎么读：

- `sample(1:n)` 返回的是 `1:30` 的一个**排列**（不是有放回地抽，所以每个编号出现且只出现一次）。这就是随机分组的全部实质——**先打乱顺序，再按顺序发标签**。
- `head(d, 6)` 给出的是「编号 1 是 B药、编号 2 是 A药、编号 4 是对照……」这样一张可以直接照着执行的分配表。
- `table(d$组别)` 确认三组例数都是 10。分组完成后，**别忘了回头检查两组的重要非处理因素是否均衡**（体重、性别、病情等）——随机化保证的是「机会均等」，不是「一定均衡」，尤其是小样本。

`set.seed()` 不是装饰。不设种子，每次运行 `sample()` 都会得到不同的分组，实验就没法复现，别人也没法核查。**种子的值本身无所谓，重要的是把它写进脚本、写进记录。**

### 区组随机化：把「随机」装进一个个小盒子

```r
set.seed(7)
k   <- 3                              # 3 个处理组
b   <- 8                              # 8 个区组，每区组 3 只条件相近的动物

blk <- rep(1:b, each = k)
trt <- as.vector(replicate(b, sample(c("A", "B", "C"))))   # 每个区组内单独打乱一次

d2  <- data.frame(区组 = blk, 处理 = trt)
head(d2, 6)
table(d2$区组, d2$处理)               # 每个区组里 A/B/C 各一个
```

关键在于 `replicate(b, sample(...))`：**每个区组各自独立地打乱一次**，而不是把 24 只动物整体打乱。这样做的收益是任意时刻看，各组例数都基本相等，中途做期中分析或试验提前结束时，不会出现「A 组 12 只、C 组 4 只」这种尴尬局面。

### 配对设计：每对内部抛一次硬币

```r
set.seed(11)
n_pair <- 10
x1 <- sample(c("试验", "对照"), n_pair, replace = TRUE)   # 每对里第一只的组别随机定
x2 <- ifelse(x1 == "试验", "对照", "试验")                # 第二只自动是相反的组

data.frame(对子 = 1:n_pair, 甲 = x1, 乙 = x2)
```

这里 `sample(..., replace = TRUE)` 是**有放回**抽样——每个对子的决定互相独立，这正是我们要的。对子内部的第二只不用再随机，因为一对里一只进试验组，另一只就必须进对照组。

### 分层随机化：先分层，再在层内随机

```r
set.seed(42)
n   <- 40
sex <- rep(c("男", "女"), each = 20)
bw  <- round(rnorm(n, 22, 2), 1)      # 体重：动物实验里最常用的均衡依据

grp <- character(n)
for (s in c("男", "女")) {                    # 一层一层地做
  idx      <- which(sex == s)
  idx      <- idx[order(bw[idx])]             # 层内先按体重排队
  grp[idx] <- sample(rep(c("试验", "对照"), length.out = length(idx)))
}

d3 <- data.frame(性别 = sex, 体重 = bw, 组别 = grp)
table(d3$性别, d3$组别)                       # 每层的两组各 10 只
tapply(d3$体重, d3$组别, mean)                # 两组的平均体重几乎一样
```

`for` 循环在这里不是多余：**分层的本质就是「逐层重复一次随机化」**。层内先按体重排序再随机贴标签，等于在层内又做了一次按体重的配对——这就是分层均衡法在代码里的样子。

### 把四种概率抽样方法跑一遍

先用代码造一个「抽样框」——1200 名学生、24 个班。实际的抽样框当然长得多，但结构是一样的。

```r
set.seed(2025)
frame <- data.frame(
  id  = 1:1200,
  cls = rep(1:24, each = 50),                      # 24 个班，每班 50 人
  sex = sample(rep(c("男", "女"), each = 600))     # 男女各半，顺序随机打乱
)

# ① 单纯随机抽样：从 1200 人里随机抽 100 人
srs <- frame[sample(nrow(frame), 100), ]

# ② 系统抽样：抽样间隔 k = 1200/100 = 12，随机定起点后每隔 12 号抽一个
kk    <- nrow(frame) / 100
start <- sample(kk, 1)
sys   <- frame[seq(start, nrow(frame), by = kk), ]

# ③ 分层抽样：按性别分两层，每层各抽 50 人
strat <- frame[unlist(lapply(split(seq_len(nrow(frame)), frame$sex),
                             function(i) sample(i, 50))), ]

# ④ 整群抽样：随机抽 4 个班，班里的学生全部入样
cl <- frame[frame$cls %in% sample(unique(frame$cls), 4), ]

c(单纯随机 = nrow(srs), 系统 = nrow(sys), 分层 = nrow(strat), 整群 = nrow(cl))

table(strat$sex)    # 分层抽样：男 50、女 50 —— 性别比例被"锁死"了
table(cl$cls)       # 整群抽样：4 个班各 50 人 —— 例数对，但只有 4 个班
```

输出怎么读：

- 前三种方法都得到 100 人，整群抽样得到 **200 人**。这就是「**整群抽样的样本量要放大**」的具体含义：你说「抽 100 人」，整群抽样给出的是整群规模的整数倍，例数并不由你精确控制。
- `table(strat$sex)` 显示男女各 50，说明分层抽样**主动保证了**性别构成与总体一致。这是它抽样误差最小的直观来源。
- `table(cl$cls)` 只有 4 个班。虽然总人数不少，但**这 4 个班内部的人彼此相似**（同班同学的家庭背景、居住区域相近），信息量远不如随机分散抽出的 100 人——这就是整群抽样精度最低的原因。

顺便用代码感受一下系统抽样的那个坑：如果总体的排列带有**周期性**，等距抽取会系统性地偏。

```r
f2 <- data.frame(id = 1:1200, sex = rep(c("男", "女"), times = 600))   # 男女交替排列
table(f2$sex[seq(6, 1200, by = 12)])     # 间隔取偶数，抽出来的全是同一种性别
```

总体的名册如果正好按「男、女、男、女」交替排列，间隔取偶数就永远只抽到同一种性别。**系统抽样前必须看一眼抽样框有没有规律的排列顺序。**

### 样本含量：`power.t.test()`

`power.t.test()` 的参数有四个：`n`、`delta`、`sd`、`power`。**给三个，它算第四个**——这是使用它的全部窍门。

```r
# 已知：希望检出的均数差 delta = 0.5，个体标准差 sd = 1，双侧 alpha = 0.05
# 求：检验效能 0.80 时需要多少例
power.t.test(delta = 0.5, sd = 1, sig.level = 0.05, power = 0.80,
             type = "two.sample", alternative = "two.sided")
```

```
     Two-sample t test power calculation

              n = 63.76576
          delta = 0.5
             sd = 1
      sig.level = 0.05
          power = 0.8
    alternative = two.sided

NOTE: n is number in *each* group
```

**最后那行 `NOTE` 一定要看**：`n` 是**每组**的例数，所以两组合计需要 128 例。这是本章最容易算错的地方——读成「总共 64 例」就少了一半。

用前面那个近似公式手算一遍：$n = 2(1.96 + 0.8416)^2 \times 1 / 0.5^2 = 62.8$，取整 63 例。R 给出 63.77，因为它用的是 $t$ 分布而不是正态近似，会略大一点。**手算用来估个数量级，正式写方案要用软件算。**

换成配对设计，`type` 改一下就行，此时的 `sd` 是**差值**的标准差：

```r
power.t.test(delta = 0.5, sd = 1, power = 0.80, type = "paired")
# n = 33.37 —— 约 34 对，比两样本设计的每组 64 例省得多
```

这就是「配对设计提高统计效率」在数字上的体现：**同样的效应量和变异，配对所要求的例数少得多**，因为配对把个体间的差异扣掉了。

### 效应量怎么影响样本含量

把 `delta` 从 0.2 一路拉到 1.0，看每组例数怎么变：

```r
delta <- c(0.2, 0.3, 0.5, 0.8, 1.0)
ceiling(sapply(delta, function(d) power.t.test(delta = d, sd = 1, power = 0.8)$n))
# [1] 394 176  64  26  17
```

阅读这串数字的正确姿势：

- 要检出「小」效应（$\delta/\sigma = 0.2$），需要**每组近 400 例**——这就是为什么很多小规模临床研究注定什么都检不出来；
- 效应量涨得不多，例数掉得很快：$\delta$ 从 0.2 提到 0.5（2.5 倍），例数从 394 掉到 64，只剩约六分之一。因为 $n$ 与 $\delta^2$ 成反比，$\delta$ 变 $k$ 倍，$n$ 就变 $1/k^2$；
- 反过来说，**「缩小 $\sigma$」和「增大 $\delta$」比「多收病人」划算得多**。严格控制纳入标准、把人群选得更同质（$\sigma$ 变小），或者在设计上让干预强度更大（$\delta$ 变大），都能省下大量例数。

### 检验效能：$n$ 与 power 的关系

反过来问：给定例数，我能有多少把握？

```r
n_seq <- c(10, 20, 30, 50, 64, 100)
round(sapply(n_seq, function(ni)
  power.t.test(n = ni, delta = 0.5, sd = 1)$power), 3)
# [1] 0.184 0.338 0.478 0.697 0.801 0.940
```

这一串数字说明两件事：

1. **效能随例数增加，但增长是「先快后慢」的**：20 → 30 例效能涨了 0.14，而 64 → 100 例同样涨 0.14 却多花了 36 例。堆例数到一定程度就不划算了。
2. **n = 10 时效能只有 0.18**：意味着真有差别时，这个实验有 **82% 的概率检不出来**。这样的小样本研究得出「无统计学意义」，几乎不携带任何信息——**它既不能证明有效，也不能证明无效。**

### 把公式里的 σ 换成你自己的数据

公式里的 $\sigma$ 不是从天上掉下来的，得从预实验或既有资料里估。R 自带的数据集就能用来练这个流程：

```r
sd(mtcars$mpg)      # 6.03 —— 假设某指标在个体间的标准差大致就是这个量级

# 想检出 5 个单位的组间差别，每组需要多少例？
power.t.test(delta = 5, sd = sd(mtcars$mpg), power = 0.80)
# n = 23.81 —— 每组 24 例，两组合计 48 例
```

真实工作中，$\sigma$ 应当来自**同一个指标、同一类人群**的预实验或文献，而不是随便找一个数据集。这里只是演示流程：**定 $\delta$ → 估 $\sigma$ → 定 $\alpha$ 和 power → 求 $n$**。

### 多组比较：`power.anova.test()`

两组以上要用方差分析，对应的函数是 `power.anova.test()`。它的参数不叫 `delta`／`sd`，而叫 `between.var`（**组间**方差，即各组均数的方差）和 `within.var`（**组内**方差，即个体变异的方差）。

```r
# 3 个处理组，预期各组总体均数为 0 / 0.5 / 1.0，个体标准差 sigma = 1
mu <- c(0, 0.5, 1.0)

# 每组 25 例时，检验效能是多少？
power.anova.test(groups = 3, n = 25, between.var = var(mu),
                 within.var = 1, sig.level = 0.05)
# power = 0.883

# 反过来：要 0.80 的效能，每组需要多少例？
power.anova.test(groups = 3, power = 0.80, between.var = var(mu),
                 within.var = 1, sig.level = 0.05)
# n = 20.30 —— 每组 21 例，三组合计 63 例
```

再扫一遍例数与效能的关系：

```r
n_a <- c(10, 20, 30, 40, 60)
round(sapply(n_a, function(ni) power.anova.test(groups = 3, n = ni,
        between.var = var(mu), within.var = 1)$power), 3)
# [1] 0.458 0.793 0.936 0.983 0.999
```

两个使用要点：

- `between.var` 传的是**均数的方差** `var(mu)`，不是均数的极差或最大差值。这是最常传错的参数。
- `power.anova.test()` 只处理**各组例数相等**的平衡设计。若你的设计例数不等，**绝不能取最大的那组例数当「保守估计」——那会把效能估高**，因为把最大组的 $n$ 代进公式，等于假装每一组都有那么大。以三组、每组 10/20/30 例，$\mu = (0,\,0.5,\,1)$、$\sigma = 1$（即 `between.var = 0.25`、`within.var = 1`）为例，重复 20000 次模拟得到的实测效能约为 0.71（换 5 个不同的随机种子各跑 20000 次，结果都在 0.709～0.713 之间）；而 `power.anova.test(n = 30)` 给出 0.936，高估了约 0.22；取最小的 10 例反而偏保守（0.458），取调和均值 16.36 则最接近实测（0.698）。所以正确做法有三条：取**最小的那组**（偏保守）、取**调和均值**（更接近实际），或者用能直接填不等例数的工具算（如两组比较时 `pwr` 包的 `pwr.t2n.test()`），也可以直接用模拟（`replicate()` + `aov()` 跑很多次，数一数有多少次 $P \lt 0.05$）来估效能。

完整的样本含量估计方法——包括率的比较、配对设计、随机区组等各类场合的公式与软件实现——**详见第 17 章**；析因设计、生存分析等场合本课程未覆盖，需要另找资料。本节的目标只是让你先建立起「样本量是可以算出来的，而且它和 $\alpha$、$\beta$、$\sigma$、$\delta$、设计类型绑在一起」这个观念。

## 容易踩的坑

- **把「按顺序分」当成了「随机分」。** 按就诊顺序、入院先后、住院号奇偶来分组，都不是随机分组。患者来就诊的时间本身带有聚集性——某段时间来的人可能普遍偏重，另一段时间普遍偏轻，于是两组在重要非处理因素上就不均衡了。同样，「让医生凭经验分」「让患者自己选」也都不是随机。**随机的定义只有一个：每个对象有同等机会被分到任一组，且这个机会由概率机制决定。**
- **对照选得和实验目的不匹配。** 「比较 A 药 + B 药联合用药是否优于单用 A 药」，对照却设成了「无关的 C 药」，那这个对照再多也无法回答研究问题——正确的对照是「A 药 + 安慰剂」。另外三件事要分清：**无对照**（只有试验组，说明不了任何问题）、**对照不足**（研究两个因素却不设单因素组，交互作用无法拆开）、**对照过剩**（比较两种都已证实有效的药，还硬加安慰剂组，多余且违反伦理）。
- **用自身对照替掉平行对照，把时间趋势当成疗效。** 「服药后血压降了，所以药有效」这种论证忽略了：血压本来就可能随时间、饮食、情绪、季节变化。自身对照简单易行，但在不同阶段接受不同处理的场合，**时间因素无法排除**，所以通常还要另设一个平行的外对照（或改用交叉设计，用另一组反向的时序来抵消时间效应）。
- **对重复测量资料逐时点做 t 检验。** 这是最典型的分析方法选错。同一批人在 5 个时间点被测量，5 个时点的数据**彼此不独立**（一个人的值天然会前后相关），而 t 检验的前提恰恰是独立性。逐点做 t 检验还会因多重比较导致假阳性膨胀，同时又完全没回答「时间有没有影响」「处理与时间有没有交互作用」这两个重复测量设计本要回答的问题。正确做法是**重复测量资料的方差分析**（注意球对称假设）。
- **把 $P \gt 0.05$ 读成「两组没有差别」。** $P \gt 0.05$ 只说明「按当前这批数据，没有足够证据认为两组不同」。如果检验效能只有 0.18，那这个「没有证据」几乎等于没做事。写结论时应当同时报告**效应量及其置信区间**和**检验效能**；回答「要多少例才够」应当用 `power.t.test()`，而不是「多收点总没错」——例数过多会浪费资源，还可能把没有临床意义的微小差别做成「有统计学意义」。

## 小结

1. **实验设计是唯一「必须提前做对」的环节。** 医学研究分调查研究（观察性）、实验研究、文献研究三类。实验研究的两大特点是研究者能人为设置处理因素、受试对象接受何种处理由随机决定；调查研究两条都不具备，只能靠设计去控制混杂。
2. **三要素是处理因素、受试对象、实验效应。** 处理因素要抓主要因素、分清非处理因素、做标准化，并警惕**混杂因素**（用排除法、平衡法、标准化法控制）；受试对象靠**诊断标准 → 纳入标准 → 排除标准**三层书面规定来界定，并满足敏感性、特异性、稳定性、同质性、依从性、经济性；实验效应靠指标体现，指标要**客观、灵敏、精确（准确度 + 精密度）、特异、有针对性**，观察时用**盲法**防偏。
3. **四原则是对照、随机、重复、均衡。** 对照有空白、安慰剂、标准、实验、自身、相互六种形式，常见错误是无对照、对照不足、对照过剩；随机化包含随机抽样、随机分组和实验顺序随机，实施方法有简单、区组、分层三种；重复主要指独立重复实验次数要够；均衡即齐同对比，是四原则中最易被忽视也最重要的一条。
4. **样本含量由 $\alpha$、$\beta$、$\sigma$、$\delta$ 和设计类型共同决定。** $n$ 与 $\sigma^2$ 成正比、与 $\delta^2$ 成反比，要求效能越高、$\alpha$ 越小，$n$ 越大。检验效能 $= 1-\beta$，习惯要求不低于 0.80。**$P \gt 0.05$ 只能说明「没检出差别」，效能不足时不能说明「没有差别」。** 完整方法详见第 17 章。
5. **常用设计类型的选择逻辑：** 只有一个因素且无法配伍 → 完全随机设计；能把对象配成条件相近的对子 → 配对设计；能按条件划分区组且对比组数 $\ge 3$ → 随机区组设计；慢性病、需要减少个体差异的影响 → 交叉设计；要分析多个因素的交互作用 → 析因设计；同一对象多时点观测 → 重复测量设计（不能用 t 检验逐点比较）。
6. **调查设计的两条主线是抽样和控制偏倚。** 抽样要记住四种概率抽样方法的做法与优缺点，以及**抽样误差排序：分层 $\lt$ 系统 $\lt$ 单纯随机 $\lt$ 整群**（整群抽样因此需要更大的样本量，多阶段抽样则是它们的组合）。偏倚分选择性偏倚、测量性偏倚（沾染、干扰、非依从、失访）、混杂性偏倚三类，分别用明确的纳入排除标准与随机化、盲法与依从性检查、匹配与分层／多变量分析来控制。调查表设计则守住提问四原则（简明、不模糊、不双重装填、不诱导）和「敏感问题放最后」。
7. **在 R 里，本章落实为四件事**：用 `set.seed()` + `sample()` 做可复现的随机分组（连同区组、配对、分层三种变体）；用索引取子集实现四种概率抽样；用 `power.t.test()` 在 `n`／`delta`／`sd`／`power` 中「给三求一」；用 `power.anova.test()` 处理多组比较（注意 `between.var` 传的是**均数的方差**）。
